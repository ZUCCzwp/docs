<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status and read the final video URL from `result.video_url`.
</Note>

This uses the same endpoint as [Create Seedance Full Video](/en/api-reference/seedance/create): `POST /api/open-api/v1/seedance/videos`. Select this route with `model: "sd2-933-720p"`.

## Supported models

| model | Notes |
|-------|-------|
| `sd2-933-720p` | Seedance 933 720p: fixed 720p output; text-to-video plus optional reference images / videos / audios |

Aliases such as `sd2_933_720p` and `sd2-933720p` normalize to `sd2-933-720p`. Legacy `sd2-adb-720p` is also accepted.

## Parameter constraints

- **Prompt**: Required, 1–5000 characters.
- **Duration**: 4–15 seconds (default `5`).
- **Aspect ratio** (`aspect_ratio` / `ratio`): `16:9`, `9:16`, `1:1`, `4:3`, `3:4` (default `16:9`).
- **Resolution**: Fixed `720p` (do not send other values).
- **Reference images**: `images` / `reference_images`, max **9**, public HTTPS URLs or `asset://{assetId}`.
- **Reference videos**: `videos` / `reference_videos`, max **3**.
- **Reference audios**: `audios` / `reference_audios`, max **3**; must be paired with at least one image or video reference.
- **Reference mode** (`reference_mode`): `frame` (first / first-last frame) or `media` (multi-image subject reference); default `frame`. Aliases `image` → `media`.
- **Generate audio** (`generate_audio`): boolean, default `true`.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `sd2-933-720p` |
| `prompt` | string | Yes | Text prompt |
| `duration` | integer | No | Duration in seconds, default `5` |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `reference_mode` | string | No | `frame` / `media` |
| `generate_audio` | boolean | No | Whether to generate audio, default `true` |
| `images` / `reference_images` | string[] | No | Reference image URLs (0–9) |
| `videos` / `reference_videos` | string[] | No | Reference video URLs (0–3) |
| `audios` / `reference_audios` | string[] | No | Reference audio URLs (0–3); requires image or video refs |

## Billing

- Mode: `per_second`
- Billing model: `sd2-933-720p`
- Unit price: **0.0479** / second (see [console pricing](https://api.viraltok.ai) if adjusted)

```text
cost = 0.0479 × duration
```

## Example request

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-933-720p",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 5,
    "aspect_ratio": "16:9",
    "reference_mode": "media",
    "generate_audio": true,
    "images": ["https://example.com/reference.png"],
    "reference_videos": ["https://example.com/reference.mp4"]
  }'
```
