---
title: '查询探测模型定价'
openapi: 'GET /api/v1/models'
---

探测并返回 ViraltokAI OpenAPI **公开模型目录**：计费、调用入口和字段约束。同一 `series` 且同一 `group` 的计费收成一条；创建任务时使用 `billings[].model_name`。没有 `series` 的模型不合并，直接使用该条的 `model_name`。

<Note>
本接口返回的是**平台默认单价**。若你在控制台为账户配置了某模型的专属价格，实际扣费以创建/查询响应中的 `cost` 为准（按账户定制价结算）。列表中的 `unit_price` 始终为公开基准价。
</Note>

<Note>
**备注（兼容路径）**：`GET /api/openapi/model/catalog` 仍可用，行为与 `GET /api/v1/models` 相同。
</Note>

### 鉴权

无需 API Key，可不携带 `Authorization` 请求头。

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `search` | string | 否 | 子串过滤，匹配 `model_name`、`display_name`、`model_type`、`series`、`remark`。不传则返回全部启用模型。 |

### 响应字段

`data.list` 中每一项是一个产品。同一 `series` 且同一 `group` 合并为一条；`series` 或 `group` 不同则分开。没有 `series` 的模型保持一条计费一条记录。

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `model_name` | string | 合并后等于 `group`。没有 `billings` 时，创建接口的 `model` 使用此值 |
| `display_name` | string | 展示名称。合并且有 `group` 时与 `group` 相同 |
| `model_type` | string | 产品类型（如 `video`、`image`、`audio`、`llm`） |
| `series` | string | 产品系列。例如 Wan 3.0 特价与官转可以同属 `wan3`，但 `group` 不同，因此仍是两条 |
| `group` | string | 分组。合并后的 `model_name`、`display_name` 和 `scheme.model` 都取此值 |
| `price_mode` | string | 计费方式（见下表） |
| `unit_price` | number | 平台默认单价（吉米币）。合并后为各计费里大于 0 的最低价 |
| `official_price` | number | 参考标价（有配置时返回，否则省略） |
| `remark` | string | 可选说明 |
| `scheme` | object | 调用约定，见下表。没有可选时长的产品不返回 `duration` |
| `billings` | array | 该产品下的计费。创建任务时传其中的 `model_name` |

### `billings[]`

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `model_name` | string | 创建接口 `model` 应传的值 |
| `display_name` | string | 该计费的展示名 |
| `price_mode` | string | 该计费的计费方式 |
| `unit_price` | number | 该计费的平台默认单价 |
| `official_price` | number | 参考标价，未配置时省略 |
| `remark` | string | 可选说明 |
| `duration` | object | 该计费自己的时长范围。字段与 `scheme.duration` 相同 |

### `scheme`

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `endpoint` | string | 创建任务的路径，如 `/api/v1/videos` |
| `method` | string | HTTP 方法，通常为 `POST` |
| `model` | string | 与外层 `group` 相同 |
| `duration` | object | `min`、`max`、`default`、`unit`（`seconds`）。离散档位另有 `options`。`adaptive` 为 true 时，`duration` 可传 `-1` 表示自动时长 |
| `resolutions` | array | 允许的分辨率 |
| `aspect_ratios` | array | 允许的宽高比 |
| `constraints` | array | 创建请求的字段限制。`field` 是 JSON 字段名，可含 `required`、`options`、`min`、`max`、`max_count`、`max_length` |

有时长范围时，`constraints` 里会有一条 `field` 为 `duration` 的限制，`min` / `max` 与 `scheme.duration` 一致。合并后的 `scheme.duration` 是各计费时长的并集；每条计费自己的范围看 `billings[].duration`。

### 计费方式（`price_mode`）

| 取值 | 含义 |
| :--- | :--- |
| `per_task` | 按次/按任务固定计费（默认） |
| `per_second` | 单价 × 视频时长（秒） |
| `per_million_tokens` | 单价 × token 数 ÷ 1,000,000 |
| `per_10k_char` | 按每 1 万字符计费（SoundClone） |
| `pay_as_you_go` | 按实际用量（token 等）后结算 |

任务实际费用以创建/查询接口返回的 `cost` 为准。

### 示例

查询全部模型：

```bash
curl -X GET 'https://api.viraltok.ai/api/v1/models'
```

搜索 Seedance 相关模型：

```bash
curl -X GET 'https://api.viraltok.ai/api/v1/models?search=seedance'
```
