---
title: 'Create Full Super-Resolution SP Fast Video'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

Create a Seedance **Full Super-Resolution SP Fast** video generation task. On success you receive a `task_id`. Poll [Query Video Task](/en/api-reference/common/query) until `completed`, then read the video URL from `result.video_url`.

<Note>
This uses the same endpoint as [Create Full Super-Resolution SP Video](/en/api-reference/seedance/sp/create): `POST /api/open-api/v1/seedance/videos`. Non-Fast SP models are on the SP page; Full Fast is [Create Full Fast Video](/en/api-reference/seedance/fast/create); GZ Fast is [Create Seedance 2.0 GZ Fast Video](/en/api-reference/seedance/fast/create-gz).
</Note>

## Models and routes

Choose an SP Fast sub-route via the `model` field:

| Route | `model` value | Billing | Duration | Requirements |
|-------|---------------|---------|----------|--------------|
| **Full Super-Resolution SP Fast** | `sd2_sp_fast_780p` | Per second | 4–15 s | Public URL or asset library; `reference_videos` not supported |
| **Video Reference Fast** | `sd2_sp_video_fast_780p` | Per second | 4–15 s | Same as above; supports `reference_videos` |

## Billing

Deduct corresponding computing credits directly based on the selected `model`:

| Item | Description |
|------|-------------|
| Calculation | **Unit price (credit/s) × `duration`** |
| Unit Price | Based on the price for the corresponding model name in the console |
| Duration | `duration` field, ranging from 4 to 15 seconds |

## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | See table above |
| `prompt` | string | Yes | Text prompt |
| `duration` | int | Yes | Length in seconds, 4–15 (default 5) |
| `ratio` | string | No | Aspect ratio, e.g. `16:9`, `9:16`, `1:1` |
| `images` | string[] | No | Reference images |
| `first_image` | string | No | First frame |
| `last_image` | string | No | Last frame |
| `reference_videos` | string[] | No | Reference videos; only `sd2_sp_video_fast_780p` |
| `reference_audios` | string[] | No | Reference audio; must pair with images/videos or frames |

## Assets

- Pass public `https://` URLs directly.
- Or [upload assets](/en/api-reference/seedance/sp/assets-upload) first, then use `asset://{asset_id}`.

## Constraints

- Do not combine `images` (reference mode) with `first_image` / `last_image` (frame mode).
- `reference_audios` cannot be used alone; pair with reference images/videos or frames.
- `reference_videos` is only supported on `sd2_sp_video_fast_780p`.

## Example

### Using uploaded assets

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2_sp_fast_780p",
    "prompt": "Slow dolly in, subtle lighting change",
    "duration": 8,
    "ratio": "16:9",
    "images": ["asset://your-asset-id-here"]
  }'
```

## Response

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "sd2_sp_fast_780p",
    "created_at": 1710000000
  }
}
```

## Poll for result

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

Statuses: `queued` → `processing` → `completed` or `failed`. Video URL is in `data.result.video_url` when completed.

<Note>
Result URLs are retained for about **3 days**. Download promptly.
</Note>
