<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status and read the final video URL from `result.video_url`.
</Note>

## Supported models

| model | Notes |
|-------|-------|
| `kling-o3` | Kling O3 video generation. Supports text-to-video, up to 3 reference images, optional first/last frames, 720p/1080p, and optional audio. |

Aliases such as `klingo3`, `kling_o3`, and `KlingO3` normalize to `kling-o3`.

## Parameter constraints

- **Prompt**: Required, 1–2000 characters.
- **Duration**: 3–15 seconds (default `6`).
- **Aspect ratio** (`aspect_ratio` / `ratio`): `16:9`, `9:16`, `1:1` (default `16:9`).
- **Resolution**: `720p`, `1080p` (default `720p`).
- **Reference images**: `reference_images` or `images`, max **3**, public HTTPS URLs.
- **First / last frame**: optional `first_image` / `last_image` (one each).
- **Generate audio**: `generate_audio`, default `false`.
- **Reference mode**: optional `reference_mode` string passthrough.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | Must be `kling-o3` |
| `prompt` | string | Yes | Text prompt, 1–2000 characters |
| `duration` | integer | No | Duration in seconds, default 6 |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `resolution` | string | No | Output resolution, default `720p` |
| `reference_images` | string[] | No | Reference image URLs (0–3) |
| `images` | string[] | No | Alias for `reference_images` when the latter is empty |
| `first_image` | string | No | First-frame image URL |
| `last_image` | string | No | Last-frame image URL |
| `generate_audio` | boolean | No | Whether to generate an audio track, default `false` |
| `reference_mode` | string | No | Optional reference mode |

## Billing

- Mode: `per_task`
- Request model: `kling-o3`
- Billing model: `kling-o3-{resolution}` (`kling-o3-720p` / `kling-o3-1080p`), falling back to `kling-o3` if the resolution row is not configured
- `duration` controls generation length only and **does not affect billing**

```text
cost = unit_price
```
