**备注（兼容路径）**：旧接口 `/api/open-api/v1/wan/videos` 仍可调用，行为与 `POST /api/v1/videos` 相同；新接入请优先使用统一入口。
</Note>


<Note>
创建成功后会返回 `task_id`。请使用 [查询视频任务](/zh/api-reference/common/query) 接口轮询任务状态，任务完成后从 `result.video_url` 获取视频地址。
</Note>

本接口与 [创建 Wan 3.0 视频](/zh/api-reference/wan/create) 共用 `POST /api/v1/videos`。通过 `model: "wan3.0-gl"` 选择本型号，独立计费。

## 支持的模型

| model | 说明 |
|-------|------|
| `wan3.0-gl` | Wan 3.0官链视频生成，支持文生视频、首帧/首尾帧生视频、参考生视频（参考图最多 10 张、参考视频最多 5 个、参考音频最多 5 段）、参考文件生视频、参考网页生视频，时长 2–30 秒，分辨率 480p/720p/1080p |

## 生成模式

| 模式 | 传参 |
|------|------|
| 文生视频 | 仅 `prompt` |
| 首帧生视频 | `first_image` |
| 首尾帧生视频 | `first_image` + `last_image` |
| 参考生视频 | `reference_images` / `reference_videos` / `reference_audios` |
| 参考文件生视频 | `file_url`（可不传 `prompt`） |
| 参考网页生视频 | `link_url` |
| 视频编辑 | `task_type: "edit"` + `reference_videos` + `prompt`（含编辑意图） |
| 视频延长 | `task_type: "extend"` + `reference_videos` + `prompt`（含延长意图） |

首尾帧（`first_image` / `last_image`）与参考素材（参考图/视频/音频、`file_url`、`link_url`）**不能混用**；`file_url` 与 `link_url` 只能二选一。参考图/视频/音频与 `file_url` 或 `link_url` 可同时使用。编辑 / 延长不支持首尾帧，也不支持 `file_url` / `link_url`。

`wan30-gl`、`wan-3.0-gl` 会归一化为 `wan3.0-gl`。也可直接传计费型号 `wan3.0-gl-480p` / `wan3.0-gl-720p` / `wan3.0-gl-1080p`，此时后缀即分辨率。

## 参数限制

- **提示词（prompt）**：与素材（首尾帧、参考图/视频/音频、文件、网页）至少填写一项；`edit` / `extend` 时必填，并写明编辑或延长意图。可用「图1」「视频1」「音频1」指代素材，编号按同类素材在数组中的顺序。
- **时长（duration）**：2–30 秒，默认 `5`。`edit` 须为 `-1`；`extend` 可为 `-1`（智能时长）或延长后的总时长（2–30）。
- **画幅比例（aspect_ratio / ratio）**：`adaptive`（自适应）、`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`21:9`，默认 `16:9`。`edit` / `extend` 须为 `adaptive`。
- **任务类型（task_type）**：可选 `edit` / `extend`（仅本型号）。空表示普通生成。
- **分辨率（resolution）**：`480P`、`720P`、`1080P`（大小写不敏感），默认 `720P`。
- **参考图**：`reference_images` 或 `images`，最多 **10** 张，须为公网可访问 URL。
- **参考视频**：`reference_videos` 或 `videos`，最多 **5** 个，须为公网可访问 URL；`edit` / `extend` 至少 1 个。
- **参考音频**：`reference_audios`，最多 **5** 段，须为公网可访问 URL。
- **首帧 / 尾帧**：`first_image` / `last_image` 各 1 张公网 URL；传 `last_image` 时必须同时传 `first_image`。
- **参考文件**：`file_url`，1 个公网 URL；支持 docx / doc / xlsx / xls / pptx / ppt / pdf / txt / key / pages / numbers / md 等，不超过 100MB、50 页。`edit` / `extend` 不可用。
- **参考网页**：`link_url`，1 个公开、免登录的网页 URL。`edit` / `extend` 不可用。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | 传 `wan3.0-gl`，或分辨率计费型号 |
| `prompt` | string | 否 | 文本提示词；未提供任何素材时必填；`edit` / `extend` 必填 |
| `duration` | integer | 否 | 时长秒数，2–30，默认 5；`edit` 须 `-1`；`extend` 支持 `-1` 或总时长 |
| `aspect_ratio` | string | 否 | 画幅比例，优先于 `ratio`；`edit` / `extend` 须 `adaptive` |
| `ratio` | string | 否 | `aspect_ratio` 别名 |
| `resolution` | string | 否 | 输出分辨率：`480P` / `720P` / `1080P`，默认 `720P` |
| `task_type` | string | 否 | `edit` 视频编辑 / `extend` 视频延长 |
| `reference_images` | string[] | 否 | 参考图 URL 列表（0–10） |
| `images` | string[] | 否 | `reference_images` 别名（当后者为空时生效） |
| `reference_videos` | string[] | 否 | 参考视频 URL 列表（0–5） |
| `videos` | string[] | 否 | `reference_videos` 别名 |
| `reference_audios` | string[] | 否 | 参考音频 URL 列表（0–5） |
| `first_image` | string | 否 | 首帧图片 URL |
| `last_image` | string | 否 | 尾帧图片 URL，需同时传 `first_image` |
| `file_url` | string | 否 | 参考文件 URL，与 `link_url` 二选一 |
| `link_url` | string | 否 | 参考网页 URL，与 `file_url` 二选一 |

## 请求示例

### 参考生视频

```bash
curl -X POST https://api.viraltok.ai/api/v1/videos \
  -H "Authorization: Bearer $JIMMYAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan3.0-gl",
    "prompt": "图1 中的人物在海边奔跑，电影感运镜",
    "duration": 5,
    "aspect_ratio": "9:16",
    "resolution": "720P",
    "reference_images": ["https://example.com/person.png"]
  }'
```

### 首尾帧生视频

```json
{
  "model": "wan3.0-gl",
  "prompt": "从微笑逐渐变为大笑，背景光线由冷变暖",
  "first_image": "https://example.com/first.png",
  "last_image": "https://example.com/last.png",
  "duration": 5
}
```

### 文生视频

```json
{
  "model": "wan3.0-gl",
  "prompt": "清晨海面，薄雾缓缓散开，电影感推镜",
  "duration": 8,
  "aspect_ratio": "21:9",
  "resolution": "1080P"
}
```

### 参考文件生视频

```json
{
  "model": "wan3.0-gl",
  "file_url": "https://example.com/product.pptx",
  "resolution": "720P",
  "duration": 10
}
```

### 参考网页生视频

```json
{
  "model": "wan3.0-gl",
  "prompt": "把这篇文章做成一支科普短片",
  "link_url": "https://example.com/article/123",
  "duration": 15
}
```

### 视频编辑

须传 `task_type: "edit"`、至少 1 个 `reference_videos`，且 `aspect_ratio` 为 `adaptive`、`duration` 为 `-1`。`prompt` 需写明编辑意图。

```bash
curl -X POST https://api.viraltok.ai/api/v1/videos \
  -H "Authorization: Bearer $JIMMYAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan3.0-gl",
    "task_type": "edit",
    "prompt": "编辑视频，把白天场景换成雨天",
    "duration": -1,
    "aspect_ratio": "adaptive",
    "resolution": "720P",
    "reference_videos": ["https://example.com/input.mp4"]
  }'
```

### 视频延长（智能时长）

须传 `task_type: "extend"`、至少 1 个 `reference_videos`，且 `aspect_ratio` 为 `adaptive`。`duration: -1` 表示由模型决定延长后的输出时长。

```bash
curl -X POST https://api.viraltok.ai/api/v1/videos \
  -H "Authorization: Bearer $JIMMYAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan3.0-gl",
    "task_type": "extend",
    "prompt": "向后延长视频，保持运镜与主体连贯",
    "duration": -1,
    "aspect_ratio": "adaptive",
    "resolution": "720P",
    "reference_videos": ["https://example.com/input.mp4"]
  }'
```

### 视频延长（指定总时长）

也可显式传入延长后的总时长。例如输入视频约 5 秒、再延长 2 秒，传 `"duration": 7`。

```bash
curl -X POST https://api.viraltok.ai/api/v1/videos \
  -H "Authorization: Bearer $JIMMYAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan3.0-gl",
    "task_type": "extend",
    "prompt": "向后延长 2 秒，人物继续向前走",
    "duration": 7,
    "aspect_ratio": "adaptive",
    "resolution": "720P",
    "reference_videos": ["https://example.com/input.mp4"]
  }'
```

## 计费说明

- 计费方式：`per_second`（按秒）
- 请求模型名：`wan3.0-gl`（或分辨率计费型号）
- 计费模型名：`wan3.0-gl-{resolution}`（`wan3.0-gl-480p` / `wan3.0-gl-720p` / `wan3.0-gl-1080p`），不同分辨率单价不同
- 未传 `resolution` 时按 `720P` 计费
- 创建时按请求 `duration` 预扣；`duration=-1` 时按可探测的参考视频时长预扣，任务成功后按实际计费秒数多退少补
- 查询任务详情时，完成后会在 `data.usage.duration` 返回实际计费秒数

```text
预扣 = 单价 × duration（或 duration=-1 时的探测秒数）
结算 = 单价 × 实际计费秒数
```

单价以控制台模型价格为准。
