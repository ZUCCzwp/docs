---
title: 'SP Query Asset Detail'
openapi: 'POST /api/open-api/v1/seedance/sp/assets/detail'
---

Query processing status and metadata for a single Seedance SP economy asset.

## Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `asset_id` | string | Yes | Asset ID returned from upload |

## Example

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/sp/assets/detail' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "asset_id": "asset_abc123"
  }'
```

## Response fields

| Field | Description |
|-------|-------------|
| `asset_id` | Asset ID |
| `official_id` | Upstream official ID |
| `status` | Composite status. Confirm value is `ACTIVE` before submitting video tasks |
| `name` | Asset name |
| `url` | Original asset URL when applicable |
| `image_url` | Image URL when applicable |
| `created_at` | Creation time |

## Status values

| Status | Meaning |
|--------|---------|
| `NONE` | Provider status not initialized yet; poll again |
| `UPLOADING` | Uploading to the provider asset library |
| `PROCESSING` | Provider asset is still processing |
| `ACTIVE` | Ready; can submit video tasks and use `asset://{asset_id}` |
| `FAILED` | Provider processing failed |
| `EXPIRED` | Expired and currently unavailable |
| `DELETED` | Deleted or invalidated and currently unavailable |
