</Note>
<Note>
  On success you get a `task_id`. Poll with [Query video task](/en/api-reference/common/query), then read `result.video_url`. Draft tasks also return `result.draft_cache_url` for enhance.
</Note>

## Model

Set `model` to `flux-3`. The billing name comes from the media fields. Cost is that billing name's unit price × `duration`.

| Request fields | Billing name | Output |
|----------------|--------------|--------|
| `draft_cache_url` | `flux-3-enhance` | 1080p, no `prompt` |
| `keyframes` | `flux-3-keyframes-draft` | 720p |
| `start_image_url` or `end_image_url` | `flux-3-flf-draft` | 720p |
| `image_url` | `flux-3-i2v-draft` | 720p |
| `video_url` | `flux-3-extend-draft` | 720p |
| `prompt` only | `flux-3-draft` | 720p, returns `draft_cache_url` |

When several media fields are present, the first matching row wins. Drafts are always 720p; enhance is always 1080p. **Do not send `resolution`.**

## Parameter limits

- **prompt**: required for drafts, 1–5000 chars; not used by enhance
- **duration**: 5–20 seconds (default 5); when enhancing, pass the same duration as the draft for billing
- **aspect_ratio**: `auto` / `21:9` / `2:1` / `16:9` / `4:3` / `1:1` / `3:4` / `9:16` (default `16:9`; ignored for enhance)
- **generate_audio**: optional, default `true` (ignored for enhance)
- **safety_tolerance**: 0–4, default `2`
- **keyframes**: max 10; `frame_index` must be unique and ≤ `duration * 24`

## Draft → enhance flow

1. Create with `model: "flux-3"` (always 720p); poll for `result.video_url` and `result.draft_cache_url`
2. Submit `model: "flux-3"` with `draft_cache_url` and the same `duration` (always 1080p, bills `flux-3-enhance`)
3. Poll the enhance task and read `result.video_url`

## Examples

Text-to-video draft (fixed 720p, bills `flux-3-draft`):

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "prompt": "A red panda walks along a mossy log",
    "duration": 5,
    "aspect_ratio": "16:9"
  }'
```

Draft enhance (fixed 1080p, bills `flux-3-enhance`):

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "duration": 5,
    "draft_cache_url": "https://example.com/draft-cache.bin"
  }'
```
