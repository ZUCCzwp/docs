---
title: 'Grok Imagine Image 2.0 image generation'
openapi: 'POST /api/open-api/v1/images'
---

Create an async **Grok Imagine Image 2.0** task with optional `quality` tiers (`low` / `medium`) for stronger detail and typography than the standard tier. Returns `task_id` on success — poll with [Query image task](/en/api-reference/images/query). When complete, read `result.image_url`; when `n > 1`, also use `result.image_urls`.

Standard tier: [Grok Imagine Image](/en/api-reference/images/grok-imagine-image/create).

<Note>
This model uses `POST /api/open-api/v1/images` with `"model": "grok-imagine-image-2"`.
</Note>

## Model overview

| Item | Details |
|------|---------|
| Model | `grok-imagine-image-2` (aliases `grok-imagine-image-2.0`, `grok-imagine-image-quality`) |
| API | `POST /api/open-api/v1/images` (async; pass `images` for edit mode) |
| Billing | **Resolution + quality base × `n`**; edit mode adds **reference surcharge** (from the first ref) |
| Modes | Text-to-image; pass `images` for edit (max 3 references) |
| Resolution | `1k`, `2k` (default `1k`) |
| Quality | `quality`: `low` \| `medium` (default `medium`). `low` is faster/cheaper for drafts |
| Output format | `jpeg`, `png`, `webp` (default `jpeg`) |

## Billing

| Resolution / quality | Billing model | Notes |
|---------------------|---------------|-------|
| `1k` + `low` | `grok-imagine-image-2-1k-low` | Output base (per image) |
| `1k` + `medium` | `grok-imagine-image-2-1k-medium` | Output base (per image) |
| `2k` + `low` | `grok-imagine-image-2-2k-low` | Output base (per image) |
| `2k` + `medium` | `grok-imagine-image-2-2k-medium` | Output base (per image) |
| Reference surcharge (edit only) | `grok-imagine-image-2` | When `images` is set, **every reference from the first** is billed |

If a quality-specific key is missing, billing falls back to `grok-imagine-image-2-{1k|2k}` (treated as medium), then `grok-imagine-image-2`.

Text-to-image (no references):

```text
total = resolution+quality unit price × n
```

Edit (with references):

```text
total = resolution+quality unit price × n + reference_count × reference unit price
```

Example (console prices): `2k`, `quality=medium`, `n=1` + 2 refs → `2k medium unit + 2 × reference unit`.

## Request fields

| Field | Type | Required | Description |
|------|------|----------|-------------|
| `model` | string | yes | Must be `grok-imagine-image-2` |
| `prompt` | string | yes | Prompt (1–5000 chars) |
| `ratio` | string | no | Aspect ratio. Default `1:1` for t2i; `auto` for edit |
| `resolution` | string | no | `1k` or `2k` (default `1k`) |
| `quality` | string | no | `low` or `medium` (default `medium`), 2.0 only |
| `n` | int | no | Output count, `1`–`4`, default `1` |
| `output_format` | string | no | `jpeg` / `png` / `webp`, default `jpeg` |
| `images` | string[] | no | Reference URLs (max 3); enables edit mode |

### Supported aspect ratios

Text-to-image: `2:1`, `20:9`, `19.5:9`, `16:9`, `4:3`, `3:2`, `1:1`, `2:3`, `3:4`, `9:16`, `9:19.5`, `9:20`, `1:2`.

Edit mode also supports `auto`.

## Examples

### Text-to-image (medium)

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "grok-imagine-image-2",
    "prompt": "Infographic: rainforest layers with clear typography",
    "ratio": "3:4",
    "resolution": "2k",
    "quality": "medium",
    "n": 1
  }'
```

### Text-to-image (low draft)

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "grok-imagine-image-2",
    "prompt": "Cyberpunk city at night, neon reflections",
    "resolution": "1k",
    "quality": "low",
    "n": 4
  }'
```

### Edit

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "grok-imagine-image-2",
    "prompt": "Change the sky to aurora, keep the subject",
    "images": ["https://example.com/ref.png"],
    "ratio": "auto",
    "resolution": "1k",
    "quality": "medium"
  }'
```

## Query results

When complete:

- `result.image_url` — first image URL
- `result.image_urls` — all URLs when `n ≥ 1`

Poll every 3–5 seconds.
