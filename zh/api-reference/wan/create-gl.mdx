<Note>
创建成功后会返回 `task_id`。请使用 [查询视频任务](/zh/api-reference/common/query) 接口轮询任务状态，任务完成后从 `result.video_url` 获取视频地址。
</Note>

本接口与 [创建 Wan 3.0 视频](/zh/api-reference/wan/create) 共用 `POST /api/open-api/v1/wan/videos`。通过 `model: "wan3.0-gl"` 选择本型号，独立计费。

## 支持的模型

| model | 说明 |
|-------|------|
| `wan3.0-gl` | Wan 3.0官链视频生成，支持文生视频、首帧/首尾帧生视频、参考生视频（参考图最多 10 张、参考视频最多 5 个、参考音频最多 5 段），时长 2–30 秒，分辨率 480p/720p/1080p |

本型号**不支持** `file_url` / `link_url`。需要参考文件或网页时请使用 [`wan3.0-gz`](/zh/api-reference/wan/create-gz)。

## 生成模式

| 模式 | 传参 |
|------|------|
| 文生视频 | 仅 `prompt` |
| 首帧生视频 | `first_image` |
| 首尾帧生视频 | `first_image` + `last_image` |
| 参考生视频 | `reference_images` / `reference_videos` / `reference_audios` |

首尾帧（`first_image` / `last_image`）与参考素材（参考图/视频/音频）**不能混用**。

`wan30-gl`、`wan-3.0-gl` 会归一化为 `wan3.0-gl`。也可直接传计费型号 `wan3.0-gl-480p` / `wan3.0-gl-720p` / `wan3.0-gl-1080p`，此时后缀即分辨率。

## 参数限制

- **提示词（prompt）**：与素材（首尾帧、参考图/视频/音频）至少填写一项。可用「图1」「视频1」「音频1」指代素材，编号按同类素材在数组中的顺序。
- **时长（duration）**：2–30 秒，默认 `5`。
- **画幅比例（aspect_ratio / ratio）**：`adaptive`（自适应）、`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`21:9`，默认 `16:9`。
- **分辨率（resolution）**：`480P`、`720P`、`1080P`（大小写不敏感），默认 `720P`。
- **参考图**：`reference_images` 或 `images`，最多 **10** 张，须为公网可访问 URL。
- **参考视频**：`reference_videos` 或 `videos`，最多 **5** 个，须为公网可访问 URL。
- **参考音频**：`reference_audios`，最多 **5** 段，须为公网可访问 URL。
- **首帧 / 尾帧**：`first_image` / `last_image` 各 1 张公网 URL；传 `last_image` 时必须同时传 `first_image`。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | 传 `wan3.0-gl`，或分辨率计费型号 |
| `prompt` | string | 否 | 文本提示词；未提供任何素材时必填 |
| `duration` | integer | 否 | 时长秒数，2–30，默认 5 |
| `aspect_ratio` | string | 否 | 画幅比例，优先于 `ratio` |
| `ratio` | string | 否 | `aspect_ratio` 别名 |
| `resolution` | string | 否 | 输出分辨率：`480P` / `720P` / `1080P`，默认 `720P` |
| `reference_images` | string[] | 否 | 参考图 URL 列表（0–10） |
| `images` | string[] | 否 | `reference_images` 别名（当后者为空时生效） |
| `reference_videos` | string[] | 否 | 参考视频 URL 列表（0–5） |
| `videos` | string[] | 否 | `reference_videos` 别名 |
| `reference_audios` | string[] | 否 | 参考音频 URL 列表（0–5） |
| `first_image` | string | 否 | 首帧图片 URL |
| `last_image` | string | 否 | 尾帧图片 URL，需同时传 `first_image` |

## 请求示例

### 参考生视频

```bash
curl -X POST https://api.viraltok.ai/api/open-api/v1/wan/videos \
  -H "Authorization: Bearer $JIMMYAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan3.0-gl",
    "prompt": "图1 中的人物在海边奔跑，电影感运镜",
    "duration": 5,
    "aspect_ratio": "9:16",
    "resolution": "720P",
    "reference_images": ["https://example.com/person.png"]
  }'
```

### 首尾帧生视频

```json
{
  "model": "wan3.0-gl",
  "prompt": "从微笑逐渐变为大笑，背景光线由冷变暖",
  "first_image": "https://example.com/first.png",
  "last_image": "https://example.com/last.png",
  "duration": 5
}
```

### 文生视频

```json
{
  "model": "wan3.0-gl",
  "prompt": "清晨海面，薄雾缓缓散开，电影感推镜",
  "duration": 8,
  "aspect_ratio": "21:9",
  "resolution": "1080P"
}
```

## 计费说明

- 计费方式：`per_second`（按秒）
- 请求模型名：`wan3.0-gl`（或分辨率计费型号）
- 计费模型名：`wan3.0-gl-{resolution}`（`wan3.0-gl-480p` / `wan3.0-gl-720p` / `wan3.0-gl-1080p`），不同分辨率单价不同
- 未传 `resolution` 时按 `720P` 计费
- 创建时按请求 `duration` 预扣；任务成功后按实际计费秒数多退少补
- 查询任务详情时，完成后会在 `data.usage.duration` 返回实际计费秒数

```text
预扣 = 单价 × duration
结算 = 单价 × 实际计费秒数
```

单价以控制台模型价格为准。
