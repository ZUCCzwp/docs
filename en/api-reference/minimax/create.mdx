<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status and read the final video URL from `result.video_url`.
</Note>

This page covers `minimax-h3` and `minimax-h3-768p`. For the official variant, see [Create MiniMax H3 Official Video](/en/api-reference/minimax/create-gz). `minimax-h3-768p` is a different model from the official billing ID `minimax-h3-gz-768p`.

## Supported models

| model | Notes |
|-------|-------|
| `minimax-h3` | MiniMax H3 standard. Defaults to 2K and is billed per task |
| `minimax-h3-768p` | MiniMax H3 768P. Fixed at 768P and billed per second |

Aliases for `minimax-h3`: `minimax_h3`, `minimaxh3`. Aliases for `minimax-h3-768p`: `minimax_h3_768p`, `minimaxh3768p`.

A `minimax-h3` request with `resolution: "768P"` is handled as `minimax-h3-768p`.

## minimax-h3

### Parameter constraints

- **Prompt**: Required, 1–2000 characters.
- **Duration**: 5–15 seconds (default `5`).
- **Aspect ratio** (`aspect_ratio` / `ratio`): `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9` (default `16:9`).
- **Size**: `2560x1440`, `1440x2560`, `1440x1440`, `1920x1440`, `1440x1920`, `3360x1440`. When omitted, a default matching the aspect ratio is used (e.g. `16:9` → `2560x1440`).
- **Reference images**: `reference_images` or `images`, max **5**, public URLs.
- **Reference audio**: `reference_audios`, max **1**.
- **First / last frame**: optional `first_image` / `last_image` (one each).
- This model does not support `reference_videos`. Use `minimax-h3-768p` on this page, or [`minimax-h3-gz`](/en/api-reference/minimax/create-gz), when you need video references.

### Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | Must be `minimax-h3` |
| `prompt` | string | Yes | Text prompt, 1–2000 characters |
| `duration` | integer | No | Duration in seconds, default 5 |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `size` | string | No | Output pixel size |
| `reference_images` | string[] | No | Reference image URLs (0–5) |
| `images` | string[] | No | Alias for `reference_images` when the latter is empty |
| `reference_audios` | string[] | No | Reference audio URLs (0–1) |
| `first_image` | string | No | First-frame image URL |
| `last_image` | string | No | Last-frame image URL |

### Billing

- Mode: `per_task`
- Billing model: `minimax-h3` (console price)
- `duration` controls generation length only and does not affect billing

```text
cost = unit_price
```

### Example request

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/minimax/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "minimax-h3",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 5,
    "aspect_ratio": "16:9",
    "size": "2560x1440"
  }'
```

## minimax-h3-768p

Resolution is fixed at 768P. Supports text-to-video, first/last-frame image-to-video, and reference image / video / audio.

No extra `mode` field. The inputs select the mode:

| Mode | When |
|------|------|
| Text-to-video | `prompt` and shared fields only |
| Image-to-video | `first_image` / `last_image` |
| Multimodal reference | `reference_images` / `reference_videos` / `reference_audios` |

<Warning>
`first_image` / `last_image` cannot be combined with `reference_images`, `reference_videos`, or `reference_audios`.
</Warning>

### Parameter constraints

- **Prompt**: Required, 1–7000 characters.
- **Duration**: 1–15 seconds (default `5`).
- **Resolution**: `768P` only. `model` `minimax-h3-768p` always uses `768P`.
- **Aspect ratio** (`aspect_ratio` / `ratio`): `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `adaptive` (default `16:9`).
- `adaptive` requires a first/last frame, a reference image, or a reference video. Audio-only requests must use a fixed ratio.
- **Reference images**: `reference_images` or `images`, max **9**.
- **Reference videos**: `reference_videos` or `videos`, max **3**. Duration must be greater than 0 seconds.
- **Reference audio**: `reference_audios`, max **3**.
- **First / last frame**: one URL each, mutually exclusive with reference media.
- Reference images, videos, audio, and first/last frames together max **12** items.
- This model does not use `size`.

### Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `minimax-h3-768p`. `minimax-h3` with `resolution` `768P` selects the same product |
| `prompt` | string | Yes | Text prompt, 1–7000 characters |
| `duration` | integer | No | Duration in seconds, 1–15, default 5 |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `resolution` | string | No | `768P` only |
| `reference_images` | string[] | No | Reference image URLs (0–9) |
| `images` | string[] | No | Alias for `reference_images` when the latter is empty |
| `reference_videos` | string[] | No | Reference video URLs (0–3) |
| `videos` | string[] | No | Alias for `reference_videos` when the latter is empty |
| `reference_audios` | string[] | No | Reference audio URLs (0–3) |
| `first_image` | string | No | First-frame image URL |
| `last_image` | string | No | Last-frame image URL |

### Billing

- Mode: `per_second`
- Billing model: `minimax-h3-768p` (console price)
- Billed seconds = the requested `duration` (5 when omitted)
- Reference-video length is not added to the charge

```text
cost = per-second price × duration
```

### Example request

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/minimax/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "minimax-h3-768p",
    "prompt": "The character walks with the reference video and the reference voice",
    "reference_images": ["https://example.com/char.png"],
    "reference_videos": ["https://example.com/ref_motion.mp4"],
    "reference_audios": ["https://example.com/ref_voice.mp3"],
    "duration": 5,
    "aspect_ratio": "adaptive"
  }'
```
