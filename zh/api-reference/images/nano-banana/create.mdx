---
title: '香蕉 NanoBanana 图像生成'
openapi: 'POST /api/open-api/v1/images'
---

创建 **NanoBanana** 异步图片生成任务。提交成功后返回 `task_id`，请使用 [查询图片任务](/zh/api-reference/images/query) 轮询状态；完成后从 `data.result.image_url` 获取图片地址。

<Note>
本模型使用异步接口：`POST /api/open-api/v1/images`。
将 `model` 设为以下任一值：
`nano-banana`、`nano-banana-2`、`nano-banana-pro`。
</Note>

<Warning>
同步接口 [GPT Image 2 文生图](/zh/api-reference/images/generations) 与 [GPT Image 2 编辑图片](/zh/api-reference/images/edits) 不支持 NanoBanana。
另外，不同上游线路对 `nano-banana` 支持情况可能不同：部分线路仅支持 `nano-banana-2 / nano-banana-pro`。
</Warning>

## 模型说明

| 项目 | 说明 |
|------|------|
| 模型 | `nano-banana` / `nano-banana-2` / `nano-banana-pro` |
| 计费 | 使用所选 `model` 的控制台配置单价（通常与分辨率/档位相关） |
| 模式 | 文生图、参考图生成（使用 `images`） |
| 分辨率 | `1k` / `2k` / `4k`（取决于具体变体支持） |
| 比例 | `auto`、`1:1`、`3:2`、`2:3`、`4:3`、`3:4`、`5:4`、`4:5`、`16:9`、`9:16`、`2:1`、`1:2`、`3:1`、`1:3`、`21:9`、`9:21` |

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | `nano-banana` / `nano-banana-2` / `nano-banana-pro` |
| `prompt` | string | 是 | 图像生成提示词 |
| `ratio` | string | 否 | 画面比例，默认 `auto` |
| `resolution` | string | 否 | `1k` / `2k` / `4k`（默认值取决于模型配置，常见为 `1k`） |
| `images` | string[] | 否 | 参考图 URL（或你客户端支持的 base64 Data URI） |
| `quality` | string | 否 | NanoBanana 路由一般会忽略（主要用于 gpt-image-2 / gpt-image-1.5） |
| `n` | int | 否 | 建议使用 `n=1`（查询结果只返回单个 `image_url`） |

## 示例

### 文生图

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "nano-banana-2",
    "prompt": "A studio product photo of a ceramic banana, clean background, soft lighting",
    "ratio": "1:1",
    "resolution": "2k"
  }'
```

### 参考图

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "nano-banana-pro",
    "prompt": "Keep the same style, enhance details, and change background to sunset beach",
    "ratio": "16:9",
    "resolution": "4k",
    "images": ["https://example.com/ref.png"]
  }'
```

## 响应示例

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "img_abc123",
    "status": "queued",
    "model": "nano-banana-2",
    "created_at": 1710000000
  }
}
```

## 查询任务

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/images/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

当 `status` 变为 `completed` 后，从 `data.result.image_url` 获取图片地址。

<Note>
图片下载地址保存约 **3 天** — 请及时下载或转存。
</Note>
