---
title: 'Grok Imagine Image 2.0 图像生成'
openapi: 'POST /api/open-api/v1/images'
---

创建 **Grok Imagine Image 2.0** 高质量异步图片生成任务。支持 `quality` 档位（`low` / `medium`），细节与排版表现优于标准版。提交成功后返回 `task_id`，请使用 [查询图片任务](/zh/api-reference/images/query) 轮询状态，完成后从 `result.image_url` 获取图片地址；当 `n > 1` 时还可从 `result.image_urls` 获取全部图片。

标准版见 [Grok Imagine Image](/zh/api-reference/images/grok-imagine-image/create)。

<Note>
本接口使用 `POST /api/open-api/v1/images`。将 `model` 设为 `grok-imagine-image-2` 即可使用本模型。
</Note>

## 模型说明

| 项目 | 说明 |
|------|------|
| 模型名 | `grok-imagine-image-2`（别名 `grok-imagine-image-2.0`、`grok-imagine-image-quality`） |
| 接口 | `POST /api/open-api/v1/images`（异步；传入 `images` 时进入编辑模式） |
| 计费 | **分辨率 + quality 基础价 × `n`**；图生图另加 **参考图加收**（从第 1 张起） |
| 模式 | 文生图；传入 `images` 时为图编辑（最多 3 张参考图） |
| 分辨率 | `1k`、`2k`（默认 `1k`） |
| 画质 | `quality`: `low` \| `medium`（默认 `medium`）。`low` 更快更省，适合试 prompt |
| 输出格式 | `jpeg`、`png`、`webp`（默认 `jpeg`） |

## 计费说明

| 分辨率 / quality | 计费模型名 | 说明 |
|-----------------|-----------|------|
| `1k` + `low` | `grok-imagine-image-2-1k-low` | 输出基础价（按张） |
| `1k` + `medium` | `grok-imagine-image-2-1k-medium` | 输出基础价（按张） |
| `2k` + `low` | `grok-imagine-image-2-2k-low` | 输出基础价（按张） |
| `2k` + `medium` | `grok-imagine-image-2-2k-medium` | 输出基础价（按张） |
| 参考图加收（仅图生图） | `grok-imagine-image-2` | 传入 `images` 时，**从第 1 张起**每张加收 |

未配置带 `quality` 后缀的价目时，会依次回退到 `grok-imagine-image-2-{1k|2k}`（视为 medium），再回退到 `grok-imagine-image-2`。

文生图（无参考图）：

```text
总费用 = 分辨率+quality 单价 × n
```

图生图 / 编辑（有参考图）：

```text
总费用 = 分辨率+quality 单价 × n + 参考图数量 × 参考图单价
```

示例（以控制台当前报价为准）：`2k`、`quality=medium`、`n=1` + 2 张参考图 → `2k medium 单价 + 2 × 参考图单价`。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | 固定为 `grok-imagine-image-2` |
| `prompt` | string | 是 | 图像生成 / 编辑提示词（1–5000 字符） |
| `ratio` | string | 否 | 画面比例。文生图默认 `1:1`；编辑模式默认 `auto` |
| `resolution` | string | 否 | `1k` 或 `2k`（默认 `1k`） |
| `quality` | string | 否 | `low` 或 `medium`（默认 `medium`），仅 2.0 生效 |
| `n` | int | 否 | 生成张数，`1`–`4`，默认 `1` |
| `output_format` | string | 否 | `jpeg` / `png` / `webp`，默认 `jpeg` |
| `images` | string[] | 否 | 参考图 URL（最多 3 张）；传入后走编辑模式 |

### 支持的比例

文生图：`2:1`、`20:9`、`19.5:9`、`16:9`、`4:3`、`3:2`、`1:1`、`2:3`、`3:4`、`9:16`、`9:19.5`、`9:20`、`1:2`。

编辑模式额外支持 `auto`。

## 示例

### 文生图（medium）

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "grok-imagine-image-2",
    "prompt": "信息图：热带雨林分层剖面，清晰排版与标注",
    "ratio": "3:4",
    "resolution": "2k",
    "quality": "medium",
    "n": 1
  }'
```

### 文生图（low，草稿）

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "grok-imagine-image-2",
    "prompt": "赛博朋克城市夜景，霓虹反射",
    "resolution": "1k",
    "quality": "low",
    "n": 4
  }'
```

### 图编辑

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "grok-imagine-image-2",
    "prompt": "把天空改成极光，保持主体不变",
    "images": ["https://example.com/ref.png"],
    "ratio": "auto",
    "resolution": "1k",
    "quality": "medium"
  }'
```

## 查询结果

完成后：

- `result.image_url`：第一张图的访问地址
- `result.image_urls`：全部图片地址数组（`n ≥ 1`）

建议每 3–5 秒轮询一次。
