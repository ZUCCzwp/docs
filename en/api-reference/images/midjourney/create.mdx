title: 'Midjourney text-to-image'
---

Create an async **Midjourney** Imagine task. The response includes a `task_id`. Poll [Query image task](/en/api-reference/images/query) (`GET /api/open-api/v1/images/{taskId}`) until `status=completed`, then read `result.image_urls` and `result.buttons`.

Follow-up actions: [Upscale / variation / expand](/en/api-reference/images/midjourney/actions). Image-to-video: [Create Midjourney image-to-video](/en/api-reference/images/midjourney/video).

<Note>
Use `POST /api/open-api/v1/midjourney/generations` (same as `/generations/imagine`). Do not send `model` in the body.

Do not post Midjourney to `POST /api/open-api/v1/images`.
</Note>

## Overview

| Item | Value |
|------|------|
| Model | `midjourney` |
| Endpoint | `POST /api/open-api/v1/midjourney/generations` |
| Billing | See billing reference below |
| Speed | `relax` (default) / `fast` / `turbo` |
| Version | `8.2` / `8.1` / `7` / `6.1` / `5.2` / `5.1`; `niji=true` + `7` / `6` → `niji7` / `niji6` |

## Billing reference

Prices come from the console. `fast` uses the same price as the regular speed. Image actions with `speed=turbo` use `midjourney-turbo`, which is higher than the regular price. Failed tasks are refunded.

| Billing model | Covers |
|---------------|--------|
| `midjourney` | Regular price and `fast` for Imagine, describe, upscale, blend, edits, variation, reroll, zoom, pan, inpaint, and remix |
| `midjourney-turbo` | `speed=turbo` for those image actions |
| `midjourney-video` | Image-to-video 480p, × `batch_size` |
| `midjourney-video-720p` | Image-to-video 720p, × `batch_size` |

A more specific version or speed price in the console wins over this table.

## Request fields

| Field | Type | Required | Description |
|------|------|------|------|
| `prompt` | string | yes | Prompt; native MJ flags such as `--ar 16:9` are allowed |
| `images` | string[] | no | Reference images (`image_urls` alias) |
| `size` | string | no | Aspect ratio (`ratio` alias) |
| `speed` | string | no | `relax` / `fast` / `turbo` |
| `version` | string | no | Body overrides the same flag in `prompt` |

See the Chinese page for the full structured-parameter list.

## Example

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/midjourney/generations' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "prompt": "a cute cat, watercolor style",
    "size": "16:9",
    "version": "6.1",
    "speed": "fast"
  }'
```
