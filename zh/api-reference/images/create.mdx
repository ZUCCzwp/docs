---
title: 'GPT Image 2 图像生成'
openapi: 'POST /api/open-api/v1/images'
---

创建 **GPT Image 2** 异步图片生成任务。提交成功后返回 `task_id`，请使用 [查询图片任务](/zh/api-reference/images/query) 轮询状态，完成后从 `result.image_url` 获取图片地址。

<Note>
接口路径：`POST /api/open-api/v1/images`，将 `model` 设为 `gpt-image-2`。

其他异步图片模型见：[GPT Image 1.5](/zh/api-reference/images/gpt-image-1.5/create)、[Seedream 5.0 Pro](/zh/api-reference/images/seedream-5-0-pro/create)、[NanoBanana](/zh/api-reference/images/nano-banana/create)。

若需 **OpenAI 兼容同步**接口，请使用 [GPT Image 2 文生图](/zh/api-reference/images/generations) 或 [GPT Image 2 编辑图片](/zh/api-reference/images/edits)（生图直连：`https://img.viraltok.ai`）。
</Note>

## 模型说明

| 项目 | 说明 |
|------|------|
| 模型名 | `gpt-image-2` |
| 计费 | **画质档位单价 × 张数 `n`**（异步） |
| 模式 | 文生图、参考图生图（`images`） |
| 比例 | `ratio`（如 `1:1`、`16:9`），默认 `auto` |
| 分辨率 | `resolution`：`1k` / `2k` / `4k` |
| 画质 | `quality`：`auto` / `low` / `medium` / `high` |

## 计费说明（异步）

| 画质 `quality` | 计费模型名 | 说明 |
|----------------|-----------|------|
| 空 / `auto` | `gpt-image-2` | 默认档 |
| `low` | `gpt-image-2-low` | 更快、更省 |
| `medium` | `gpt-image-2-medium` | 折中 |
| `high` | `gpt-image-2-high` | 更高质量 |

费用公式：

```text
总费用 = 画质档位单价 × n
```

单价以控制台 / 定价页为准。若带后缀的计费型号未配置，会回退到基础价 `gpt-image-2`。

<Info>
同步 generations/edits 使用独立计费型号 `gpt-image-2-sync` / `gpt-image-2-sync-{quality}`，详见 [GPT Image 2 文生图](/zh/api-reference/images/generations)。
</Info>

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | 固定为 `gpt-image-2` |
| `prompt` | string | 是 | 图像生成提示词 |
| `ratio` | string | 否 | 画面比例，默认 `auto`；支持常见比例如 `1:1`、`16:9`、`9:16` 等 |
| `resolution` | string | 否 | `1k` / `2k` / `4k`，默认 `1k` |
| `quality` | string | 否 | `auto` / `low` / `medium` / `high` |
| `n` | int | 否 | 生成张数，默认 `1` |
| `images` | string[] | 否 | 参考图 URL 列表 |

<Warning>
`resolution=4k` 时，部分比例可能不受支持；常见可用比例包括 `16:9` / `9:16` / `2:1` / `1:2` / `21:9` / `9:21`。
</Warning>

## 示例

### 文生图

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "gpt-image-2",
    "prompt": "赛博朋克城市雨夜，霓虹招牌特写，电影画幅",
    "ratio": "16:9",
    "resolution": "2k",
    "quality": "auto",
    "n": 1
  }'
```

### 参考图生图

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "gpt-image-2",
    "prompt": "保持主体轮廓，换成日落海滩背景",
    "ratio": "1:1",
    "resolution": "1k",
    "quality": "high",
    "images": ["https://example.com/ref.png"]
  }'
```

## 响应示例

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "img_abc123",
    "status": "queued",
    "model": "gpt-image-2",
    "created_at": 1710000000
  }
}
```

## 查询任务

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/images/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

任务状态：`queued` → `processing` → `completed` / `failed`。完成后从 `data.result.image_url` 获取图片地址。

<Note>
图片结果 URL 保存约 **3 天**，请及时转存。
</Note>
