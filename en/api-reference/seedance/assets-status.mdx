---
title: 'Query Asset Audit Status'
openapi: 'POST /api/open-api/v1/seedance/assets/status'
---

Check audit status for submitted assets (full / Manxue route). Do not use an `asset_id` in video creation until status is `Active`.

## Example

```bash
curl -X POST 'https://www.jimmyai.cn/api/open-api/v1/seedance/assets/status' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "asset_ids": ["asset-id-1", "asset-id-2"]
  }'
```

## Status values

| Status | Meaning |
|--------|---------|
| `Pending` | Under review |
| `Active` | Approved; use as `asset://{asset_id}` |
| `Failed` / `Rejected` | Rejected; resubmit if needed |
