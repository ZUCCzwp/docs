<Note>
**备注（兼容路径）**：旧接口 `/api/open-api/v1/super-resolution/videos` 仍可调用，行为与 `POST /api/v1/videos` 相同；新接入请优先使用统一入口。
</Note>


创建视频超分任务，将公网可访问的低分辨率视频增强为更高清视频。提交成功后返回 `task_id`，请使用 [查询视频任务](/zh/api-reference/common/query) 轮询状态，完成后从 `result.video_url` 获取结果。

## 模型

请求 `model` 固定为 `superResolution`。目标清晰度用 `resolution`，帧率档位用 `fps`。

| 字段 | 取值 | 默认 | 计费名 |
|------|------|------|--------|
| `resolution` | `720p`、`1080p`、`2k`、`4k` | `1080p` | |
| `fps` | `lowfps`（30 FPS）、`highfps`（120 FPS） | `lowfps` | `superResolution-{resolution}-{fps}` |

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | `superResolution` |
| `video_url` | string | 是 | 待超分视频的公网 URL，任务处理期间须保持可访问 |
| `resolution` | string | 否 | `720p`、`1080p`（默认）、`2k`、`4k` |
| `fps` | string | 否 | `lowfps`（默认，30 FPS）或 `highfps`（120 FPS） |

## 计费说明

- 计费方式：`per_second`（按秒）
- 能解析 `video_url` 时，按 `ceil(时长)` 预扣（不足 1 秒按 1 秒）
- 解析不到时长时，先按 15 秒预扣
- 任务完成后按成片实际时长向上取整结算，预扣差额多退少补
- 单价：以控制台中计费名 `superResolution-{resolution}-{fps}` 为准

```text
费用 = 模型单价 × ceil(实际视频时长秒数)
```

## 示例

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "superResolution",
    "resolution": "1080p",
    "fps": "lowfps",
    "video_url": "https://example.com/input-low-resolution.mp4"
  }'
```

## 响应示例

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "video_task_1234567890",
    "status": "queued",
    "model": "superResolution-1080p-lowfps",
    "created_at": 1782529105,
    "cost": 0.4
  }
}
```

## 查询任务

```bash
curl -X GET 'https://api.viraltok.ai/api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

建议每 5–10 秒轮询一次，状态变为 `completed` / `failed` 后停止。结果 URL 保存约 **3 天**，请及时转存。
