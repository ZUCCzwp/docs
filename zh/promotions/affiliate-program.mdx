**联盟推广计划**面向愿意向受众推荐 ViraltokAI 的创作者与开发者。审核通过后，您将获得专属邀请链接与邀请海报；好友通过链接注册并完成充值，您可在其前若干次充值中获得**邀请返利**（吉米币）。

<Card title="前往控制台申请" icon="arrow-up-right-from-square" href="https://api.viraltok.ai/console?tab=affiliate">
  打开控制台 → **联盟推广** 标签页
</Card>

---

## 活动规则摘要

| 项目 | 说明 |
| :--- | :--- |
| **邀请人数** | 不设上限 |
| **返利触发** | 被邀请好友每次成功充值吉米币 |
| **返利次数** | 每位好友的前 **N** 次充值（默认 **3** 次，以您的推广等级为准） |
| **返利比例** | 好友当次充值吉米币 × 您的**邀请返利比例**（%），由审核时分配的推广等级决定 |
| **返利到账** | 进入**可划转余额**，需手动划转到账户吉米币后用于 API 消费 |
| **邀请链接** | `https://api.viraltok.ai/register?invite=<您的邀请码>` |

<Warning>
返利比例、返利次数与推广等级由平台审核配置，**不同推广员可能不同**。请勿对外承诺固定比例；以控制台审核通过后的显示为准。
</Warning>

## 如何申请

在 [控制台 · 联盟推广](https://api.viraltok.ai/console?tab=affiliate) 填写以下信息：

<Steps>
<Step title="选择推广渠道（可多选）">
  可选：**抖音、小红书、B 站、YouTube、Twitter/X、Telegram、微信、其他**。请选择您**实际运营**的渠道。
</Step>

<Step title="填写社媒账号链接">
  至少一条可访问的主页或账号链接（如 `https://…`）。用于核实推广能力。
</Step>

<Step title="撰写推广计划">
  说明您打算如何向受众介绍 ViraltokAI（见下方模板与建议）。
</Step>

<Step title="上传账号证明截图">
  社媒后台、粉丝数据或代表性内容截图，证明账号为您本人运营。
</Step>

<Step title="留下联系方式">
  邮箱、Telegram、微信等，便于审核沟通。
</Step>

<Step title="提交并等待审核">
  状态为「审核中」时请耐心等待。通过后平台会邮件通知（若邮箱可用），控制台状态变为「已通过」。
</Step>
</Steps>

## 推广计划怎么写

审核会重点看：**受众是否匹配**、**计划是否可执行**、**是否了解 ViraltokAI 产品**。

### 建议包含的内容

1. **受众**：开发者 / 短视频创作者 / 电商团队等
2. **渠道与形式**：教程视频、图文测评、直播演示、社群答疑、开源 Demo 等
3. **推广重点**：例如 Sora/Seedance 视频 API、GPT Image、LLM（Codex 集成）等
4. **更新频率**：周更、系列专栏、活动期集中推广等
5. **合规说明**：标注 API 按量计费、需自行充值吉米币等

### 示例（可改写）

```text
我主要在 B 站与 Telegram 开发者群运营，受众为独立开发者与 AI 应用爱好者。
计划在未来 4 周内发布 2 期 ViraltokAI 实战视频：一期讲解 Open API 视频生成与任务查询，
一期讲解 Codex + ViraltokAI LLM 接入（Responses API）。
每期附带 GitHub 示例仓库与文档链接，并在社群答疑。
推广内容会明确标注按量计费与官方文档地址，不使用夸大宣传。
```

### 不建议的内容

- 空白或一句话应付（如「随便推广一下」）
- 承诺固定返利比例或「稳赚」类表述
- 与所选渠道无关的计划（选了 YouTube 却只写微信群）

## 审核通过后做什么

1. 在控制台复制 **专属邀请链接**，或下载 **邀请海报** 分享
2. 引导好友通过链接 **注册**（注册页可带邀请码）
3. 好友 **充值吉米币** 后，您在其前 N 次充值中获得返利
4. 在「返利明细」查看每笔记录
5. 将 **可划转余额** 划转到账户吉米币，用于 API 调用

### 划转返利

返利不会自动进入消费余额。在控制台点击 **划转到账户余额**，将可划转余额转为吉米币后即可调用 API。

## 推广等级

平台按推广能力配置不同 **推广等级**（如 Starter、Trainee、Ambassador 等）。每个等级对应：

- **邀请返利比例**（%）
- **好友返利充值次数**（前 N 次）

审核通过时确定等级；后续平台也可能根据表现**调级**。等级名称与比例以控制台为准。

## 数据统计

推广员可在控制台查看：

| 指标 | 含义 |
| :--- | :--- |
| 总邀请数 | 通过您的邀请码注册的用户数 |
| 总充值 | 被邀请好友累计充值吉米币 |
| 总返现 | 您累计获得的邀请返利 |
| 可划转余额 | 尚未划转到消费余额的返利 |

## 常见问题

<AccordionGroup>
<Accordion title="任何人都能申请吗？">
  需有真实、可验证的推广渠道与计划。平台保留拒绝虚假或低质量申请的权利。
</Accordion>

<Accordion title="好友必须用邀请链接注册吗？">
  是。只有携带您邀请码完成注册的用户，才会计入您的邀请关系并产生返利。
</Accordion>

<Accordion title="返利比例是固定的吗？">
  不是。由审核时分配的推广等级决定，且平台可能调整等级配置。以控制台显示为准。
</Accordion>

<Accordion title="第 4 次充值还有返利吗？">
  默认仅前 **3** 次。若您的等级配置了不同的 N，以控制台「好友返利充值次数」为准。
</Accordion>

<Accordion title="返利可以直接提现吗？">
  当前返利划转为**吉米币**，用于 ViraltokAI Open API 消费，不支持直接提现到银行卡。
</Accordion>

<Accordion title="推广 ViraltokAI 时要注意什么？">
  请如实介绍按量计费与模型能力，勿夸大效果；勿在文档或宣传中泄露内部渠道信息。对外请使用 [公开 API 文档](/zh/api-reference/introduction) 与 [模型定价](/zh/api-reference/common/model-catalog)。
</Accordion>
</AccordionGroup>
