---
title: 'Query Image Task'
openapi: 'GET /api/v1/images/{taskId}'
---

<Note>
**Note (compatibility)**: `GET /api/open-api/v1/images/{taskId}` still works and matches `GET /api/v1/images/{taskId}`.
</Note>

> [!IMPORTANT]
> The image download URL (`image_url`) is valid for **3 days**. Please download or transfer it in time.

The response field `data.cost` is the billed amount for this task (JimiCoin). It is returned on both create and query endpoints.
