<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status, read the video URL from `result.video_url`, and read `completion_tokens` / `total_tokens` from `data.usage`.
</Note>

This uses the same endpoint as [Create Seedance 2.5 Official Channel Video](/en/api-reference/seedance/25/create): `POST /api/open-api/v1/seedance25/videos`. Select this product with `model: "seedance2.5-dreamina"`.

<Warning>
Do **not** call `/api/open-api/v1/seedance/videos` (Seedance 2.0 / Full routes). That would land on the Full channel.
</Warning>

## Supported models

| model | Notes |
|-------|-------|
| `seedance2.5-dreamina` | Seedance 2.5 Dreamina: independent billing; text-to-video plus reference images / videos / audios |

Aliases such as `seedance-2.5-dreamina` and `seedance25-dreamina` normalize to `seedance2.5-dreamina`. Billing names `seedance2.5-480p-dreamina`, `seedance2.5-720p-dreamina`, and `seedance2.5-1080p-dreamina` are also accepted.

## Parameter constraints

- **Prompt**: Required, 1–5000 characters.
- **Duration**: 5–30 seconds. Default `5` when omitted.
- **Aspect ratio** (`aspect_ratio` / `ratio`): `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `adaptive`. Default `16:9`.
- **Resolution**: `480p`, `720p`, `1080p` (default `720p`).
- **Reference images**: max **30**.
- **Reference videos**: max **10**.
- **Reference audios**: max **10**.
- **generate_audio**: default `true`.
- **Not supported**: `first_image` / `last_image` and `omni_reference_task_type`.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `seedance2.5-dreamina`, or a matching billing name |
| `prompt` | string | Yes | Text prompt |
| `duration` | integer | No | Duration in seconds, default `5` |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `resolution` | string | No | `480p` / `720p` / `1080p`, default `720p` |
| `reference_images` | string[] | No | Reference image URLs (0–30) |
| `images` | string[] | No | Alias for `reference_images` |
| `reference_videos` | string[] | No | Reference video URLs (0–10) |
| `videos` | string[] | No | Alias for `reference_videos` |
| `reference_audios` | string[] | No | Reference audio URLs (0–10) |
| `audios` | string[] | No | Alias for `reference_audios` |
| `generate_audio` | boolean | No | Generate audio; default `true` |

## Billing

Creation precharges by resolution. After the task succeeds, usage is settled from actual tokens (overage charged / unused refunded in one delta). Tasks with reference videos use different precharge and per-million-token prices (JimiCoin; Console-configurable).

- Precharge mode: `per_second`
- Precharge models: `seedance2.5-480p-dreamina` / `seedance2.5-720p-dreamina` / `seedance2.5-1080p-dreamina`
- With reference videos: `seedance2.5-video-480p-dreamina` / `seedance2.5-video-720p-dreamina` / `seedance2.5-video-1080p-dreamina`
- Settlement models: `seedance2.5-480p-dreamina-token` / `seedance2.5-720p-dreamina-token` / `seedance2.5-1080p-dreamina-token`
- With reference videos: `seedance2.5-video-480p-dreamina-token` / `seedance2.5-video-720p-dreamina-token` / `seedance2.5-video-1080p-dreamina-token`
- With reference videos, precharge seconds = **output duration + reference video duration**

```text
precharge = unit price × precharge seconds
due JimiCoin = completion_tokens / 1,000,000 × per-million-token price
after success, charge or refund the delta vs precharge
```

## Example request

### Text to video

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance25/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-dreamina",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 5,
    "aspect_ratio": "16:9",
    "resolution": "480p"
  }'
```

### Multimodal references

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance25/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-dreamina",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 8,
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "reference_images": ["https://example.com/reference.png"],
    "reference_videos": ["https://example.com/reference.mp4"],
    "reference_audios": ["https://example.com/reference.mp3"]
  }'
```
