---
title: 'Create Nano Banana Image'
api: 'POST /api/open-api/v1/images'
---

Create a new image generation task using Nano Banana models.

## Request Body

<ParamField body="model" type="string" required>
  Model name. Use `nano-banana-2` or `nano-banana`.
</ParamField>

<ParamField body="prompt" type="string" required>
  The text prompt to generate the image.
</ParamField>

<ParamField body="size" type="string">
  Image aspect ratio/size. Supported values: `1:1`, `3:2`, `2:3`, `4:3`, `3:4`, `16:9`, `9:16`.
  
  Default: `auto`
</ParamField>

<ParamField body="images" type="array">
  List of reference image URLs (supports single image).
</ParamField>
