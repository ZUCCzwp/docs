<Note>
**Note (compatibility)**: The legacy path `/api/open-api/v1/super-resolution/videos` still works and matches `POST /api/v1/videos`; prefer the unified endpoint for new integrations.
</Note>


Create a video super-resolution task that enhances a publicly accessible low-resolution video. After submission you receive a `task_id`. Poll via [Query Video Task](/en/api-reference/common/query) and read `result.video_url` when completed.

## Model

Set `model` to `superResolution`. Choose the target with `resolution` and the frame-rate tier with `fps`.

| Field | Values | Default | Billing name |
|-------|--------|---------|--------------|
| `resolution` | `720p`, `1080p`, `2k`, `4k` | `1080p` | |
| `fps` | `lowfps` (30 FPS), `highfps` (120 FPS) | `lowfps` | `superResolution-{resolution}-{fps}` |

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `superResolution` |
| `video_url` | string | Yes | Public URL of the source video; must remain accessible while processing |
| `resolution` | string | No | `720p`, `1080p` (default), `2k`, `4k` |
| `fps` | string | No | `lowfps` (default, 30 FPS) or `highfps` (120 FPS) |

## Billing

- Mode: `per_second`
- When `video_url` duration can be read, precharge `ceil(duration)` seconds (minimum 1)
- When duration cannot be read, precharge 15 seconds
- After the task completes, settle to `ceil(actual duration)` and refund or charge the difference
- Unit price: console price for billing name `superResolution-{resolution}-{fps}`

```text
cost = unit_price × ceil(actual_video_duration_seconds)
```

## Example

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "superResolution",
    "resolution": "1080p",
    "fps": "lowfps",
    "video_url": "https://example.com/input-low-resolution.mp4"
  }'
```

## Response example

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "video_task_1234567890",
    "status": "queued",
    "model": "superResolution-1080p-lowfps",
    "created_at": 1782529105,
    "cost": 0.4
  }
}
```

## Query task

```bash
curl -X GET 'https://api.viraltok.ai/api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

Poll every 5–10 seconds until `completed` or `failed`. Result URLs are kept about **3 days** — download promptly.
