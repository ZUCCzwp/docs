**备注（兼容路径）**：旧接口 `/api/open-api/v1/seedance25/videos` 仍可调用，行为与 `POST /api/v1/videos` 相同；新接入请优先使用统一入口。
</Note>


<Note>
创建成功后会返回 `task_id`。请使用 [查询视频任务](/zh/api-reference/common/query) 接口轮询任务状态，任务完成后从 `result.video_url` 获取视频地址，并从 `data.usage` 读取 `completion_tokens` / `total_tokens`。
</Note>

本接口与 [创建 Seedance 2.5官链视频](/zh/api-reference/seedance/25/create) 共用 `POST /api/v1/videos`。通过 `model: "seedance2.5-dreamina"` 选择本型号。

<Warning>
**不要**调用 `/api/v1/videos`（那是 Seedance 2.0 / 满血等线路）。误用会落到满血渠道。
</Warning>

## 支持的模型

| model | 说明 |
|-------|------|
| `seedance2.5-dreamina` | Seedance 2.5 Dreamina：独立计费；文生视频、参考图 / 视频 / 音频，以及视频编辑 |

`seedance-2.5-dreamina`、`seedance25-dreamina` 等别名会归一化为 `seedance2.5-dreamina`。也可直接传计费名：`seedance2.5-480p-dreamina`、`seedance2.5-720p-dreamina`、`seedance2.5-1080p-dreamina`。

## 参数限制

- **提示词（prompt）**：必填，长度 1–5000。
- **时长（duration）**：5–30 秒。未传默认 `5`。视频编辑（`edit`）必须为 `-1`；未传时自动补 `-1`。
- **画幅比例（aspect_ratio / ratio）**：`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`21:9`、`adaptive`。未传默认 `16:9`。`edit` / `extend` 未传时自动补 `adaptive`。
- **分辨率（resolution）**：`480p`、`720p`、`1080p`，默认 `720p`。
- **参考图**：最多 **30** 张。
- **参考视频**：最多 **10** 条。单条与合计时长均不超过 30.2 秒。
- **参考音频**：最多 **10** 条。
- **generate_audio**：默认 `true`。
- **不支持** `first_image` / `last_image`。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | 固定传 `seedance2.5-dreamina`，或对应计费名 |
| `prompt` | string | 是 | 文本提示词 |
| `duration` | integer | 否 | 时长秒数，默认 `5` |
| `aspect_ratio` | string | 否 | 画幅比例，优先于 `ratio` |
| `ratio` | string | 否 | `aspect_ratio` 别名 |
| `resolution` | string | 否 | `480p` / `720p` / `1080p`，默认 `720p` |
| `reference_images` | string[] | 否 | 参考图 URL（0–30） |
| `images` | string[] | 否 | `reference_images` 别名 |
| `reference_videos` | string[] | 否 | 参考视频 URL（0–10） |
| `videos` | string[] | 否 | `reference_videos` 别名 |
| `reference_audios` | string[] | 否 | 参考音频 URL（0–10） |
| `audios` | string[] | 否 | `reference_audios` 别名 |
| `generate_audio` | boolean | 否 | 是否生成配音，默认 `true` |
| `omni_reference_task_type` | string | 否 | 任务类型引导：`auto` / `reference` / `edit` / `extend`。带参考素材时可用 |

## 任务类型引导

带参考素材时，可用 `omni_reference_task_type` 显式声明这次要做哪种子任务。它把子任务的参数校验提前到提交阶段，让不合法的组合当场报错，而不是任务跑起来之后才失败。

| 取值 | 用途 | 约束 |
|------|------|------|
| `auto` | 默认行为，由模型自行判定参考生视频 / 编辑 / 延长 | 时长仍为 5–30 秒 |
| `reference` | 参考生视频：依据参考图 / 视频 / 音频生成新视频 | 比例与时长无额外限制 |
| `edit` | 视频编辑：替换主体、增删对象、局部重绘 | 须含至少 1 个公网 `reference_videos`；`aspect_ratio` 须为 `adaptive`；`duration` 须为 `-1`；提示词需含「编辑 / 增加 / 删除 / 修改 / 替换」一类动词 |
| `extend` | 视频延长：向前或向后续写 | 须含 `reference_videos`；`aspect_ratio` 须为 `adaptive`；时长仍为 5–30 秒；提示词需含「延长 / 延续 / 续写」一类动词 |

为省去重复填写，`edit` 未传 `aspect_ratio` 时自动补 `adaptive`、未传 `duration` 时自动补 `-1`，`extend` 未传 `aspect_ratio` 时自动补 `adaptive`。

不传该字段时按普通生成处理。首尾帧字段不要传。

## 计费说明

创建时按分辨率预扣（是否含参考视频不影响预扣型号）。任务成功后按实际 token 用量结算，多退少补，差额记一笔。含参考视频与不含参考视频使用不同的百万 token 单价（吉米币，控制台可配）。

`edit` 的 `duration` 为 `-1`，创建阶段还不知道输出时长，预扣秒数按参考视频时长向上取整，并限定在 4–30 秒。参考视频须是可直接访问、能读出时长的公网 mp4；读不到时长会在创建阶段直接报错。成功后仍按实际 token 结算。

- 预扣方式：`per_second`
- 预扣模型：`seedance2.5-480p-dreamina` / `seedance2.5-720p-dreamina` / `seedance2.5-1080p-dreamina`
- 结算模型：`seedance2.5-480p-dreamina-token` / `seedance2.5-720p-dreamina-token` / `seedance2.5-1080p-dreamina-token`
- 带参考视频时结算改为 `seedance2.5-video-480p-dreamina-token` / `seedance2.5-video-720p-dreamina-token` / `seedance2.5-video-1080p-dreamina-token`

```text
预扣 = 对应单价 × 预扣秒数
应付吉米币 = completion_tokens / 1,000,000 × 百万 token 单价
成功后按应付与预扣差额多退少补
```

## 示例请求

### 文生视频

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-dreamina",
    "prompt": "电影感产品展示，自然光，缓慢推镜",
    "duration": 5,
    "aspect_ratio": "16:9",
    "resolution": "480p"
  }'
```

### 多模态参考

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-dreamina",
    "prompt": "电影感产品展示，自然光，缓慢推镜",
    "duration": 8,
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "reference_images": ["https://example.com/reference.png"],
    "reference_videos": ["https://example.com/reference.mp4"],
    "reference_audios": ["https://example.com/reference.mp3"]
  }'
```

### 视频编辑

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-dreamina",
    "prompt": "给画面加一群飞鸟",
    "omni_reference_task_type": "edit",
    "aspect_ratio": "adaptive",
    "duration": -1,
    "resolution": "720p",
    "reference_videos": ["https://example.com/reference.mp4"]
  }'
```
