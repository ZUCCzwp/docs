---
title: 'Midjourney 二次操作'
---

对已完成的 Imagine / Variation 任务做放大、变体、扩图、局部重绘等。均返回新的 `task_id`，用 [查询图片任务](/zh/api-reference/images/query) 轮询：`GET /api/open-api/v1/images/{taskId}`。Describe 完成后读 `result.descriptions`。

<Note>
`task_id` 传本平台返回的任务 ID（`task_...`），不要传上游 ID。系统会自动映射。
</Note>

## 接口一览

| 功能 | 路径 | 计费 |
|------|------|------|
| 多图融合 | `POST /api/open-api/v1/midjourney/generations/blend` | `midjourney` |
| 图生文 | `POST /api/open-api/v1/midjourney/generations/describe` | `midjourney` |
| 图片编辑 | `POST /api/open-api/v1/midjourney/generations/edits` | `midjourney` |
| 放大选图 | `POST /api/open-api/v1/midjourney/generations/upscale` | `midjourney` |
| 变体 | `POST /api/open-api/v1/midjourney/generations/variation` | `midjourney` |
| 强变体 | `POST /api/open-api/v1/midjourney/generations/high-variation` | `midjourney` |
| 弱变体 | `POST /api/open-api/v1/midjourney/generations/low-variation` | `midjourney` |
| 重新生成 | `POST /api/open-api/v1/midjourney/generations/reroll` | `midjourney` |
| 缩放扩图 | `POST /api/open-api/v1/midjourney/generations/zoom` | `midjourney` |
| 平移扩图 | `POST /api/open-api/v1/midjourney/generations/pan` | `midjourney` |
| 局部重绘入口 | `POST /api/open-api/v1/midjourney/generations/inpaint` | `midjourney` |
| Modal 补参 | `POST /api/open-api/v1/midjourney/generations/modal` | `midjourney` |
| 强重塑 | `POST /api/open-api/v1/midjourney/generations/remix-strong` | `midjourney` |
| 弱重塑 | `POST /api/open-api/v1/midjourney/generations/remix-subtle` | `midjourney` |

表中是普通价，`fast` 与此相同。`speed=turbo` 改为 `midjourney-turbo`，高于普通价。图生文、放大选图也按是否 turbo 计价。完整对照见 [计费参考](/zh/api-reference/images/midjourney/create#计费参考)。Remix 仅 v8.1 / v8.2。

## 公共字段

| 字段 | 说明 |
|------|------|
| `task_id` | 父任务 ID（须已完成） |
| `index` | 选第几张，范围 `1`–`4` |
| `custom_id` | 查询结果里 `buttons[].customId`，与 `index` 二选一，传了它优先 |
| `speed` | `relax` / `fast` / `turbo` |

## 示例

### 放大第 1 张

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/midjourney/generations/upscale' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{"task_id": "task_xxx", "index": 1}'
```

### 变体

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/midjourney/generations/variation' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{"task_id": "task_xxx", "index": 3, "speed": "turbo"}'
```

### Blend

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/midjourney/generations/blend' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "images": ["https://example.com/a.png", "https://example.com/b.png"],
    "size": "16:9",
    "speed": "fast"
  }'
```

Blend 需要 2–4 张图，不支持 `prompt`。可用 `dimensions`：`SQUARE` / `PORTRAIT` / `LANDSCAPE`，`size` 优先。

### Edits

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/midjourney/generations/edits' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "prompt": "replace the background with a modern kitchen, keep the product unchanged",
    "images": ["https://example.com/product.png"],
    "version": "8.1",
    "speed": "fast"
  }'
```

### Zoom / Pan

- Zoom：`zoom_ratio` 为 `1.5` 或 `2`，或直接传 `custom_id`
- Pan：`direction` 为 `up` / `down` / `left` / `right`

### 局部重绘

1. 对已放大的单图调用 `/inpaint`，任务进入 `status=modal`
2. 再调 `/modal`，提交 `prompt` 和 `mask`（遮罩）

## 工作流

```text
POST /midjourney/generations
  → GET /api/open-api/v1/images/{taskId} 至 completed
  → /upscale 或 /variation 或 /reroll
  → 单图可继续 /zoom /inpaint（再 /modal）
```
