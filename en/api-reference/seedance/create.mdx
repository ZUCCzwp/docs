---
title: 'Create Seedance Full Video'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

Create a Seedance **Full (Manxue)** video generation task. On success you receive a `task_id`. Poll [Query Video Task](/en/api-reference/common/query) until `completed`, then read the video URL from `result.video_url`.

<Warning>
Do **not** send Seedance 2.5 models (`seedance-2.5`, `seedance-2.5-sp`, `seedance-2.5-720p`, `seedance2.5-gz`, `seedance2.5-md`, `seedance2.5-30s`, etc.) to this endpoint. Use [Create Seedance 2.5 Video](/en/api-reference/seedance/25/create), [Create Seedance 2.5 GZ Video](/en/api-reference/seedance/25/create-gz), or [Create Seedance 2.5 MD Video](/en/api-reference/seedance/25/create-ar): `POST /api/open-api/v1/seedance25/videos`. Hitting `/seedance/videos` routes them onto the Seedance 2.0 Full line.
</Warning>

<Note>
Other routes: **Mini** — [Mini Create Video](/en/api-reference/seedance/mini/create); **SP economy** — [SP Create Video](/en/api-reference/seedance/sp/create); **MD** — [MD Create Video](/en/api-reference/seedance/md/create); **Seedance 2.0 GZ** — [Create Seedance 2.0 GZ Video](/en/api-reference/seedance/gz720/create); **Seedance 2.5** — [Create Seedance 2.5 Video](/en/api-reference/seedance/25/create); **Seedance 2.5 GZ** — [Create Seedance 2.5 GZ Video](/en/api-reference/seedance/25/create-gz).
</Note>

## Models and routes

Choose a Full-route sub-model with the `model` field:

| Route | `model` values | Billing | Duration | Assets |
|-------|----------------|---------|----------|--------|
| **Full (Manxue)** | `sd2_mx_720p`, `sd2_mx_1080p`, `sd2_mx_2k`, `sd2_mx_4k` | Per second | 4–15 s | Must [audit assets](/en/api-reference/seedance/assets-audit) first; use `asset://{assetId}` |
| **Fast** | `sd2_mx_fast_720p`, `sd2_mx_fast_1080p` | Per second | 4–15 s | Same as Manxue; `reference_videos` not supported |
| **Video reference** | `sd2_mx_video_720p`, `sd2_mx_video_1080p`, `sd2_mx_video_2k`, `sd2_mx_video_4k` | Per second | 4–15 s | Same as Manxue; supports `reference_videos` |
| **Video reference Fast** | `sd2_mx_video_fast_720p`, `sd2_mx_video_fast_1080p` | Per second | 4–15 s | Same as Manxue; supports `reference_videos` |

## Billing

Full (Manxue) routes are billed **per second**. Each `model` has its own unit price (e.g. `sd2_mx_720p`, `sd2_mx_1080p`).

| Item | Description |
|------|-------------|
| Formula | **unit price (per second) × `duration`** |
| Unit price | See the [console pricing](https://api.viraltok.ai) for the model name |
| Duration | `duration` field, 4–15 seconds |

## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | See table above |
| `prompt` | string | Yes | Text prompt |
| `duration` | int | Yes | Length in seconds, 4–15 (default 5) |
| `ratio` | string | No | Aspect ratio, e.g. `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `Adaptive` |
| `images` | string[] | No | Reference images |
| `first_image` | string | No | First frame image |
| `last_image` | string | No | Last frame image |
| `reference_videos` | string[] | No | Reference videos; only `sd2_mx_video_*` models |
| `reference_audios` | string[] | No | Reference audio |

### Asset URL format

- **Full / Fast / video-reference series**: `images`, `first_image`, `last_image`, `reference_videos`, and `reference_audios` must use `asset://{assetId}`. [Submit for audit](/en/api-reference/seedance/assets-audit) first, then poll [audit status](/en/api-reference/seedance/assets-status) until `Active`.
- **`reference_videos`**: only supported on `sd2_mx_video_*` and `sd2_mx_video_fast_*`; not on standard Full or Fast models.

### General constraints

- `images` (reference mode) and `first_image` / `last_image` (frame mode) **cannot be used together**.

## Example

### Full (Manxue) — reference image (audit required)

```bash
# 1. Submit assets for audit (see assets-audit doc)
# 2. Poll audit status until Active
# 3. Create video
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2_mx_720p",
    "prompt": "Slow dolly in with subtle lighting changes",
    "duration": 5,
    "ratio": "16:9",
    "images": ["asset://your-asset-id-here"]
  }'
```

## Response example

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "sd2_mx_720p",
    "created_at": 1710000000
  }
}
```

## Query task

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

Task status: `queued` → `processing` → `completed` / `failed`. Read the video URL from `data.result.video_url` when completed.

<Note>
Result URLs are kept for about **3 days**. Download promptly.
</Note>
