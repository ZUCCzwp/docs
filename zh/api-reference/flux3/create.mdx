## 模型

请求 `model` 固定为 `flux-3`。计费名由请求里的素材字段决定，费用 = 计费名单价 × `duration`。

| 请求字段 | 计费名 | 输出 |
|----------|--------|------|
| `draft_cache_url` | `flux-3-enhance` | 1080p，不需要 `prompt` |
| `keyframes` | `flux-3-keyframes-draft` | 720p |
| `start_image_url` 或 `end_image_url` | `flux-3-flf-draft` | 720p |
| `image_url` | `flux-3-i2v-draft` | 720p |
| `video_url` | `flux-3-extend-draft` | 720p |
| 只有 `prompt` | `flux-3-draft` | 720p，返回 `draft_cache_url` |

多种素材同时出现时，按上表从上到下命中第一条。草稿一律 720p，增强一律 1080p；**不要传 `resolution`**。

## 参数限制

- **prompt**：草稿必填，1–5000 字符；增强不需要
- **duration**：5–20 秒（默认 5）；增强时请填与草稿相同的时长用于计费
- **aspect_ratio**：`auto` / `21:9` / `2:1` / `16:9` / `4:3` / `1:1` / `3:4` / `9:16`（默认 `16:9`；增强忽略）
- **generate_audio**：可选，默认 `true`（增强忽略）
- **safety_tolerance**：0–4，默认 `2`
- **keyframes**：最多 10；`frame_index` 唯一且 ≤ `duration * 24`

## 草稿 → 增强流程

1. 用 `model: "flux-3"` 生成草稿（固定 720p），轮询拿到 `result.video_url` 与 `result.draft_cache_url`
2. 再提交 `model: "flux-3"`，传入 `draft_cache_url` 与相同 `duration`（固定 1080p，计费 `flux-3-enhance`）
3. 轮询增强任务，从 `result.video_url` 取成片

## 示例

文生草稿（固定 720p，计费 `flux-3-draft`）：

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "prompt": "一只小熊猫在苔藓圆木上行走",
    "duration": 5,
    "aspect_ratio": "16:9"
  }'
```

草稿增强（固定 1080p，计费 `flux-3-enhance`）：

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "duration": 5,
    "draft_cache_url": "https://example.com/draft-cache.bin"
  }'
```
