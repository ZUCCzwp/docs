<Note>
**备注（兼容路径）**：旧接口 `/api/open-api/v1/seedance/videos` 仍可调用，行为与 `POST /api/v1/videos` 相同；新接入请优先使用统一入口。

创建 Seedance **满血版超分 Fast** 视频生成任务。提交成功后返回 `task_id`，请使用 [查询视频任务](/zh/api-reference/common/query) 轮询状态，完成后从 `result.video_url` 获取视频地址。

<Note>
本接口与 [创建满血版超分视频](/zh/api-reference/seedance/sp/create) 共用 `POST /api/v1/videos`。非 Fast SP 见 SP 文档；官转 Fast 见 [创建 Seedance 2.0官转 Fast视频](/zh/api-reference/seedance/fast/create-gz)。
</Note>

## 模型选择

在线制作和调用 `POST /api/v1/videos` 均使用 **`sd2-sp-fast`**。服务根据 `reference_videos` 是否至少包含一条非空视频引用选择计费模型。

| 模式 | 计费模型 | 计费 | 时长 | 素材要求 |
|------|-------------|------|------|----------|
| 无参考视频 | `sd2_sp_fast_720p` | 按秒 | 4–15 秒 | `reference_videos` 省略或为空 |
| 有参考视频 | `sd2_sp_video_fast_720p` | 按秒 | 4–15 秒 | `reference_videos` 包含视频引用 |

两种模式均固定输出 **720p** 视频。

## 计费说明

服务按上表选出的计费模型扣除算力额度。创建任务响应的 `data.model` 为实际计费模型。

| 项目 | 说明 |
|------|------|
| 计费方式 | **单价（元/秒）× `duration`** |
| 单价来源 | 以控制台定价中对应模型名为准 |
| 时长 | `duration` 字段，范围 4–15 秒 |

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | `sd2-sp-fast` |
| `resolution` | string | 否 | 固定 `720p`，可省略 |
| `prompt` | string | 是 | 视频生成提示词 |
| `duration` | int | 是 | 时长（秒），4–15，默认 5 |
| `ratio` | string | 否 | 画面比例，如 `16:9`、`9:16`、`1:1` |
| `images` | string[] | 否 | 参考图列表 |
| `first_image` | string | 否 | 首帧图片 |
| `last_image` | string | 否 | 尾帧图片 |
| `reference_videos` | string[] | 否 | 参考视频列表，包含非空视频引用时使用视频参考计费 |
| `reference_audios` | string[] | 否 | 参考音频；须搭配参考图/视频或首尾帧 |

## 素材说明

- 可直接传入公网 `https://` URL。
- 也可先 [上传素材](/zh/api-reference/seedance/sp/assets-upload)，再使用 `asset://{asset_id}`。

## 约束

- `images`（参考图模式）与 `first_image` / `last_image`（首尾帧模式）**不可同时使用**。
- `reference_audios` 不能单独使用，须搭配参考图、参考视频或首尾帧。

## 示例

### 使用素材库 asset

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-sp-fast",
    "prompt": "镜头缓慢推进，光影变化细腻",
    "duration": 8,
    "ratio": "16:9",
    "images": ["asset://your-asset-id-here"]
  }'
```

### 使用参考视频

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-sp-fast",
    "prompt": "沿用参考视频的运镜，改为傍晚光线",
    "duration": 8,
    "ratio": "16:9",
    "reference_videos": ["https://example.com/reference.mp4"]
  }'
```

## 响应示例

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "sd2_sp_fast_720p",
    "created_at": 1710000000
  }
}
```

## 查询任务

```bash
curl -X GET 'https://api.viraltok.ai/api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

任务状态：`queued` → `processing` → `completed` / `failed`。完成后从 `data.result.video_url` 获取视频地址。

<Note>
视频结果 URL 保存约 **3 天**，请及时转存。
</Note>
