<Note>
本接口采用异步处理。提交后保存 `task_id`，通过 [查询图片任务](/zh/api-reference/images/query) 轮询状态。完成后从 `result.image_url` 读取图片地址。
</Note>

## 支持的模型

| model | 说明 |
|-------|------|
| `muse-images` | Muse 图片。支持文生图和最多 9 张参考图生图。每次返回 1 张 WebP。按次计费。 |

`muse-image` 等别名会归一化为 `muse-images`。

## 参数限制

- **提示词（prompt）**：必填，去除首尾空白后不能为空。带参考图时也必填。
- **参考图片**：`images` 或 `image_urls`，最多 9 张公网 URL。省略或传空为纯文字生成。参考图用于指导生成，不保证成为逐像素一致的源图。
- **比例**：支持 `1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`。文生图默认 `1:1`；参考图生图省略时跟随参考图构图。`size` 为比例兼容字段，可传上述比例或 `auto`；两者均合法时 `aspect_ratio` 优先。不能传 `"auto"` 给 `aspect_ratio`，也不能传 `1024x1024` 等像素尺寸。
- **数量**：每次只生成 1 张。可省略 `n`，或显式传 `1`。
- 不支持指定像素或 1K / 2K / 4K 档位。不要发送 `resolution` 或任何时长字段。
- 不支持参考视频、参考音频、遮罩、首尾帧、续写或 remix。同步接口 `/images/generations`、`/images/edits` 不支持本模型。

## 计费

- 请求模型名：`muse-images`
- 计费模型名：`muse-images`，`per_task`（按次）。单价以控制台为准。

<RequestExample>
```bash 文生图
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/muse/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "muse-images",
    "prompt": "一只红色陶瓷杯放在白色桌面上，柔和棚拍灯光，产品摄影，无文字",
    "aspect_ratio": "1:1",
    "n": 1
  }'
```

```bash 参考图生图
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/muse/images' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "muse-images",
    "prompt": "保留参考图中杯子的外观，将背景改为木质咖啡桌，温暖自然光",
    "images": ["https://example.com/cup.png"],
    "n": 1
  }'
```
</RequestExample>

<ResponseExample>
```json 200
{
  "code": "20000",
  "msg": "ok",
  "data": {
    "task_id": "img_xxxxxxxx",
    "status": "submitted",
    "model": "muse-images"
  }
}
```
</ResponseExample>
