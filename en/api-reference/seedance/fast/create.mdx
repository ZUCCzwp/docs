---
title: 'Create Full Fast Video'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

Create a Seedance **Full Fast** video generation task. On success you receive a `task_id`. Poll [Query Video Task](/en/api-reference/common/query) until `completed`, then read the video URL from `result.video_url`.

<Note>
This uses the same endpoint as [Create Seedance Full Video](/en/api-reference/seedance/create): `POST /api/open-api/v1/seedance/videos`. Non-Fast Full models are on the Full page; SP Fast is [Create Full Super-Resolution SP Fast Video](/en/api-reference/seedance/fast/create-sp); Official Fast is [Create Seedance 2.0 Official Fast Video](/en/api-reference/seedance/fast/create-gz).
</Note>

## Models and routes

Choose a Full Fast sub-model with the `model` field:

| Route | `model` values | Billing | Duration | Assets |
|-------|----------------|---------|----------|--------|
| **Full Fast** | `sd2_mx_fast_720p`, `sd2_mx_fast_1080p` | Per second | 4–15 s | Must [audit assets](/en/api-reference/seedance/assets-audit) first; use `asset://{assetId}`; `reference_videos` not supported |
| **Video reference Fast** | `sd2_mx_video_fast_720p`, `sd2_mx_video_fast_1080p` | Per second | 4–15 s | Same as Full Fast; supports `reference_videos` |

## Billing

Full Fast routes are billed **per second**. Each `model` has its own unit price.

| Item | Description |
|------|-------------|
| Formula | **unit price (per second) × `duration`** |
| Unit price | See the [console pricing](https://api.viraltok.ai) for the model name |
| Duration | `duration` field, 4–15 seconds |

## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | See table above |
| `prompt` | string | Yes | Text prompt |
| `duration` | int | Yes | Length in seconds, 4–15 (default 5) |
| `ratio` | string | No | Aspect ratio, e.g. `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `Adaptive` |
| `images` | string[] | No | Reference images |
| `first_image` | string | No | First frame image |
| `last_image` | string | No | Last frame image |
| `reference_videos` | string[] | No | Reference videos; only `sd2_mx_video_fast_*` |
| `reference_audios` | string[] | No | Reference audio |

### Asset URL format

- `images`, `first_image`, `last_image`, `reference_videos`, and `reference_audios` must use `asset://{assetId}`. [Submit for audit](/en/api-reference/seedance/assets-audit) first, then poll [audit status](/en/api-reference/seedance/assets-status) until `Active`.
- **`reference_videos`**: only supported on `sd2_mx_video_fast_*`; not on `sd2_mx_fast_*`.

### General constraints

- `images` (reference mode) and `first_image` / `last_image` (frame mode) **cannot be used together**.

## Example

### Full Fast — reference image (audit required)

```bash
# 1. Submit assets for audit (see assets-audit doc)
# 2. Poll audit status until Active
# 3. Create video
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2_mx_fast_720p",
    "prompt": "Slow dolly in with subtle lighting changes",
    "duration": 5,
    "ratio": "16:9",
    "images": ["asset://your-asset-id-here"]
  }'
```

## Response example

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "sd2_mx_fast_720p",
    "created_at": 1710000000
  }
}
```

## Query task

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

Task status: `queued` → `processing` → `completed` / `failed`. Read the video URL from `data.result.video_url` when completed.

<Note>
Result URLs are kept for about **3 days**. Download promptly.
</Note>
