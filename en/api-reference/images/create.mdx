---
title: 'Create Image (Async)'
openapi: 'POST /api/open-api/v1/images'
---

<Note>
This endpoint is **asynchronous**: it returns a `task_id`. Poll [Query Image Task](/en/api-reference/images/query) for results. **Recommended for production** to avoid **504** timeouts on sync calls behind Cloudflare.

For **synchronous** text-to-image or image edit (OpenAI-compatible, returns `b64_json` on success), use [Text-to-Image (Sync)](/en/api-reference/images/generations) or [Edit Image (Sync)](/en/api-reference/images/edits); sync calls may use the direct image endpoint `https://img.viraltok.ai`.
</Note>

<Note>
Async image tasks use `ratio` for **aspect ratio** (e.g. `1:1`, `16:9`); default is `auto`. Sync OpenAI-compatible endpoints (`/images/generations`, `/images/edits`) still use `size` for **pixel dimensions** (e.g. `1024x1024`).

[Seedream 5.0 Pro](/en/api-reference/images/seedream-5-0-pro/create) uses the same async endpoint with `"model": "doubao-seedream-5-0-pro"`.

[GPT Image 1.5](/en/api-reference/images/gpt-image-1.5/create) uses the same async endpoint with `"model": "gpt-image-1.5"` (async only; sync generations/edits are not supported).
</Note>
