## 计费说明

### Veo 3.1 Fast（`veo_3_1_fast`）

请求 `model` 为 `veo_3_1_fast`。计费模型由 `resolution` 决定：

| resolution | 计费模型 | 说明 |
|------------|----------|------|
| `720p` / `1080p`（默认 `720p`） | `veo_3_1_fast` | 标准分辨率，按次 |
| `4k` | `veo_3_1_fast-4k` | 4K 独立计费档，按次 |

也可直接传 `model: "veo_3_1_fast-4k"`（等价于 4K 计费）。

### Veo 3.1 Lite（`veo_3_1_lite`）

请求 `model` 为 `veo_3_1_lite`。**仅支持 `720p`**（默认）；不支持 `1080p` / `4k`。

| resolution | 计费模型 | 说明 |
|------------|----------|------|
| `720p`（默认） | `veo_3_1_lite` | 标准档，按次 |

参考图与首尾帧互斥：`images[]` 与 `first_frame_url` / `last_frame_url` 不可同时使用。
