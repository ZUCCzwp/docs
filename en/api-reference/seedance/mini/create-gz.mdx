<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status and read the final video URL from `result.video_url`.
</Note>

This uses the same endpoint as [Mini Create Video](/en/api-reference/seedance/mini/create) and [Create Seedance 2.0 GZ Video](/en/api-reference/seedance/gz720/create): `POST /api/open-api/v1/seedance/videos`. Select this route with a `model` that starts with `seedance2.0-gz-mini`.

## Supported models

| model | Notes | Resolution |
|-------|-------|------------|
| `seedance2.0-gz-mini` | Official Mini; default 720p | `480p` / `720p` |
| `seedance2.0-gz-mini-720p` / `seedance2.0-gz-mini-480p` | Billing names include resolution | matching tier |

`1080p` is not supported.

## Parameter constraints

- **Prompt**: Required.
- **Duration**: 4–15 seconds (default `5`).
- **Aspect ratio** (`aspect_ratio` / `ratio`): `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `adaptive` (default `16:9`).
- **Resolution**: `480p` / `720p` (default `720p`). You may also encode resolution in `model`.
- **Reference images**: `images` or `reference_images`, max **9**.
- **Reference videos**: `videos` or `reference_videos`, max **3**.
- **Reference audios**: `audios` or `reference_audios`, max **3**; must be paired with at least one image or video reference.
- **First / last frame**: `first_image` / `last_image` cannot be mixed with multimodal references; last frame requires first frame.
- **generate_audio**: Default `true`.

## Asset review

Reference images / videos / audios and first/last frames must be public `https://` URLs, or reviewed assets `asset://{assetId}` / `assetId://{assetId}`.

Public URLs are submitted to the [Seedance 2.0 asset library](/en/api-reference/seedance/sp/assets-upload) and must pass review before the generation task starts. You may also upload first and pass `asset://`.

First-frame / first-last-frame mode is mutually exclusive with multimodal references.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `seedance2.0-gz-mini*`; see table |
| `prompt` | string | Yes | Text prompt |
| `duration` | integer | No | Duration in seconds, default `5` |
| `resolution` | string | No | `480p` / `720p`; optional if `model` already includes it |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `images` | string[] | No | Reference image URLs (0–9) |
| `reference_images` | string[] | No | Alias for `images` when `images` is empty |
| `videos` / `reference_videos` | string[] | No | Reference video URLs (0–3) |
| `audios` / `reference_audios` | string[] | No | Reference audio URLs (0–3); requires image or video refs |
| `first_image` | string | No | First-frame image |
| `last_image` | string | No | Last-frame image |
| `generate_audio` | boolean | No | Generate audio track; default `true` |

## Billing

- Mode: `per_second`
- Billing model: the request `model` (unit price from [console pricing](https://api.viraltok.ai))

```text
cost = unit_price × duration
```

## Example request

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-gz-mini-720p",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 5,
    "aspect_ratio": "16:9",
    "images": ["https://example.com/reference.png"]
  }'
```

## Result URL

When the task completes, read `data.result.video_url`. Official Mini returns a **direct upstream media link** (not copied to our object storage) — download promptly.
