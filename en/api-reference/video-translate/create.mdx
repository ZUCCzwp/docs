---
title: 'Create video-translate task'
openapi: 'en/api-reference/openapi.json POST /api/open-api/v1/video-translate/videos'
---

Submit a video translation task: translate spoken audio into a target language and produce a dubbed video. On success you get a `task_id`. Poll with [Query video task](/en/api-reference/common/query), then read `result.video_url`. If captions were requested, also read `result.caption_url`.

Source video max length is **8 minutes**. `video_url` must be a public URL that stays reachable while the task runs.

## Supported models

| model | Notes |
|-------|-------|
| `video-translate-precision` | Higher-quality translation (default) |
| `video-translate-speed` | Faster translation |

## Request fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `model` | string | no | `video-translate-precision` (default) or `video-translate-speed` |
| `video_url` | string | yes | Public URL of the source video |
| `output_language` | string | yes | Target language; see [Target languages](#target-languages-output_language) for the full enum |
| `translate_audio_only` | boolean | no | Translate the voice track only (no lip sync) |
| `speaker_num` | integer | no | Number of speakers (≥ 1) |
| `enable_dynamic_duration` | boolean | no | Stretch/shrink duration for speaking rate; default `true` |
| `srt_url` | string | no | Public URL of a custom SRT file |
| `srt_role` | string | no | `input` (source captions) or `output` (target captions) |
| `enable_caption` | boolean | no | Generate an SRT; returned as `result.caption_url` |
| `brand_glossary_id` | string | no | Brand glossary ID for custom term translations |

## Billing

- Mode: `per_second`
- Duration: probed from `video_url`, **rounded up** (minimum 1 second)
- Videos longer than 480 seconds (8 minutes) are rejected
- Unit price: configured per `model` in the console

```text
cost = unit_price × ceil(video_duration_seconds)
```

## Query task

Poll every 5–10 seconds until `completed` / `failed`. Result URLs are kept about **3 days** — download promptly. Read `result.video_url` for the video; with captions enabled, also `result.caption_url`.

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

<RequestExample>

curl -X POST 'https://api.viraltok.ai/api/open-api/v1/video-translate/videos' \

  -d '{
    "model": "video-translate-precision",
