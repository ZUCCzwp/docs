<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status and read the final video URL from `result.video_url`. Read `completion_tokens` / `total_tokens` from `data.usage`.
</Note>

This uses the same endpoint as [Create Seedance Full Video](/en/api-reference/seedance/create): `POST /api/open-api/v1/seedance/videos`. Select this series with a `model` that starts with `seedance2.0-gz`.

## Supported models

| model | Notes | Resolution |
|-------|-------|------------|
| `seedance2.0-gz` / `seedance2.0-gz-720p` | Standard GZ; default 720p | `480p` / `720p` / `1080p` |
| `seedance2.0-gz-480p` / `seedance2.0-gz-1080p` | Standard GZ billing names | matching tier |
| `seedance2.0-gz-fast` / `seedance2.0-gz-fast-720p` / `seedance2.0-gz-fast-480p` | Fast | `480p` / `720p` |

For `seedance2.0-gz-mini*`, see [Create Official Mini Video](/en/api-reference/seedance/mini/create-gz).

Aliases such as `seedance2.0-gz720p` and `seedance20-gz-720p` normalize to `seedance2.0-gz-720p`.

## Parameter constraints

- **Prompt**: Required.
- **Duration**: 4–15 seconds (default `5`).
- **Aspect ratio** (`aspect_ratio` / `ratio`): `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `adaptive` (default `16:9`).
- **Resolution**: Standard `480p` / `720p` / `1080p` (default `720p`); Fast `480p` / `720p` only. You may also encode resolution in `model`.
- **Reference images**: `images` or `reference_images`, max **9**.
- **Reference videos**: `videos` or `reference_videos`, max **3**.
- **Reference audios**: `audios` or `reference_audios`, max **3**; must be paired with at least one image or video reference.
- **First / last frame**: `first_image` / `last_image` cannot be mixed with multimodal references; last frame requires first frame.
- **generate_audio**: Default `true`.

## Asset review

Reference images / videos / audios and first/last frames must be public `https://` URLs, or reviewed assets `asset://{assetId}` / `assetId://{assetId}`.

Public URLs are submitted to the [Seedance 2.0 asset library](/en/api-reference/seedance/sp/assets-upload) and must pass review before the generation task starts. You may also upload first and pass `asset://`.

First-frame / first-last-frame mode is mutually exclusive with multimodal references.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `seedance2.0-gz*` series; see table |
| `prompt` | string | Yes | Text prompt |
| `duration` | integer | No | Duration in seconds, default `5` |
| `resolution` | string | No | See table; optional if `model` already includes it |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `images` | string[] | No | Reference image URLs (0–9) |
| `reference_images` | string[] | No | Alias for `images` when `images` is empty |
| `videos` / `reference_videos` | string[] | No | Reference video URLs (0–3) |
| `audios` / `reference_audios` | string[] | No | Reference audio URLs (0–3); requires image or video refs |
| `first_image` | string | No | First-frame image |
| `last_image` | string | No | Last-frame image |
| `generate_audio` | boolean | No | Generate audio track; default `true` |

## Billing

`seedance2.0-gz*` is billed by **price per million tokens**, settled from upstream `completion_tokens` after success.

Requests **with reference videos** (`reference_videos` / `videos`) use a separate billing name (insert `-video` into the model). You do not change the request `model`:

| Request model | No video refs | With video refs |
|---------------|---------------|-----------------|
| `seedance2.0-gz-720p` | `seedance2.0-gz-720p` | `seedance2.0-gz-video-720p` |
| `seedance2.0-gz-fast` | `seedance2.0-gz-fast` | `seedance2.0-gz-fast-video` |
| `seedance2.0-gz-mini-720p` | `seedance2.0-gz-mini-720p` | `seedance2.0-gz-mini-video-720p` |

```text
cost = completion_tokens / 1,000,000 × unit_price of the billing name
```

On some routes, `seedance2.0-gz-720p` **does not return tokens**, so it is billed **per second at create time** (no token settlement):

```text
cost = unit_price × duration
```

In that case console `unit_price` is the **per-second** price. Other `seedance2.0-gz*` models still use per-million-token pricing.

## Example request

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-gz-720p",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 5,
    "aspect_ratio": "16:9",
    "images": ["https://example.com/reference.png"],
    "reference_videos": ["https://example.com/reference.mp4"]
  }'
```

## Result URL

When the task completes, read `data.result.video_url`. The `seedance2.0-gz` series returns a **direct upstream media link** (not copied to our object storage) — download promptly.
