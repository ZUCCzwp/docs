---
title: '创建视频翻译任务'
openapi: 'zh/api-reference/openapi.json POST /api/open-api/v1/video-translate/videos'
---

提交视频翻译任务：将源视频口播翻译并合成到目标语言。提交成功后返回 `task_id`，请使用 [查询视频任务](/zh/api-reference/common/query) 轮询状态。完成后从 `result.video_url` 获取成片；若开启字幕，另有 `result.caption_url`。

源视频最长 **8 分钟**。`video_url` 须为公网可访问地址，任务处理期间保持可达。

## 支持的模型

| model | 说明 |
|-------|------|
| `video-translate-precision` | 高精度翻译（默认） |
| `video-translate-speed` | 快速翻译 |

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 否 | `video-translate-precision`（默认）或 `video-translate-speed` |
| `video_url` | string | 是 | 待翻译视频的公网 URL |
| `output_language` | string | 是 | 目标语言，见下方 [目标语言](#目标语言output_language) 完整枚举 |
| `translate_audio_only` | boolean | 否 | 仅翻译音轨，不改口型 |
| `speaker_num` | integer | 否 | 说话人数量（≥ 1） |
| `enable_dynamic_duration` | boolean | 否 | 按目标语速调整时长，默认 `true` |
| `srt_url` | string | 否 | 自定义 SRT 字幕文件公网 URL |
| `srt_role` | string | 否 | `input`（源语言字幕）或 `output`（目标语言字幕） |
| `enable_caption` | boolean | 否 | 生成配套 SRT；完成后见 `result.caption_url` |
| `brand_glossary_id` | string | 否 | 品牌术语表 ID（专有名词翻译） |

## 计费说明

- 计费方式：`per_second`（按秒）
- 计费时长：根据 `video_url` 解析实际时长，**向上取整**（不足 1 秒按 1 秒）
- 超过 480 秒（8 分钟）的视频会被拒绝
- 单价：以控制台中对应 `model` 配置为准

```text
费用 = 模型单价 × ceil(视频时长秒数)
```

## 查询任务

建议每 5–10 秒轮询一次，状态变为 `completed` / `failed` 后停止。结果 URL 保存约 **3 天**，请及时转存。完成后从 `result.video_url` 取成片；开启字幕时另有 `result.caption_url`。

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```
