<Note>
**备注（兼容路径）**：旧接口 `/api/open-api/v1/seedance/videos` 仍可调用，行为与 `POST /api/v1/videos` 相同；新接入请优先使用统一入口。
</Note>


创建 Seedance **满血版超分** 视频生成任务。提交成功后返回 `task_id`，请使用 [查询视频任务](/zh/api-reference/common/query) 轮询状态，完成后从 `result.video_url` 获取视频地址。

<Note>
本接口与 [创建视频](/zh/api-reference/videos/create) 共用 `POST /api/v1/videos`。Mini 见 [创建Mini视频](/zh/api-reference/seedance/mini/create)，SP Fast 见 [创建满血版超分 Fast视频](/zh/api-reference/seedance/fast/create-sp)。
</Note>

## 模型

请求 `model` 固定为 `sd2-sp`。分辨率用 `resolution`：`480p`、`720p`（默认）、`1080p`、`2k`、`4k`。时长 4–15 秒。

## 计费说明

按 **秒** 计费。费用 = 对应计费名的单价 × `duration`。单价以控制台定价为准。

| 请求 | 计费名 |
|------|--------|
| 不带参考视频 | `sd2_sp_{resolution}` |
| 带 `reference_videos` | `sd2_sp_video_{resolution}` |


## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | `sd2-sp` |
| `prompt` | string | 是 | 视频生成提示词 |
| `duration` | int | 是 | 时长（秒），4–15，默认 5 |
| `resolution` | string | 否 | `480p`、`720p`（默认）、`1080p`、`2k`、`4k` |
| `ratio` | string | 否 | 画面比例，如 `16:9`、`9:16`、`1:1` |
| `images` | string[] | 否 | 参考图列表 |
| `first_image` | string | 否 | 首帧图片 |
| `last_image` | string | 否 | 尾帧图片 |
| `reference_videos` | string[] | 否 | 参考视频。传入后按 `sd2_sp_video_{resolution}` 计费 |
| `reference_audios` | string[] | 否 | 参考音频；须搭配参考图/视频或首尾帧 |

## 素材说明

- 可直接传入公网 `https://` URL。
- 也可先 [上传素材](/zh/api-reference/seedance/sp/assets-upload)，再使用 `asset://{asset_id}`。

## 约束

- `images`（参考图模式）与 `first_image` / `last_image`（首尾帧模式）**不可同时使用**。
- `reference_audios` 不能单独使用，须搭配参考图、参考视频或首尾帧。

## 示例


### 满血版超分 — 首帧图生视频

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-sp",
    "prompt": "雨夜街头，女孩回头微笑，电影感镜头推进",
    "duration": 5,
    "resolution": "720p",
    "ratio": "16:9",
    "first_image": "https://example.com/start.png"
  }'
```

### 参考图生视频

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-sp",
    "prompt": "人物缓缓转头，微风拂动发丝",
    "duration": 6,
    "resolution": "1080p",
    "ratio": "9:16",
    "images": [
      "https://example.com/ref-1.jpg",
      "https://example.com/ref-2.jpg"
    ]
  }'
```

### 使用素材库 asset

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-sp",
    "prompt": "镜头缓慢推进，光影变化细腻",
    "duration": 8,
    "ratio": "16:9",
    "images": ["asset://your-asset-id-here"]
  }'
```

## 响应示例

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "sd2_sp_720p",
    "created_at": 1710000000
  }
}
```

## 查询任务

```bash
curl -X GET 'https://api.viraltok.ai/api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

任务状态：`queued` → `processing` → `completed` / `failed`。完成后从 `data.result.video_url` 获取视频地址。

<Note>
视频结果 URL 保存约 **3 天**，请及时转存。
</Note>
