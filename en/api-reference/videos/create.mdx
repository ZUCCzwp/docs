## Discontinued

Sora video generation is offline. This endpoint no longer accepts new Sora tasks.

Use other video models still listed in the console and docs (for example Veo, Seedance, Grok, Wan), submit via their create endpoints, then poll [Query video task](/en/api-reference/common/query).
