---
title: '创建 Seedance 2.0 GZ 视频'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

<Note>
创建成功后会返回 `task_id`。请使用 [查询视频任务](/zh/api-reference/common/query) 接口轮询任务状态，任务完成后从 `result.video_url` 获取视频地址，并从 `data.usage` 读取 `completion_tokens` / `total_tokens`。
</Note>

本接口与 [创建 Seedance 满血版视频](/zh/api-reference/seedance/create) 共用 `POST /api/open-api/v1/seedance/videos`。通过 `model` 以 `seedance2.0-gz` 开头选择本系列。

## 支持的模型

| model | 说明 | 分辨率 |
|-------|------|--------|
| `seedance2.0-gz` / `seedance2.0-gz-720p` | 标准 GZ；默认 720p | `480p` / `720p` / `1080p` |
| `seedance2.0-gz-480p` / `seedance2.0-gz-1080p` | 标准 GZ，计费名已含分辨率 | 对应档位 |
| `seedance2.0-gz-fast` / `seedance2.0-gz-fast-720p` / `seedance2.0-gz-fast-480p` | Fast | `480p` / `720p` |

`seedance2.0-gz-mini*` 见 [创建官链 Mini 视频](/zh/api-reference/seedance/mini/create-gz)。

`seedance2.0-gz720p`、`seedance20-gz-720p` 等别名会归一化为 `seedance2.0-gz-720p`。

## 参数限制

- **提示词（prompt）**：必填。
- **时长（duration）**：4–15 秒，默认 `5`。
- **画幅比例（aspect_ratio / ratio）**：`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`21:9`、`adaptive`，默认 `16:9`。
- **分辨率（resolution）**：标准档 `480p` / `720p` / `1080p`（默认 `720p`）；Fast 仅 `480p` / `720p`。也可把分辨率写进 `model`。
- **参考图**：`images` 或 `reference_images`，最多 **9** 张。
- **参考视频**：`videos` 或 `reference_videos`，最多 **3** 个。
- **参考音频**：`audios` 或 `reference_audios`，最多 **3** 段；须搭配至少一张参考图或一个参考视频。
- **首尾帧**：`first_image` / `last_image` 与多模态参考（参考图 / 视频 / 音频）**不可混用**；尾帧必须搭配首帧。
- **生成音频（generate_audio）**：默认 `true`。

## 素材审核

参考图 / 视频 / 音频、首尾帧须为公网 `https://` URL，或已审核素材 `asset://{assetId}` / `assetId://{assetId}`。

传入公网 URL 时，平台会先提交 [Seedance 2.0 素材库](/zh/api-reference/seedance/sp/assets-upload) 并等待审核通过后再创建任务。也可自行上传后传 `asset://`。

场景互斥：首帧 / 首尾帧 与 多模态参考 不可同时使用。

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | `seedance2.0-gz*` 系列，见上表 |
| `prompt` | string | 是 | 文本提示词 |
| `duration` | integer | 否 | 时长秒数，默认 `5` |
| `resolution` | string | 否 | 见上表；可省略若 `model` 已含分辨率 |
| `aspect_ratio` | string | 否 | 画幅比例，优先于 `ratio` |
| `ratio` | string | 否 | `aspect_ratio` 别名 |
| `images` | string[] | 否 | 参考图 URL（0–9） |
| `reference_images` | string[] | 否 | `images` 为空时的别名 |
| `videos` / `reference_videos` | string[] | 否 | 参考视频 URL（0–3） |
| `audios` / `reference_audios` | string[] | 否 | 参考音频 URL（0–3）；须搭配图或视频 |
| `first_image` | string | 否 | 首帧图 |
| `last_image` | string | 否 | 尾帧图 |
| `generate_audio` | boolean | 否 | 是否生成音轨，默认 `true` |

## 计费说明

`seedance2.0-gz*` 按 **百万 token 单价** 计费；任务成功后按上游 `completion_tokens` 结算（多退少补）。

**带参考视频**（`reference_videos` / `videos`）使用独立计费名（在型号中插入 `-video`），单价与无参考视频不同。请求里的 `model` 不必改；若直接传 `seedance2.0-gz-video*`，则 **必须** 传参考视频，否则请改用不带 `-video` 的型号重试。

| 请求 model | 无参考视频 | 有参考视频 |
|------------|------------|------------|
| `seedance2.0-gz-720p` | `seedance2.0-gz-720p` | `seedance2.0-gz-video-720p` |
| `seedance2.0-gz-fast` | `seedance2.0-gz-fast` | `seedance2.0-gz-fast-video` |
| `seedance2.0-gz-mini-720p` | `seedance2.0-gz-mini-720p` | `seedance2.0-gz-mini-video-720p` |

```text
费用 = completion_tokens / 1,000,000 × 对应计费名的百万 token 单价
```

`seedance2.0-gz-720p` 在部分线路查询**不返回 token**，改为创建时 **按秒计费**，不再按 token 结算：

```text
费用 = 单价 × duration
```

该情况下控制台 `unit_price` 表示**每秒**单价。其它 `seedance2.0-gz*` 仍按百万 token 单价。

## 示例请求

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-gz-720p",
    "prompt": "电影感产品展示，自然光，缓慢推镜",
    "duration": 5,
    "aspect_ratio": "16:9",
    "images": ["https://example.com/reference.png"],
    "reference_videos": ["https://example.com/reference.mp4"]
  }'
```

## 结果地址

任务完成后从 `data.result.video_url` 读取地址。`seedance2.0-gz` 系列返回的是**上游直链**，平台**不转存 OSS**，请及时下载。
