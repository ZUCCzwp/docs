<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status, read the video URL from `result.video_url`, and read `completion_tokens` / `total_tokens` from `data.usage`.
</Note>

This uses the same endpoint as [Create Seedance 2.5 Video](/en/api-reference/seedance/25/create): `POST /api/open-api/v1/seedance25/videos`. Select this product with `model: "seedance2.5-gz"`.

<Warning>
Do **not** call `/api/open-api/v1/seedance/videos` (Seedance 2.0 / Full routes). That would land on the Full channel.
</Warning>

## Supported models

| model | Notes |
|-------|-------|
| `seedance2.5-gz` | Seedance 2.5 GZ: independent billing; text-to-video, first/last frames, and reference images / videos / audios |

Aliases such as `seedance-2.5-gz` and `seedance25-gz` normalize to `seedance2.5-gz`. Billing names `seedance2.5-gz-480p` and `seedance2.5-gz-720p` are also accepted.

## Parameter constraints

- **Prompt**: Required, 1–5000 characters.
- **Duration**: 4–30 seconds, or `-1` for auto duration (precharged as 30s). Default `5` when omitted.
- **Aspect ratio** (`aspect_ratio` / `ratio`): `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `adaptive`. Default `adaptive`. First/last-frame jobs are forced to `adaptive`.
- **Resolution**: `480p`, `720p` (default `720p`).
- **Reference images**: max **30**.
- **Reference videos**: max **10**; each clip 2–30s, combined ≤ **30** seconds.
- **Reference audios**: max **10**; audio-only references are allowed.
- **First / last frame**: optional `first_image` / `last_image`; **cannot** be combined with `reference_images`.
- **generate_audio**: default `true`.
- **watermark**: default `false`.
- **output_format**: `mp4` (default) or `mov`.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `seedance2.5-gz`, or a matching billing name |
| `prompt` | string | Yes | Text prompt |
| `duration` | integer | No | Duration in seconds, default `5`; `-1` for auto duration |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `resolution` | string | No | `480p` / `720p`, default `720p` |
| `first_image` | string | No | First-frame image URL |
| `last_image` | string | No | Last-frame image URL |
| `reference_images` | string[] | No | Reference image URLs (0–30) |
| `images` | string[] | No | Alias for `reference_images` |
| `reference_videos` | string[] | No | Reference video URLs (0–10) |
| `videos` | string[] | No | Alias for `reference_videos` |
| `reference_audios` | string[] | No | Reference audio URLs (0–10) |
| `audios` | string[] | No | Alias for `reference_audios` |
| `generate_audio` | boolean | No | Generate audio; default `true` |
| `watermark` | boolean | No | Add watermark; default `false` |
| `output_format` | string | No | `mp4` / `mov`; default `mp4` |

## Billing

You are precharged by resolution at submit time. After the task succeeds, usage is settled to actual token usage (one refund or extra-charge row). Requests with reference videos use a different per-million-token rate (JimiCoin, configurable in Console).

- Precharge mode: `per_second`
- Precharge models: `seedance2.5-gz-480p` / `seedance2.5-gz-720p`
- With reference videos: `seedance2.5-gz-video-480p` / `seedance2.5-gz-video-720p`
- Settlement models: `seedance2.5-gz-token`; with reference videos `seedance2.5-gz-video-token`
- With reference videos, precharged seconds = **output duration + reference video duration**
- `duration = -1` is precharged as **30 seconds**

```text
precharge = unit_price × precharged seconds
due JimiCoin = completion_tokens / 1,000,000 × per-million-token price
reconciled to the difference after success
```

## Example request

### Text to video

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance25/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-gz",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 8,
    "aspect_ratio": "16:9",
    "resolution": "720p"
  }'
```

### First and last frame

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance25/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-gz",
    "prompt": "The camera eases from morning light into sunset",
    "first_image": "https://example.com/start.png",
    "last_image": "https://example.com/end.png",
    "duration": 8,
    "resolution": "720p"
  }'
```

### Multimodal references

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance25/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-gz",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 8,
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "reference_images": ["https://example.com/reference.png"],
    "reference_videos": ["https://example.com/reference.mp4"],
    "reference_audios": ["https://example.com/reference.mp3"]
  }'
```
