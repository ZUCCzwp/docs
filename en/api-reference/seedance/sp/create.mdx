title: 'Create Full Super-Resolution SP Video'
openapi: 'POST /api/v1/videos'

<Note>
**Note (compatibility)**: The legacy path `/api/open-api/v1/seedance/videos` still works and matches `POST /api/v1/videos`; prefer the unified endpoint for new integrations.
</Note>


Create a Seedance **Full Super-Resolution SP** video generation task. On success you receive a `task_id`. Poll [Query Video Task](/en/api-reference/common/query) until `completed`, then read the video URL from `result.video_url`.

<Note>
This uses the same endpoint as [Create Seedance Full Video](/en/api-reference/seedance/create): `POST /api/v1/videos`. For Full (Manxue), see the full-route doc; for Mini, see [Mini Create Video](/en/api-reference/seedance/mini/create); for SP Fast, see [Create Full Super-Resolution SP Fast Video](/en/api-reference/seedance/fast/create-sp).
</Note>

## Models

Set `model` to `sd2-sp`. Choose `resolution`: `480p`, `720p` (default), `1080p`, `2k`, or `4k`. Duration is 4–15 seconds.

## Billing

Billed **per second**. Cost = that billing name's unit price × `duration`. Unit prices are on the console.

| Request | Billing name |
|---------|--------------|
| No reference video | `sd2_sp_{resolution}` |
| With `reference_videos` | `sd2_sp_video_{resolution}` |


## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `sd2-sp` |
| `prompt` | string | Yes | Text prompt |
| `duration` | int | Yes | Length in seconds, 4–15 (default 5) |
| `resolution` | string | No | `480p`, `720p` (default), `1080p`, `2k`, `4k` |
| `ratio` | string | No | Aspect ratio, e.g. `16:9`, `9:16`, `1:1` |
| `images` | string[] | No | Reference images |
| `first_image` | string | No | First frame |
| `last_image` | string | No | Last frame |
| `reference_videos` | string[] | No | Reference videos. When present, billing uses `sd2_sp_video_{resolution}` |
| `reference_audios` | string[] | No | Reference audio; must pair with images/videos or frames |

## Assets

- Pass public `https://` URLs directly.
- Or [upload assets](/en/api-reference/seedance/sp/assets-upload) first, then use `asset://{asset_id}`.

## Constraints

- Do not combine `images` (reference mode) with `first_image` / `last_image` (frame mode).
- `reference_audios` cannot be used alone; pair with reference images/videos or frames.

## Examples


### Full Super-Resolution SP — first-frame to video

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-sp",
    "prompt": "Rainy street at night, girl turns and smiles, cinematic dolly-in",
    "duration": 5,
    "resolution": "720p",
    "ratio": "16:9",
    "first_image": "https://example.com/start.png"
  }'
```

### Reference images

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-sp",
    "prompt": "Subject slowly turns head, gentle breeze in hair",
    "duration": 6,
    "resolution": "1080p",
    "ratio": "9:16",
    "images": [
      "https://example.com/ref-1.jpg",
      "https://example.com/ref-2.jpg"
    ]
  }'
```

### Using uploaded assets

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-sp",
    "prompt": "Slow dolly in, subtle lighting change",
    "duration": 8,
    "ratio": "16:9",
    "images": ["asset://your-asset-id-here"]
  }'
```

## Response

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "sd2_sp_720p",
    "created_at": 1710000000
  }
}
```

## Poll for result

```bash
curl -X GET 'https://api.viraltok.ai/api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

Statuses: `queued` → `processing` → `completed` or `failed`. Video URL is in `data.result.video_url` when completed.

<Note>
Result URLs are retained for about **3 days**. Download promptly.
</Note>
