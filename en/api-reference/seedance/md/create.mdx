---
title: 'MD Create Video'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

Create a Seedance **MD** video task. On success you receive a `task_id`. Poll [Query Video Task](/en/api-reference/common/query) until `completed`, then read the video URL from `result.video_url`.

<Note>
This endpoint is shared with [Create Seedance Full Video](/en/api-reference/seedance/create): `POST /api/open-api/v1/seedance/videos`. For Full (Manxue), Mini, and SP routes, see their respective docs.
</Note>

## Models

| Route | `model` values | Billing | Duration |
|-------|----------------|---------|----------|
| MD standard | `seedance2.0-md` | Per task | 4–15 s |
| MD fast | `seedance2.0-fast-md` | Per task | **10** or **15** s |
| MD Fast SR | `seedance2.0-fast-sr` | Per task | 4–15 s |
| MD Pro | `seedance2.0-pro` | Per task | **10** or **15** s |
| MD Pro fast | `seedance2.0-fast-pro` | Per task | **10** or **15** s |

Except `seedance2.0-fast-sr` (**1080p**), MD output is fixed at **720p**. Billing is per task, independent of duration.

## Model features

| Model | Billing | Duration | Asset support | Aspect ratios |
|-------|---------|----------|---------------|---------------|
| `seedance2.0-md` | Per task | 4–15 s | Up to **4** reference images, **3** reference videos, **1** reference audio | `16:9`, `9:16`, `1:1` |
| `seedance2.0-fast-md` | Per task | 10 or 15 s | Up to **4** reference images, **3** reference videos, **1** reference audio | `16:9`, `9:16`, `1:1` |
| `seedance2.0-fast-sr` | Per task | 4–15 s | Up to **4** reference images, **3** reference videos; **no** reference audio; output **1080p** | `16:9`, `9:16`, `1:1` |
| `seedance2.0-pro` | Per task | 10 or 15 s | Up to **9** reference images, **3** reference audios; **no** reference videos; audio requires images | `16:9`, `9:16`, `1:1` |
| `seedance2.0-fast-pro` | Per task | 10 or 15 s | Up to **9** reference images, **3** reference audios; **no** reference videos; audio requires images | `16:9`, `9:16`, `1:1` |

<Note>
Pro models (`seedance2.0-pro` / `seedance2.0-fast-pro`) target higher output quality, support more reference images and audio references, but do not support reference videos. Standard/fast MD supports reference videos with up to 4 reference images.
</Note>

## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | See table above |
| `prompt` | string | Yes | Text prompt, max **5000** characters |
| `duration` | int | Yes | Length in seconds. `seedance2.0-md` / `seedance2.0-fast-sr` support 4–15; `seedance2.0-fast-md` / `seedance2.0-pro` / `seedance2.0-fast-pro` support **10** or **15** only. Default 5 |
| `ratio` | string | No | `16:9` (default), `9:16`, or `1:1` |
| `images` | string[] | No | Reference images. Standard/fast MD / Fast SR: max **4**; Pro: max **9** |
| `first_image` | string | No | First frame; must be paired with `last_image` in frame mode |
| `last_image` | string | No | Last frame; must be paired with `first_image` in frame mode |
| `reference_videos` | string[] | No | Reference videos. `seedance2.0-md` / `seedance2.0-fast-md` / `seedance2.0-fast-sr`; max **3** |
| `reference_audios` | string[] | No | Reference audio. Standard/fast MD: max **1** clip; Pro: max **3** clips with `images`; `seedance2.0-fast-sr` **not supported** |

<Warning>
`seedance2.0-pro` / `seedance2.0-fast-pro` do **not** support `reference_videos`. Pro `reference_audios` cannot be used alone — `images` is required. The `resolution` field is ignored; output is always 720p.
</Warning>

## Assets

- Pass publicly reachable `https://` image or video URLs directly. **Images do not support GIF format**.
- SP asset library (`asset://`) and Full-route audit flows do not apply to MD.

## Constraints

- Do not combine `images` (reference mode) with `first_image` / `last_image` (frame mode).
- **First frame only is not supported**; in frame mode, `first_image` and `last_image` **must both be provided**.
- `ratio` must be one of `16:9`, `9:16`, `1:1`.
- Prompt at most 5000 characters.
- `seedance2.0-md`: `duration` 4–15 s; `images` max 4; `reference_videos` max 3; `reference_audios` max 1 clip.
- `seedance2.0-fast-md`: `duration` **10** or **15** s only; `images` max 4; `reference_videos` max 3; `reference_audios` max 1 clip.
- `seedance2.0-fast-sr`: `duration` 4–15 s; output **1080p**; `images` max 4; `reference_videos` max 3; **no** `reference_audios`.
- `seedance2.0-pro` / `seedance2.0-fast-pro`: `duration` **10** or **15** s only; `images` max 9; **no** `reference_videos`; `reference_audios` max 3 clips and must be paired with `images`.
- `reference_videos` (standard/fast MD): combined duration ≤ **15** s, combined size ≤ **200MB**; each resolution between **720px and 2160px**, frame rate **24–60 FPS**.
- `reference_audios`: combined duration ≤ **15** s; frame mode does not support audio references.

## Examples

### MD standard — reference images

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-md",
    "prompt": "Subject turns slowly, breeze in hair, cinematic lighting",
    "duration": 8,
    "ratio": "16:9",
    "images": [
      "https://example.com/ref-1.jpg",
      "https://example.com/ref-2.jpg"
    ]
  }'
```

### MD Pro — multi-image reference

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-pro",
    "prompt": "Cinematic street at night, neon reflections on wet pavement, slow dolly in",
    "duration": 10,
    "ratio": "16:9",
    "images": [
      "https://example.com/ref-1.jpg",
      "https://example.com/ref-2.jpg",
      "https://example.com/ref-3.jpg"
    ]
  }'
```

### MD Pro fast — image + audio reference

<Note>
Pro `reference_audios` must be paired with `images`; audio-only requests are not supported.
</Note>

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-fast-pro",
    "prompt": "A cute rabbit playing on the grass with upbeat background music",
    "duration": 15,
    "ratio": "9:16",
    "images": [
      "https://example.com/rabbit.png"
    ],
    "reference_audios": [
      "https://example.com/bgm.mp3"
    ]
  }'
```

### MD fast — first and last frame image-to-video

<Note>
In frame mode, `first_image` and `last_image` **must both be provided**. First frame only is not supported.
</Note>

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-fast-md",
    "prompt": "Rainy street at night, girl looks back and smiles, slow dolly in",
    "duration": 10,
    "ratio": "9:16",
    "first_image": "https://example.com/start.png",
    "last_image": "https://example.com/end.png"
  }'
```

## Response

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "seedance2.0-md",
    "created_at": 1710000000
  }
}
```

## Poll for result

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

Statuses: `queued` → `processing` → `completed` or `failed`. Video URL is in `data.result.video_url` when completed.

<Note>
Result URLs are retained for about **3 days**. Download promptly.
</Note>
