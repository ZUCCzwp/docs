<Note>
**Note (compatibility)**: The legacy path `/api/open-api/v1/seedance25/videos` still works and matches `POST /api/v1/videos`. Prefer the unified endpoint for new integrations.
</Note>

<Note>
After creation, the response returns a `task_id`. Use [Query Video Task](/en/api-reference/common/query) to poll status. When the task completes, read the video URL from `result.video_url` and `completion_tokens` / `total_tokens` from `data.usage`.
</Note>

This uses the same endpoint as [Create Seedance 2.5 Official Channel Video](/en/api-reference/seedance/25/create): `POST /api/v1/videos`. Select this product with `model: "seedance2.5-flash"`.

<Warning>
Do not submit `seedance2.5-flash` to `/api/open-api/v1/seedance/videos`. That path is Seedance 2.0.
</Warning>

## Supported models

| model | Notes |
|-------|-------|
| `seedance2.5-flash` | Seedance 2.5 Flash: text-to-video, reference images / videos / audios, first and last frames, video edit and extend. `480p` / `720p`, up to 30 seconds |

Aliases `seedance-2.5-flash`, `seedance-2-5-flash`, and `seedance25-flash` normalize to `seedance2.5-flash`. Billing names `seedance2.5-flash-480p` and `seedance2.5-flash-720p` are also accepted.

Draft fields `draft` / `draft_task_id` are not supported.

## Parameter constraints

- **Prompt**: Required, 1–5000 characters. Use `@图片1` / `@视频1` / `@音频1` to point at reference assets. Indexes start at 1.
- **Duration**: 4–30 seconds, or `-1` for automatic duration. Default `5` when omitted. Video edit accepts only `-1` or an omitted duration; output length follows the source video.
- **Aspect ratio** (`aspect_ratio` / `ratio`): `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9`, `adaptive`. Default `adaptive`. First/last frame, edit, and extend accept only `adaptive`.
- **Resolution**: `480p` or `720p`. Default `720p`. `1080p` is rejected at submission.
- **Reference images**: `reference_images` plus first/last frames, at most **10**.
- **Reference videos**: at most **5**.
- **Reference audios**: at most **5**. Audio-only references are allowed.
- **First / last frame**: `first_image` / `last_image`. Without a reference video or audio, they cannot be combined with `reference_images`. With a reference video or audio, frames are sent as reference images.
- **omni_reference_task_type**: With reference media, `auto`, `reference`, `edit`, or `extend`. `edit` needs at least one reference video, `adaptive` ratio, and duration `-1` or omitted. `extend` needs at least one reference video and `adaptive` ratio.
- **generate_audio**: default `true`.
- **watermark**: default `false`.
- **output_format**: `mp4` (default) or `mov`.
- **nsfw_check**: default `false`. When `true`, the prompt and reference images are checked before a task is created. A hit returns an error and does not create a task.

## Request fields

| Field | Type | Required | Notes |
|------|------|------|------|
| `model` | string | Yes | `seedance2.5-flash`, or a matching billing name |

| `aspect_ratio` | string | No | Aspect ratio. Takes priority over `ratio` |
| `ratio` | string | No | Alias of `aspect_ratio` |
| `resolution` | string | No | `480p` / `720p`. Default `720p` |
| `first_image` | string | No | First-frame image URL |
| `last_image` | string | No | Last-frame image URL |
| `reference_images` | string[] | No | Reference image URLs |
| `images` | string[] | No | Alias of `reference_images` |
| `reference_videos` | string[] | No | Reference video URLs (0–5) |
| `videos` | string[] | No | Alias of `reference_videos` |
| `reference_audios` | string[] | No | Reference audio URLs (0–5) |

## Billing

Creation precharges by resolution. After success, the task settles on actual token usage and the difference is refunded or charged. Reference-video jobs use a different per-million-token price (Jimmy coins, configurable in the console).

- Precharge mode: `per_second`
- Precharge models: `seedance2.5-flash-480p` / `seedance2.5-flash-720p`
- With reference videos: `seedance2.5-flash-video-480p` / `seedance2.5-flash-video-720p`
- Settlement models: `seedance2.5-flash-token`; with reference videos, `seedance2.5-flash-video-token`
- Omitted `duration` precharges **5 seconds**
- `duration = -1`, or an omitted duration on video edit, precharges **30 seconds**
- Reference videos add another **30 seconds** to the precharge

```text
precharge = unit price × prepaid seconds
amount due = completion_tokens / 1,000,000 × per-million-token price
after success, refund or charge the difference
```

## Examples

### Text to video

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-flash",
    "prompt": "A cinematic shot of a fox walking through a sunlit forest, camera slowly tracking",
    "duration": 8,
    "aspect_ratio": "16:9",
    "resolution": "720p"
  }'
```

### First and last frame

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-flash",
    "prompt": "Smoothly transition from the first frame to the last frame",
    "first_image": "https://example.com/first.jpg",
    "last_image": "https://example.com/last.jpg",
    "aspect_ratio": "adaptive",
    "duration": 5,
    "resolution": "720p"
  }'
```

### Video edit

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.5-flash",
    "prompt": "Edit @视频1: replace the cloudy sky with a clear sunset while keeping the camera move",
    "reference_videos": ["https://example.com/source.mp4"],
    "omni_reference_task_type": "edit",
    "aspect_ratio": "adaptive",
    "duration": -1
  }'
```
