---
title: 'Probe model pricing'
openapi: 'GET /api/openapi/model/catalog'
---

Probe **public model pricing** for active ViraltokAI OpenAPI billing models: model IDs, display names, types, default unit prices, and billing modes. Use this endpoint to discover which `model` values you can pass to create endpoints and to estimate cost before submitting tasks.

<Note>
This endpoint returns **platform default prices**. If your account has custom per-model pricing configured in the console, actual charges on create/query responses use your account rate instead. The list always shows the public baseline `unit_price`.
</Note>

### Authentication

No API key is required. You may call this endpoint without an `Authorization` header.

### Query parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `search` | string | No | Substring filter matched against `model_name`, `display_name`, `model_type`, and `remark`. Omit to return all active models. |

### Response fields

Each item in `data.list` describes one active billing model:

| Field | Type | Description |
| :--- | :--- | :--- |
| `model_name` | string | Public OpenAPI model ID — use this value in `model` on create endpoints |
| `display_name` | string | Human-readable model label |
| `model_type` | string | Product category (for example `video`, `image`, `audio`) |
| `price_mode` | string | Billing mode (see below) |
| `unit_price` | number | Default platform unit price in JimiCoin |
| `official_price` | number | Reference list price when configured; omitted when not set |
| `remark` | string | Optional notes about the model or pricing |
| `group` | string | Optional grouping label for related models |

### Billing modes (`price_mode`)

| Value | Meaning |
| :--- | :--- |
| `per_task` | Flat fee per request or task (default) |
| `per_second` | Unit price multiplied by video duration in seconds |
| `per_million_tokens` | Unit price multiplied by token count ÷ 1,000,000 |
| `per_10k_char` | Unit price per 10,000 characters (SoundClone) |
| `pay_as_you_go` | Usage-based billing from reported token or usage metadata |

Actual task cost appears in the `cost` field on create and query responses after billing runs.

### Example

List all models:

```bash
curl -X GET 'https://api.viraltok.ai/api/openapi/model/catalog'
```

Search for Seedance models:

```bash
curl -X GET 'https://api.viraltok.ai/api/openapi/model/catalog?search=seedance'
```

{
  "code": 20000,
