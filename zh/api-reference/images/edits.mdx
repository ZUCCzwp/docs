---
title: '编辑图片（同步）'
openapi: 'POST /api/open-api/v1/images/edits'
---

<Note>
本接口为**同步**调用，兼容 OpenAI `POST /v1/images/edits`。使用 `multipart/form-data` 上传源图，请求成功后**立即扣费**，并在响应 `data` 中直接返回编辑后的图片（`b64_json` 或 `url`）。
</Note>

<Note>
同步图片编辑可使用**生图直连地址** `https://img.viraltok.ai`（路径与 `api.viraltok.ai` 相同，例如 `POST /api/open-api/v1/images/edits`）。
</Note>

<Warning>
图片编辑通常需要 **30–120 秒**。请将客户端超时设置为 **≥ 180 秒**。单文件（`image` / `mask`）不超过 **20MB**。

若同步调用返回 **504 Gateway Timeout**，多为服务端经 **Cloudflare** 代理时 CF 超时断开，任务可能仍在后台执行。生产环境**建议优先使用** [创建图片任务](/zh/api-reference/images/create)（异步）创建后通过 [查询图片任务](/zh/api-reference/images/query) 获取结果。
</Warning>
