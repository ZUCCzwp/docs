---
title: 'Create Seedance Video'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

Create a Seedance 2.0 video generation task. On success you receive a `task_id`. Poll [Query Video Task](/en/api-reference/common/query) until `completed`, then read the video URL from `result.video_url`.

## Models and routes

Choose the backend route with the `model` field:

| Route | `model` values | Billing | Duration | Assets |
|-------|----------------|---------|----------|--------|
| **Full (Manxue)** | `sd2_mx_720p`, `sd2_mx_1080p`, `sd2_mx_2k`, `sd2_mx_4k` | Per second | 4–12 s | Must [audit assets](/en/api-reference/seedance/assets-audit) first; use `asset://{assetId}` |
| **Fast** | `sd2_mx_fast_720p`, `sd2_mx_fast_1080p` | Per second | 4–12 s | Same as Manxue; `reference_videos` not supported |
| **Video reference** | `sd2_mx_video_720p`, `sd2_mx_video_1080p`, `sd2_mx_video_2k`, `sd2_mx_video_4k` | Per second | 4–12 s | Same as Manxue; supports `reference_videos` |
| **Video reference Fast** | `sd2_mx_video_fast_720p`, `sd2_mx_video_fast_1080p` | Per second | 4–12 s | Same as Manxue; supports `reference_videos` |
| **SP economy** | `seedance2.0-sp`, `seedance2.0-fast-sp` | Per second × resolution | 4–15 s | See [SP Create Video](/en/api-reference/seedance/sp/create) |
| **SP official** | `seedance2.0-of-sp`, `seedance2.0-of-fast-sp` | Per second × resolution | 4–15 s | See [SP Create Video](/en/api-reference/seedance/sp/create) |
| **Mini** | `seedance2.0-mini` | Per second × resolution | 4–15 s | See [SP Create Video](/en/api-reference/seedance/sp/create) (same as SP) |
| **Mini video ref** | `seedance2.0-mini-video` | Per second × resolution | 4–15 s | Supports `reference_videos`, same as SP |
| **MD (standard)** | `seedance2.0-md` | Per task | 1–15 s | Public URLs; see [MD Create Video](/en/api-reference/seedance/md/create) |
| **MD (fast)** | `seedance2.0-fast-md` | Per task | 1–15 s | Same as MD standard |

<Note>
For **SP route** (economy and official), see [SP Create Video](/en/api-reference/seedance/sp/create). For **MD route**, see [MD Create Video](/en/api-reference/seedance/md/create).
</Note>

## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | See table above |
| `prompt` | string | Yes | Text prompt |
| `duration` | int | Yes | Length in seconds (default 5) |
| `resolution` | string | No | Output resolution for SP/Mini: `480p`, `720p` (default), `1080p` |
| `ratio` | string | No | e.g. `16:9`, `9:16`, `1:1`; full route also supports `4:3`, `3:4`, `21:9`, `Adaptive` |
| `images` | string[] | No | Reference images |
| `first_image` | string | No | First frame |
| `last_image` | string | No | Last frame |
| `reference_videos` | string[] | No | Reference videos |
| `reference_audios` | string[] | No | Reference audio |

### Asset link format

- **Manxue / Fast / Video reference series**: Media fields must use `asset://{assetId}` after [submitting for audit](/en/api-reference/seedance/assets-audit) and waiting until status is `Active` via [audit status](/en/api-reference/seedance/assets-status).
- **`reference_videos`**: Only `sd2_mx_video_*` and `sd2_mx_video_fast_*` models support reference videos; standard Manxue and Fast models do not.
- **SP economy**: See [SP Create Video](/en/api-reference/seedance/sp/create).
- **MD**: Pass publicly reachable `https://` URLs; reference audio is not supported. See [MD Create Video](/en/api-reference/seedance/md/create).

### Constraints

- Do not combine `images` (reference mode) with `first_image` / `last_image` (frame mode).

## Examples

### MD — reference images

See [MD Create Video](/en/api-reference/seedance/md/create). Minimal example:

```bash
curl -X POST 'https://www.jimmyai.cn/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-md",
    "prompt": "Generate a rhythmic short clip based on the references",
    "duration": 8,
    "ratio": "16:9",
    "images": ["https://example.com/scene.jpg"],
    "reference_videos": ["https://example.com/motion.mp4"]
  }'
```

### Full (Manxue) — audited reference image

```bash
curl -X POST 'https://www.jimmyai.cn/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2_mx_720p",
    "prompt": "Slow dolly in, subtle lighting change",
    "duration": 5,
    "ratio": "16:9",
    "images": ["asset://your-asset-id-here"]
  }'
```

## Response

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "sd2_mx_720p",
    "created_at": 1710000000
  }
}
```

## Poll for result

```bash
curl -X GET 'https://www.jimmyai.cn/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

Statuses: `queued` → `processing` → `completed` or `failed`. Video URL is in `data.result.video_url` when completed.

<Note>
Result URLs are retained for about **3 days**. Download promptly.
</Note>
