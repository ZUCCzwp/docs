## 适合谁参与

- 在 **抖音、小红书、B 站、YouTube、Twitter/X、Telegram、微信** 等平台分享 AI 教程或测评的创作者
- 维护开发者社群、开源项目或技术博客的 KOL
- 为企业客户提供 ViraltokAI API 接入方案的集成商

## 参与前准备

1. 注册 [ViraltokAI 控制台](https://api.viraltok.ai/register) 账号
2. 熟悉 [API 文档](/zh/api-reference/introduction) 与 [模型定价](/zh/api-reference/common/model-catalog)
3. 准备可证明推广能力的**社媒主页链接**与**账号截图**

<Info>
推广返利以**吉米币（JimiCoin）**结算，划转后可消费全部 Open API 能力（视频、图像、LLM 等）。具体比例与次数由审核时确定的**推广等级**决定，以控制台显示为准。
</Info>
