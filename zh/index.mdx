# 快速开始

欢迎使用我们的API服务！本指南将帮助您快速开始使用图像和视频生成功能。

## 第一步：获取API密钥

1. [注册账号](https://api.viraltok.ai/register)
2. 登录您的账户,访问 [API密钥管理页面](https://api.viraltok.ai/console?tab=apikeys)
3. 创建新的API密钥
4. 保存您的密钥（密钥只显示一次）

## 第二步：账号充值

1. 登录您的账户,访问[充值页面](https://api.viraltok.ai/recharge)
2. 选择充值金额（最低 1 美金起）
3. 完成支付（支持支付宝、微信）


## 第三步：发送请求
获取接入信息
API 地址（所谓的 Base_Url）：https://api.viraltok.ai
API 密钥：您刚创建的密钥

### 视频生成示例

<Note>
**备注（兼容路径）**：旧 `/api/open-api/v1/...` 产品路径（如 `/seedance/videos`、`/kling/videos`）以及 `/api/open-api/v1/videos|/images` 仍可调用。
</Note>

使用统一入口 `POST /api/v1/videos`，通过 `model` 选择产品。

```bash theme={null}
curl --request POST \
  --url https://api.viraltok.ai/api/v1/videos \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '
{
  "model": "seedance-2.5",
  "prompt": "一只猫在阳光下走动",
  "duration": 5,
  "aspect_ratio": "16:9"
}
'
```

### 图片生成示例

```bash theme={null}
curl --request POST \
  --url https://api.viraltok.ai/api/v1/images \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '
{
  "model": "gpt-image-2",
  "prompt": "赛博朋克城市雨夜",
  "aspect_ratio": "16:9",
  "resolution": "2k"
}
'
```

## 第四步：查询任务状态

由于我们使用异步处理模式，您需要查询任务状态来获取结果：

```bash theme={null}
curl --request GET \
  --url https://api.viraltok.ai/api/v1/videos/{taskId} \
  --header 'Authorization: Bearer <token>'
```

图片任务使用 `GET /api/v1/images/{taskId}`。
