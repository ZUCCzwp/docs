---
title: 'MD Create Video'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

Create a Seedance **MD** video task. On success you receive a `task_id`. Poll [Query Video Task](/en/api-reference/common/query) until `completed`, then read the video URL from `result.video_url`.

<Note>
This endpoint is shared with [Create Seedance Full Video](/en/api-reference/seedance/create): `POST /api/open-api/v1/seedance/videos`. For Full (Manxue), Mini, and SP routes, see their respective docs.
</Note>

## Models

| Route | `model` values | Billing | Duration |
|-------|----------------|---------|----------|
| MD standard | `seedance2.0-md` | Per task | **5** / **10** / **15** s |
| MD fast | `seedance2.0-fast-md` | Per task | **10** or **15** s |

MD output is fixed at **720p**. Billing is per task, independent of duration.

## Model features

| Model | Billing | Duration | Asset support | Aspect ratios |
|-------|---------|----------|---------------|---------------|
| `seedance2.0-md` | Per task | 5 / 10 / 15 s | Up to **9** reference images; no reference videos, audio, or first/last frames | `1:1`, `3:4`, `4:3`, `9:16`, `16:9`, `21:9` |
| `seedance2.0-fast-md` | Per task | 10 or 15 s | Up to **4** reference images, **3** reference videos, **1** reference audio | `16:9`, `9:16`, `1:1` |

## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | See table above |
| `prompt` | string | Yes | Text prompt. Max **6000** characters for `seedance2.0-md`; max **5000** for `seedance2.0-fast-md` |
| `duration` | int | Yes | Length in seconds. `seedance2.0-md` supports **5**, **10**, **15** only; `seedance2.0-fast-md` supports **10** or **15** only. Default 5 |
| `ratio` | string | No | `seedance2.0-md`: `1:1`, `3:4`, `4:3`, `9:16`, `16:9`, `21:9` (omit for the model default). `seedance2.0-fast-md`: `16:9` (default), `9:16`, or `1:1` |
| `images` | string[] | No | Reference images. Max **9** for `seedance2.0-md`; max **4** for `seedance2.0-fast-md` |
| `first_image` | string | No | `seedance2.0-fast-md` only: first frame; must be paired with `last_image` |
| `last_image` | string | No | `seedance2.0-fast-md` only: last frame; must be paired with `first_image` |
| `reference_videos` | string[] | No | `seedance2.0-fast-md` only: reference videos, max **3** |
| `reference_audios` | string[] | No | `seedance2.0-fast-md` only: reference audio, max **1** clip |

<Warning>
The `resolution` field is ignored; output is always 720p. `seedance2.0-md` does not support first/last frames, reference videos, or reference audio.
</Warning>

## Assets

- Pass publicly reachable `https://` image or video URLs directly. **Images do not support GIF format**.
- SP asset library (`asset://`) and Full-route audit flows do not apply to MD.

## Constraints

### `seedance2.0-md`

- `duration` is **5**, **10**, or **15** seconds only.
- `images` max **9**.
- `ratio` supports `1:1`, `3:4`, `4:3`, `9:16`, `16:9`, `21:9`; omit to use the model default.
- Prompt at most 6000 characters.
- `first_image` / `last_image`, `reference_videos`, and `reference_audios` are not supported.

### `seedance2.0-fast-md`

- Do not combine `images` (reference mode) with `first_image` / `last_image` (frame mode).
- **First frame only is not supported**; in frame mode, `first_image` and `last_image` **must both be provided**.
- `ratio` must be one of `16:9`, `9:16`, `1:1`.
- Prompt at most 5000 characters.
- `duration` **10** or **15** s only; `images` max 4; `reference_videos` max 3; `reference_audios` max 1 clip.
- `reference_videos`: combined duration ≤ **15** s, combined size ≤ **200MB**; each resolution between **720px and 2160px**, frame rate **24–60 FPS**.
- `reference_audios`: combined duration ≤ **15** s; frame mode does not support audio references.

## Examples

### MD standard — text or reference images

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-md",
    "prompt": "Subject turns slowly, breeze in hair, cinematic lighting",
    "duration": 5,
    "ratio": "16:9",
    "images": [
      "https://example.com/ref-1.jpg",
      "https://example.com/ref-2.jpg"
    ]
  }'
```

### MD fast — first and last frame image-to-video

<Note>
In frame mode, `first_image` and `last_image` **must both be provided**. First frame only is not supported. Frame mode applies to `seedance2.0-fast-md` only.
</Note>

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-fast-md",
    "prompt": "Rainy street at night, girl looks back and smiles, slow dolly in",
    "duration": 10,
    "ratio": "9:16",
    "first_image": "https://example.com/start.png",
    "last_image": "https://example.com/end.png"
  }'
```

## Response

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "seedance2.0-md",
    "created_at": 1710000000
  }
}
```

## Poll for result

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

Statuses: `queued` → `processing` → `completed` or `failed`. Video URL is in `data.result.video_url` when completed.

<Note>
Result URLs are retained for about **3 days**. Download promptly.
</Note>
