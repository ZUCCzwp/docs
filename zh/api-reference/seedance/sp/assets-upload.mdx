---
title: 'SP 上传素材'
openapi: 'POST /api/open-api/v1/seedance/sp/assets/upload'
---

将图片、视频、音频或文本素材上传至 Seedance SP 经济版素材库。返回的 `asset_id` 可在 [SP 创建视频](/zh/api-reference/seedance/sp/create) 中通过 `asset://{asset_id}` 引用。

<Note>
本接口适用于 **SP 经济版**（`sd2_sp_*`）以及 **Seedance 2.0 GZ**（`seedance2.0-gz*`，公网 URL 也可在创建任务时由平台代为提交审核）。满血版请使用 [提交素材审核](/zh/api-reference/seedance/assets-audit)。
</Note>

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 素材名称 |
| `type` | string | 是 | 素材类型：`image`、`video`、`audio`、`text` |
| `url` | string | 是 | 素材公网 URL |

## 请求示例

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/sp/assets/upload' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "参考图1",
    "type": "image",
    "url": "https://example.com/ref.jpg"
  }'
```

## 响应示例

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "asset_id": "asset_abc123"
  }
}
```

素材提交后会自动进入处理流程。请通过 [查询素材详情](/zh/api-reference/seedance/sp/assets-detail) 根据 `status` 判断是否已可用；**只有 `ACTIVE` 状态的素材可以提交视频生成任务**。

## 素材状态说明

| 状态 | 说明 |
|------|------|
| `NONE` | 素材记录已创建，但尚未开始上传或处理。请稍后查询，当前不可提交任务 |
| `UPLOADING` | 素材正在上传。请等待状态更新，当前不可提交任务 |
| `PROCESSING` | 素材已提交，正在处理中。请继续查询，当前不可提交任务 |
| `ACTIVE` | 素材已处理完成且可用。只有此状态可以提交视频生成任务 |
| `FAILED` | 素材处理失败。请处理后重新提交素材 |
| `EXPIRED` | 素材已过期，当前不可用。请重新查询并等待重新处理为 `ACTIVE`，必要时重新提交 |
| `DELETED` | 素材已被删除或已失效，当前不可用。请重新提交并等待状态变为 `ACTIVE` |

## 后续步骤

1. 调用 [查询素材详情](/zh/api-reference/seedance/sp/assets-detail) 或 [批量查询素材状态](/zh/api-reference/seedance/sp/assets-status)
2. 等待 `status` 变为 `ACTIVE`
3. 在创建视频请求的 `images`、`first_image` 等字段中使用 `asset://{asset_id}`
