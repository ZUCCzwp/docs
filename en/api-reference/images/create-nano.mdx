---
title: 'Create Nano Banana Image'
openapi: 'POST /api/open-api/v1/images'
---

## Request Body

<ParamField body="model" type="string" required>
  Model name. Use `nano-banana-2`, `nano-banana`, or `nano-banana-pro`.
</ParamField>

<ParamField body="prompt" type="string" required>
  The text prompt to generate the image.
</ParamField>

<ParamField body="size" type="string">
  Image aspect ratio/size. Supported values: `1:1`, `3:2`, `2:3`, `4:3`, `3:4`, `16:9`, `9:16`.
  
  Default: `9:16`
</ParamField>

<ParamField body="images" type="array">
  List of reference image URLs (up to 6 images).
</ParamField>

<ParamField body="resolution" type="string">
  Image resolution. Supported values: `1k`, `2k`, `4k`.
  
  Default: `1k`
</ParamField>
