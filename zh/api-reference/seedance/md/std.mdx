---
title: 'STD 创建视频'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

创建 Seedance **STD** 视频生成任务。提交成功后返回 `task_id`，请使用 [查询视频任务](/zh/api-reference/common/query) 轮询状态，完成后从 `result.video_url` 获取视频地址。

<Note>
本接口与 [创建 Seedance 视频](/zh/api-reference/seedance/create) 共用 `POST /api/open-api/v1/seedance/videos`。通过 `model: "seedance2.0-std"` 选择标准版线路。
</Note>

## 模型

| 线路 | `model` 取值 | 计费 | 时长 | 输出 |
|------|-------------|------|------|------|
| STD 标准版 | `seedance2.0-std` | 按次 | 4–15 秒 | 固定 720p |

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | 固定为 `seedance2.0-std` |
| `prompt` | string | 是 | 视频生成提示词 |
| `duration` | int | 是 | 时长（秒），4–15，默认 5 |
| `ratio` | string | 否 | 画面比例：`16:9`（默认）、`9:16`、`1:1`、`4:3`、`3:4`、`21:9` |
| `images` | string[] | 否 | 参考图列表，最多 **9** 张 |
| `first_image` | string | 否 | 首帧图片 |
| `last_image` | string | 否 | 尾帧图片 |
| `reference_videos` | string[] | 否 | 参考视频列表 |
| `reference_audios` | string[] | 否 | 参考音频列表，最多 **3** 段 |

<Warning>
`resolution` 字段无效，STD 输出固定为 720p。
</Warning>

## 素材说明

- 直接传入可公网访问的 `https://` 图片、视频或音频 URL。
- `reference_videos` 仅支持视频 URL。图片请传入 `images`。
- 不使用 SP 素材库 `asset://` 流程；满血版 `asset://` 审核流程也不适用于 STD。

## 约束

- `images`（参考图模式）与 `first_image` / `last_image`（首尾帧模式）**不可同时使用**。
- 首尾帧模式下可以传 `first_image`、`last_image`，或同时传入两者。
- 首尾帧模式不支持 `reference_audios`。
- `ratio` 仅支持 `21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`。
- `images` 最多 9 张。
- `reference_audios` 最多 3 段。
- `reference_videos` 仅支持视频 URL，不支持图片 URL。

## 示例

### 参考图生视频

```bash
curl -X POST 'https://www.jimmyai.cn/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-std",
    "prompt": "人物在晨光中穿过城市街道，镜头稳定跟拍，电影感光影",
    "duration": 8,
    "ratio": "16:9",
    "images": [
      "https://example.com/ref-1.jpg",
      "https://example.com/ref-2.jpg"
    ]
  }'
```

### 视频与音频参考

```bash
curl -X POST 'https://www.jimmyai.cn/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-std",
    "prompt": "参考视频中的运动节奏，生成一段有音乐律动的产品展示视频",
    "duration": 10,
    "ratio": "9:16",
    "reference_videos": [
      "https://example.com/motion.mp4"
    ],
    "reference_audios": [
      "https://example.com/music.mp3"
    ]
  }'
```

### 首尾帧生视频

```bash
curl -X POST 'https://www.jimmyai.cn/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-std",
    "prompt": "从室内窗边平滑过渡到夜晚城市天台，镜头缓慢推进",
    "duration": 6,
    "ratio": "21:9",
    "first_image": "https://example.com/start.png",
    "last_image": "https://example.com/end.png"
  }'
```

## 响应示例

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "seedance2.0-std",
    "created_at": 1710000000
  }
}
```

## 查询任务

```bash
curl -X GET 'https://www.jimmyai.cn/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

任务状态：`queued` → `processing` → `completed` / `failed`。完成后从 `data.result.video_url` 获取视频地址。

<Note>
视频结果 URL 保存约 **3 天**，请及时转存。
</Note>
