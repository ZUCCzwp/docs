# Quickstart

Welcome to our API service! This guide will help you quickly get started with image and video generation features.

## Step 1: Get your API Key

1. [Register an account](https://api.viraltok.ai/register)
2. Log in to your account, and visit the [API Key Management Page](https://api.viraltok.ai/console?tab=apikeys)
3. Create a new API Key
4. Save your key (it will only be displayed once)

## Step 2: Account Recharge

1. Log in to your account, and visit the [Recharge Page](https://api.viraltok.ai/recharge)
2. Select the recharge amount (minimum $1)
3. Complete the payment (supports Alipay, WeChat Pay)

## Step 3: Send a Request
Get connection info
API Base URL: https://api.viraltok.ai
API Key: The key you just created

### Video Generation Example

<Note>
**Note (compatibility)**: Legacy `/api/open-api/v1/...` product paths (e.g. `/seedance/videos`, `/kling/videos`) and `/api/open-api/v1/videos|/images` still work.
</Note>

Use the unified endpoint `POST /api/v1/videos` and select the product with `model`.

```bash theme={null}
curl --request POST \
  --url https://api.viraltok.ai/api/v1/videos \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '
{
  "model": "seedance-2.5",
  "prompt": "A cat walking in sunlight",
  "duration": 5,
  "aspect_ratio": "16:9"
}
'
```

### Image Generation Example

```bash theme={null}
curl --request POST \
  --url https://api.viraltok.ai/api/v1/images \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '
{
  "model": "gpt-image-2",
  "prompt": "Cyberpunk city at night in the rain",
  "aspect_ratio": "16:9",
  "resolution": "2k"
}
'
```

## Step 4: Query Task Status

Since we use an asynchronous processing mode, you need to query the task status to get the results:

```bash theme={null}
curl --request GET \
  --url https://api.viraltok.ai/api/v1/videos/{taskId} \
  --header 'Authorization: Bearer <token>'
```

For image tasks, use `GET /api/v1/images/{taskId}`.
