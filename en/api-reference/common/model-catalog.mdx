---
title: 'Probe model pricing'
openapi: 'GET /api/v1/models'
---

Probe the public ViraltokAI OpenAPI **model catalog**: billing, create endpoint, and field limits. Rows that share both `series` and `group` are one item. Pass `billings[].model_name` on create. A row with no `series` stays separate, and its `model_name` is the create value.

<Note>
This endpoint returns **platform default prices**. If your account has custom per-model pricing configured in the console, actual charges on create/query responses use your account rate instead. The list always shows the public baseline `unit_price`.
</Note>

<Note>
**Compatibility note**: `GET /api/openapi/model/catalog` still works and matches `GET /api/v1/models`.
</Note>

### Authentication

No API key is required. You may call this endpoint without an `Authorization` header.

### Query parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `search` | string | No | Substring filter matched against `model_name`, `display_name`, `model_type`, `series`, and `remark`. Omit to return all active models. |

### Response fields

Each item in `data.list` is one product. The same `series` and the same `group` merge into one item. A different series or group stays separate. A model with no `series` stays one row per billing name.

| Field | Type | Description |
| :--- | :--- | :--- |
| `model_name` | string | Equals `group` after a merge. When `billings` is absent, pass this value as `model` on create |
| `display_name` | string | Label. After a merge with a `group`, this matches `group` |
| `model_type` | string | Product category (for example `video`, `image`, `audio`, `llm`) |
| `series` | string | Product series. Wan 3.0 variants can share `wan3` and still stay separate when `group` differs |
| `group` | string | Catalog group. Merged `model_name`, `display_name`, and `scheme.model` use this value |
| `price_mode` | string | Billing mode (see below) |
| `unit_price` | number | Default platform unit price in JimiCoin. After a merge, the lowest positive billing price |
| `official_price` | number | Reference list price when configured; omitted when not set |
| `remark` | string | Optional notes |
| `scheme` | object | Call contract. See below. Products with no caller-chosen duration omit `duration` |
| `billings` | array | Billing options. Pass one of these `model_name` values on create |

### `billings[]`

| Field | Type | Description |
| :--- | :--- | :--- |
| `model_name` | string | Value to send as `model` on the create endpoint |
| `display_name` | string | Label for this billing option |
| `price_mode` | string | Billing mode for this option |
| `unit_price` | number | Default platform unit price for this option |
| `official_price` | number | Reference list price; omitted when unset |
| `remark` | string | Optional notes |
| `duration` | object | This billing option's own duration range. Same shape as `scheme.duration` |

### `scheme`

| Field | Type | Description |
| :--- | :--- | :--- |
| `endpoint` | string | Create path, such as `/api/v1/videos` |
| `method` | string | HTTP method, usually `POST` |
| `model` | string | Same value as `group` |
| `duration` | object | `min`, `max`, `default`, and `unit` (`seconds`). Discrete steps also include `options`. When `adaptive` is true, `duration` may be `-1` for automatic length |
| `resolutions` | array | Allowed resolutions |
| `aspect_ratios` | array | Allowed aspect ratios |
| `constraints` | array | Limits for create-request fields. `field` is the JSON name and may include `required`, `options`, `min`, `max`, `max_count`, and `max_length` |

When a duration range exists, `constraints` includes an entry with `field` `duration` whose `min` and `max` match `scheme.duration`. The merged `scheme.duration` is the union of the billing ranges. Read `billings[].duration` for one billing option's own range.

### Billing modes (`price_mode`)

| Value | Meaning |
| :--- | :--- |
| `per_task` | Flat fee per request or task (default) |
| `per_second` | Unit price multiplied by video duration in seconds |
| `per_million_tokens` | Unit price multiplied by token count ÷ 1,000,000 |
| `per_10k_char` | Unit price per 10,000 characters (SoundClone) |
| `pay_as_you_go` | Usage-based billing from reported token or usage metadata |

Actual task cost appears in the `cost` field on create and query responses after billing runs.

### Example

List all models:

```bash
curl -X GET 'https://api.viraltok.ai/api/v1/models'
```

Search for Seedance models:

```bash
curl -X GET 'https://api.viraltok.ai/api/v1/models?search=seedance'
```
