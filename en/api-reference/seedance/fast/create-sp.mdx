<Note>
**Note (compatibility)**: The legacy path `/api/open-api/v1/seedance/videos` still works and matches `POST /api/v1/videos`; prefer the unified endpoint for new integrations.
</Note>


Create a Seedance **Full Super-Resolution SP Fast** video generation task. On success you receive a `task_id`. Poll [Query Video Task](/en/api-reference/common/query) until `completed`, then read the video URL from `result.video_url`.

<Note>
This uses the same endpoint as [Create Full Super-Resolution SP Video](/en/api-reference/seedance/sp/create): `POST /api/v1/videos`. Non-Fast SP models are on the SP page; Official Fast is [Create Seedance 2.0 Official Fast Video](/en/api-reference/seedance/fast/create-gz).
</Note>

## Model selection

Use **`sd2-sp-fast`** in the online studio and in `POST /api/v1/videos`. The API selects the billing model based on whether `reference_videos` contains a nonempty video reference.

| Mode | Billing model | Billing | Duration | Requirements |
|-------|---------------|---------|----------|--------------|
| Without reference video | `sd2_sp_fast_720p` | Per second | 4–15 s | Omit `reference_videos` or leave it empty |
| With reference video | `sd2_sp_video_fast_720p` | Per second | 4–15 s | Include a video reference in `reference_videos` |

Both modes output video at **720p**.

## Billing

The API deducts credits using the billing model selected above. The create response returns the actual billing model in `data.model`.

| Item | Description |
|------|-------------|
| Calculation | **Unit price (credit/s) × `duration`** |
| Unit Price | Based on the price for the corresponding model name in the console |
| Duration | `duration` field, ranging from 4 to 15 seconds |

## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `sd2-sp-fast` |
| `resolution` | string | No | Fixed at `720p`. You can omit it. |
| `prompt` | string | Yes | Text prompt |
| `duration` | int | Yes | Length in seconds, 4–15 (default 5) |
| `ratio` | string | No | Aspect ratio, e.g. `16:9`, `9:16`, `1:1` |
| `images` | string[] | No | Reference images |
| `first_image` | string | No | First frame |
| `last_image` | string | No | Last frame |
| `reference_videos` | string[] | No | Reference videos. A nonempty video reference selects the video reference billing model. |
| `reference_audios` | string[] | No | Reference audio; must pair with images/videos or frames |

## Assets

- Pass public `https://` URLs directly.
- Or [upload assets](/en/api-reference/seedance/sp/assets-upload) first, then use `asset://{asset_id}`.

## Constraints

- Do not combine `images` (reference mode) with `first_image` / `last_image` (frame mode).
- `reference_audios` cannot be used alone; pair with reference images/videos or frames.

## Example

### Using uploaded assets

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-sp-fast",
    "prompt": "Slow dolly in, subtle lighting change",
    "duration": 8,
    "ratio": "16:9",
    "images": ["asset://your-asset-id-here"]
  }'
```

### Using a reference video

```bash
curl -X POST 'https://api.viraltok.ai/api/v1/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2-sp-fast",
    "prompt": "Follow the camera motion in the reference video with evening lighting",
    "duration": 8,
    "ratio": "16:9",
    "reference_videos": ["https://example.com/reference.mp4"]
  }'
```

## Response

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "sd2_sp_fast_720p",
    "created_at": 1710000000
  }
}
```

## Poll for result

```bash
curl -X GET 'https://api.viraltok.ai/api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

Statuses: `queued` → `processing` → `completed` or `failed`. Video URL is in `data.result.video_url` when completed.

<Note>
Result URLs are retained for about **3 days**. Download promptly.
</Note>
