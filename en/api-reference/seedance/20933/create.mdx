<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status and read the final video URL from `result.video_url`.
</Note>

This uses the same endpoint as [Create Seedance Full Video](/en/api-reference/seedance/create): `POST /api/open-api/v1/seedance/videos`. Select this route with `model: "seedance2.0-933"`.

## Supported models

| model | Notes |
|-------|-------|
| `seedance2.0-933` | Seedance 2.0 933 video generation with text-to-video plus optional reference images / videos / audios |

Aliases such as `seedance-2.0-933`, `seedance20933`, and `seedance2_0_933` normalize to `seedance2.0-933`.

Billing model names are also accepted as `model`: `seedance2.0-933-480p`, `seedance2.0-933-720p`, `seedance2.0-933-1080p` (resolution is parsed from the model when `resolution` is omitted; an explicit `resolution` field takes precedence).

## Parameter constraints

- **Prompt**: Required, 1–5000 characters.
- **Duration**: 4–15 seconds (default `4`).
- **Aspect ratio** (`aspect_ratio` / `ratio`): `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16` (default `16:9`).
- **Resolution**: `480p`, `720p`, `1080p` (default `480p`).
- **Reference images**: `reference_images` or `images`, max **9**, public HTTPS URLs.
- **Reference videos**: `reference_videos` or `videos`, max **3**.
- **Reference audios**: `reference_audios` or `audios`, max **3**.
- **Face processing** (`face_processing`): boolean, default `true`.
- **Generate audio** (`generate_audio`): boolean, default `false`.
- **Reference mode** (`reference_mode`): `image` or `frame`, default `image`.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `seedance2.0-933`, or billing names `seedance2.0-933-480p` / `-720p` / `-1080p` |
| `prompt` | string | Yes | Text prompt |
| `duration` | integer | No | Duration in seconds, default 4 |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `resolution` | string | No | `480p` / `720p` / `1080p`, default `480p` |
| `face_processing` | boolean | No | Enable face processing, default `true` |
| `generate_audio` | boolean | No | Generate audio, default `false` |
| `reference_mode` | string | No | `image` / `frame`, default `image` |
| `reference_images` | string[] | No | Reference image URLs (0–9) |
| `images` | string[] | No | Alias for `reference_images` when the latter is empty |
| `reference_videos` | string[] | No | Reference video URLs (0–3) |
| `videos` | string[] | No | Alias for `reference_videos` |
| `reference_audios` | string[] | No | Reference audio URLs (0–3) |
| `audios` | string[] | No | Alias for `reference_audios` |

## Billing

- Mode: `per_second`
- Billed by **resolution** (unit price from console):
  - `seedance2.0-933-480p`
  - `seedance2.0-933-720p`
  - `seedance2.0-933-1080p`
- Request `model` remains `seedance2.0-933`; the system selects the billing model from `resolution`

```text
cost = resolution_unit_price × duration
```

## Example request

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-933",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 4,
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "face_processing": true,
    "generate_audio": false,
    "reference_mode": "image",
    "reference_images": ["https://example.com/reference.png"],
    "reference_videos": ["https://example.com/reference.mp4"],
    "reference_audios": ["https://example.com/reference.mp3"]
  }'
```
