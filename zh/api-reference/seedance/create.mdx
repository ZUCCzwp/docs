---
title: '创建 Seedance 满血版视频'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

创建 Seedance **满血版**（Manxue）视频生成任务。提交成功后返回 `task_id`，请使用 [查询视频任务](/zh/api-reference/common/query) 轮询状态，完成后从 `result.video_url` 获取视频地址。

<Warning>
**请勿**把 `seedance-2.5` / `seedance-2.5-sp` / `seedance2.5-gz` / `seedance2.5-md` / `seedance2.5-30s` / `seedance-2.5-720p` 等 Seedance 2.5 型号发到本接口。标准版 / SP 使用 [创建 Seedance 2.5 视频](/zh/api-reference/seedance/25/create)，GZ 使用 [创建 Seedance 2.5 GZ 视频](/zh/api-reference/seedance/25/create-gz)，MD 固定时长使用 [创建 Seedance 2.5 MD 视频](/zh/api-reference/seedance/25/create-ar)：`POST /api/open-api/v1/seedance25/videos`。误用 `/seedance/videos` 会落到 Seedance 2.0 满血线路。
</Warning>

<Note>
其他线路文档：**Mini** 见 [Mini 创建视频](/zh/api-reference/seedance/mini/create)；**SP 经济版** 见 [SP 创建视频](/zh/api-reference/seedance/sp/create)；**MD** 见 [MD 创建视频](/zh/api-reference/seedance/md/create)；**Seedance 2.0 GZ** 见 [创建 Seedance 2.0 GZ 视频](/zh/api-reference/seedance/gz720/create)；**Seedance 2.5** 见 [创建 Seedance 2.5 视频](/zh/api-reference/seedance/25/create)；**Seedance 2.5 GZ** 见 [创建 Seedance 2.5 GZ 视频](/zh/api-reference/seedance/25/create-gz)。
</Note>

## 模型与线路

通过 `model` 字段选择满血版子线路：

| 线路 | `model` 取值 | 计费 | 时长 | 素材要求 |
|------|-------------|------|------|----------|
| **满血版** | `sd2_mx_720p`、`sd2_mx_1080p`、`sd2_mx_2k`、`sd2_mx_4k` | 按秒 | 4–15 秒 | 参考素材须先 [素材审核](/zh/api-reference/seedance/assets-audit)，使用 `asset://{assetId}` |
| **Fast** | `sd2_mx_fast_720p`、`sd2_mx_fast_1080p` | 按秒 | 4–15 秒 | 同上；不支持 `reference_videos` |
| **视频参考** | `sd2_mx_video_720p`、`sd2_mx_video_1080p`、`sd2_mx_video_2k`、`sd2_mx_video_4k` | 按秒 | 4–15 秒 | 同上；支持 `reference_videos` |
| **视频参考 Fast** | `sd2_mx_video_fast_720p`、`sd2_mx_video_fast_1080p` | 按秒 | 4–15 秒 | 同上；支持 `reference_videos` |

## 计费说明

满血版按 **秒** 计费，不同 `model` 对应不同单价（如 `sd2_mx_720p`、`sd2_mx_1080p` 等）。

| 项目 | 说明 |
|------|------|
| 计费方式 | **单价（元/秒）× `duration`** |
| 单价来源 | 以 [控制台定价](https://api.viraltok.ai) 中对应模型名为准 |
| 时长 | `duration` 字段，范围 4–15 秒 |

## 请求参数说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | 见上表 |
| `prompt` | string | 是 | 视频生成提示词 |
| `duration` | int | 是 | 时长（秒），4–15，默认 5 |
| `ratio` | string | 否 | 画面比例，如 `16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`21:9`、`Adaptive` |
| `images` | string[] | 否 | 参考图列表 |
| `first_image` | string | 否 | 首帧图片 |
| `last_image` | string | 否 | 尾帧图片 |
| `reference_videos` | string[] | 否 | 参考视频列表；仅 `sd2_mx_video_*` 系列支持 |
| `reference_audios` | string[] | 否 | 参考音频列表 |

### 素材链接格式

- **满血版 / Fast / 视频参考系列**：`images`、`first_image`、`last_image`、`reference_videos`、`reference_audios` 须使用 `asset://{assetId}` 格式。须先调用 [提交素材审核](/zh/api-reference/seedance/assets-audit)，再 [查询审核状态](/zh/api-reference/seedance/assets-status) 直至 `Active`。
- **`reference_videos`**：仅 `sd2_mx_video_*`、`sd2_mx_video_fast_*` 模型支持；满血版与 Fast 系列不支持。

### 通用约束

- `images`（参考图模式）与 `first_image` / `last_image`（首尾帧模式）**不可同时使用**，请二选一。

## 示例

### 满血版 — 参考图（须先审核）

```bash
# 1. 提交审核（见 assets-audit 文档）
# 2. 轮询审核状态直至 Active
# 3. 创建视频
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2_mx_720p",
    "prompt": "镜头缓慢推进，光影变化细腻",
    "duration": 5,
    "ratio": "16:9",
    "images": ["asset://your-asset-id-here"]
  }'
```

## 响应示例

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "sd2_mx_720p",
    "created_at": 1710000000
  }
}
```

## 查询任务

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

任务状态：`queued` → `processing` → `completed` / `failed`。完成后从 `data.result.video_url` 获取视频地址。

<Note>
视频结果 URL 保存约 **3 天**，请及时转存。
</Note>
