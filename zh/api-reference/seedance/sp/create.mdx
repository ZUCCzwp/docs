---
title: 'SP 创建视频'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

创建 Seedance **SP** 视频生成任务（经济版）。提交成功后返回 `task_id`，请使用 [查询视频任务](/zh/api-reference/common/query) 轮询状态，完成后从 `result.video_url` 获取视频地址。

<Note>
本接口与 [创建 Seedance 满血版视频](/zh/api-reference/seedance/create) 共用 `POST /api/open-api/v1/seedance/videos`。满血版见满血版文档，Mini 见 [Mini 创建视频](/zh/api-reference/seedance/mini/create)，MD 见 [MD 创建视频](/zh/api-reference/seedance/md/create)。
</Note>

## 模型与线路

通过 `model` 字段选择经济版子线路：

| 线路 | `model` 取值 | 计费 | 时长 | 素材要求 |
|------|-------------|------|------|----------|
| **经济版** | `sd2_sp_480p`、`sd2_sp_720p`、`sd2_sp_1080p`、`sd2_sp_2k`、`sd2_sp_4k` | 按秒 | 4–15 秒 | 支持公网 URL 或素材库 |
| **经济版 Fast** | `sd2_sp_fast_780p` | 按秒 | 4–15 秒 | 同上；不支持 `reference_videos` |
| **视频参考** | `sd2_sp_video_480p`、`sd2_sp_video_720p`、`sd2_sp_video_1080p`、`sd2_sp_video_2k`、`sd2_sp_video_4k` | 按秒 | 4–15 秒 | 同上；支持 `reference_videos` |
| **视频参考 Fast** | `sd2_sp_video_fast_780p` | 按秒 | 4–15 秒 | 同上；支持 `reference_videos` |

## 计费说明

根据选择的 `model` 直接扣除对应算力额度：

| 项目 | 说明 |
|------|------|
| 计费方式 | **单价（元/秒）× `duration`** |
| 单价来源 | 以控制台定价中对应模型名为准 |
| 时长 | `duration` 字段，范围 4–15 秒 |


## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | 见上表 |
| `prompt` | string | 是 | 视频生成提示词 |
| `duration` | int | 是 | 时长（秒），4–15，默认 5 |
| `resolution` | string | 否 | 输出分辨率：`480p`、`720p`（默认）、`1080p` |
| `ratio` | string | 否 | 画面比例，如 `16:9`、`9:16`、`1:1` |
| `images` | string[] | 否 | 参考图列表 |
| `first_image` | string | 否 | 首帧图片 |
| `last_image` | string | 否 | 尾帧图片 |
| `reference_videos` | string[] | 否 | 参考视频列表 |
| `reference_audios` | string[] | 否 | 参考音频；须搭配参考图/视频或首尾帧 |

## 素材说明

- 可直接传入公网 `https://` URL。
- 也可先 [上传素材](/zh/api-reference/seedance/sp/assets-upload)，再使用 `asset://{asset_id}`。

## 约束

- `images`（参考图模式）与 `first_image` / `last_image`（首尾帧模式）**不可同时使用**。
- `reference_audios` 不能单独使用，须搭配参考图、参考视频或首尾帧。

## 示例


### 经济版 — 首帧图生视频

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2_sp_720p",
    "prompt": "雨夜街头，女孩回头微笑，电影感镜头推进",
    "duration": 5,
    "ratio": "16:9",
    "first_image": "https://example.com/start.png"
  }'
```

### 参考图生视频

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2_sp_720p",
    "prompt": "人物缓缓转头，微风拂动发丝",
    "duration": 6,
    "ratio": "9:16",
    "images": [
      "https://example.com/ref-1.jpg",
      "https://example.com/ref-2.jpg"
    ]
  }'
```

### 使用素材库 asset

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2_sp_fast_780p",
    "prompt": "镜头缓慢推进，光影变化细腻",
    "duration": 8,
    "ratio": "16:9",
    "images": ["asset://your-asset-id-here"]
  }'
```

## 响应示例

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "sd2_sp_720p",
    "created_at": 1710000000
  }
}
```

## 查询任务

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

任务状态：`queued` → `processing` → `completed` / `failed`。完成后从 `data.result.video_url` 获取视频地址。

<Note>
视频结果 URL 保存约 **3 天**，请及时转存。
</Note>
