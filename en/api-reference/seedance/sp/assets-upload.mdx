---
title: 'SP Upload Asset'
openapi: 'POST /api/open-api/v1/seedance/sp/assets/upload'
---

Upload image, video, audio, or text assets to the Seedance SP economy asset library. Use the returned `asset_id` as `asset://{asset_id}` in [SP Create Video](/en/api-reference/seedance/sp/create).

<Note>
This endpoint is for **SP economy route** models (`sd2_sp_*` series). For the full Manxue route, use [Submit Asset Audit](/en/api-reference/seedance/assets-audit).
</Note>

## Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Asset name |
| `type` | string | Yes | Asset type: `image`, `video`, `audio`, `text` |
| `url` | string | Yes | Public asset URL |

## Example

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/sp/assets/upload' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "reference-1",
    "type": "image",
    "url": "https://example.com/ref.jpg"
  }'
```

## Response

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "asset_id": "asset_abc123"
  }
}
```

After upload, the asset enters processing automatically. Poll [Query Asset Detail](/en/api-reference/seedance/sp/assets-detail) and check `status`. **Only assets with `ACTIVE` status can be used for video generation.**

## Status values

| Status | Meaning |
|--------|---------|
| `NONE` | Record created but upload/processing has not started. Poll again; not ready for video tasks |
| `UPLOADING` | Asset is uploading. Wait for status updates; not ready for video tasks |
| `PROCESSING` | Asset submitted and processing. Keep polling; not ready for video tasks |
| `ACTIVE` | Ready to use. Only this status can be used for video generation |
| `FAILED` | Processing failed. Fix the issue and re-upload |
| `EXPIRED` | Expired and unavailable. Re-poll until `ACTIVE`, or re-upload if needed |
| `DELETED` | Deleted or invalidated. Re-upload and wait until `ACTIVE` |

## Next steps

1. Poll [Query Asset Detail](/en/api-reference/seedance/sp/assets-detail) or [Batch Query Asset Status](/en/api-reference/seedance/sp/assets-status)
2. Wait until `status` is `ACTIVE`
3. Reference `asset://{asset_id}` in video create requests
