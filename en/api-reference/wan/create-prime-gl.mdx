<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status and read the final video URL from `result.video_url`.
</Note>

This endpoint is shared with [Create Wan 3.0 Video](/en/api-reference/wan/create) at `POST /api/open-api/v1/wan/videos`. Select this model with `model: "wan3.0-prime-gl"`; it is billed separately. For standard Official Channel, see [`wan3.0-gl`](/en/api-reference/wan/create-gl).

## Supported models

| model | Notes |
|-------|-------|
| `wan3.0-prime-gl` | Wan 3.0 Prime Official Channel video generation. Supports text-to-video, first-frame / first-and-last-frame video, and reference video (up to 10 images, 5 videos, 5 audios). 2–30s duration, 480p/720p/1080p. |

This model **does not** support `file_url` / `link_url`. Use [`wan3.0-gz`](/en/api-reference/wan/create-gz) when you need a reference document or webpage.

## Generation modes

| Mode | Fields |
|------|--------|
| Text-to-video | `prompt` only |
| First frame | `first_image` |
| First and last frame | `first_image` + `last_image` |
| Reference media | `reference_images` / `reference_videos` / `reference_audios` |

First/last frames (`first_image` / `last_image`) **cannot be combined** with reference media (reference images/videos/audios).

Aliases `wan30-prime-gl` and `wan-3.0-prime-gl` normalize to `wan3.0-prime-gl`. You may also pass billing models `wan3.0-prime-gl-480p` / `wan3.0-prime-gl-720p` / `wan3.0-prime-gl-1080p` directly; the suffix then sets the resolution.

## Parameter constraints

- **Prompt**: Provide a prompt or at least one input (frames or reference images/videos/audios). Refer to media as "图1", "视频1", "音频1" (image 1, video 1, audio 1), numbered by order within each media array.
- **Duration**: 2–30 seconds (default `5`).
- **Aspect ratio** (`aspect_ratio` / `ratio`): `adaptive`, `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `21:9` (default `16:9`).
- **Resolution**: `480P`, `720P`, `1080P` (case-insensitive), default `720P`.
- **Reference images**: `reference_images` or `images`, max **10**, public HTTPS URLs.
- **Reference videos**: `reference_videos` or `videos`, max **5**, public HTTPS URLs.
- **Reference audios**: `reference_audios`, max **5**, public HTTPS URLs.
- **First / last frame**: `first_image` / `last_image`, one public URL each; `last_image` requires `first_image`.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `wan3.0-prime-gl`, or a resolution billing model |
| `prompt` | string | No | Text prompt; required when no input media is provided |
| `duration` | integer | No | Duration in seconds, 2–30, default 5 |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `resolution` | string | No | Output resolution: `480P` / `720P` / `1080P`, default `720P` |
| `reference_images` | string[] | No | Reference image URLs (0–10) |
| `images` | string[] | No | Alias for `reference_images` when the latter is empty |
| `reference_videos` | string[] | No | Reference video URLs (0–5) |
| `videos` | string[] | No | Alias for `reference_videos` |
| `reference_audios` | string[] | No | Reference audio URLs (0–5) |
| `first_image` | string | No | First frame image URL |
| `last_image` | string | No | Last frame image URL; requires `first_image` |

## Examples

### Reference media

```bash
curl -X POST https://api.viraltok.ai/api/open-api/v1/wan/videos \
  -H "Authorization: Bearer $JIMMYAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan3.0-prime-gl",
    "prompt": "The person in 图1 runs along the beach, cinematic camera movement",
    "duration": 5,
    "aspect_ratio": "9:16",
    "resolution": "720P",
    "reference_images": ["https://example.com/person.png"]
  }'
```

### First and last frame

```json
{
  "model": "wan3.0-prime-gl",
  "prompt": "The smile slowly turns into laughter; lighting shifts from cool to warm",
  "first_image": "https://example.com/first.png",
  "last_image": "https://example.com/last.png",
  "duration": 5
}
```

### Text-to-video

```json
{
  "model": "wan3.0-prime-gl",
  "prompt": "Morning sea with thinning mist, cinematic push-in",
  "duration": 8,
  "aspect_ratio": "21:9",
  "resolution": "1080P"
}
```

## Billing

- Mode: `per_second`
- Request model: `wan3.0-prime-gl` (or a resolution billing model)
- Billing model: `wan3.0-prime-gl-{resolution}` (`wan3.0-prime-gl-480p` / `wan3.0-prime-gl-720p` / `wan3.0-prime-gl-1080p`); unit price differs by resolution
- Without `resolution`, billed as `720P`
- On create, prepaid by request `duration`; after success, settled to actual billed seconds (refund or surcharge)
- After completion, task query returns actual billed seconds in `data.usage.duration`

```text
prepaid = unit_price × duration
settled = unit_price × actual_billed_seconds
```

Unit prices follow the console model pricing.
