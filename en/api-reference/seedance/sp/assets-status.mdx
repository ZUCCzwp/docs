---
title: 'SP Batch Query Asset Status'
openapi: 'POST /api/open-api/v1/seedance/sp/assets/status'
---

Batch query processing status for Seedance SP economy assets.

## Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `asset_ids` | string[] | Yes | List of asset IDs |

## Example

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/sp/assets/status' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "asset_ids": ["asset_abc123", "asset_def456"]
  }'
```

## Response

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "items": [
      {
        "asset_id": "asset_abc123",
        "status": "Active",
        "name": "reference-1"
      }
    ]
  }
}
```
