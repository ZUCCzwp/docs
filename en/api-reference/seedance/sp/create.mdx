---
title: 'SP Create Video'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

Create a Seedance **SP** video generation task (economy). On success you receive a `task_id`. Poll [Query Video Task](/en/api-reference/common/query) until `completed`, then read the video URL from `result.video_url`.

<Note>
This uses the same endpoint as [Create Seedance Full Video](/en/api-reference/seedance/create): `POST /api/open-api/v1/seedance/videos`. For Full (Manxue), see the full-route doc; for Mini, see [Mini Create Video](/en/api-reference/seedance/mini/create); for MD, see [MD Create Video](/en/api-reference/seedance/md/create).
</Note>

## Models

## Models and Routes

Choose the SP economy sub-route via the `model` field:

| Route | `model` value | Billing | Duration | Requirements |
|-------|---------------|---------|----------|--------------|
| **Economy Standard** | `sd2_sp_480p`, `sd2_sp_720p`, `sd2_sp_1080p`, `sd2_sp_2k`, `sd2_sp_4k` | Per second | 4–15 s | Public URL or asset library |
| **Economy Fast** | `sd2_sp_fast_780p` | Per second | 4–15 s | Same as above; `reference_videos` not supported |
| **Video Reference** | `sd2_sp_video_480p`, `sd2_sp_video_720p`, `sd2_sp_video_1080p`, `sd2_sp_video_2k`, `sd2_sp_video_4k` | Per second | 4–15 s | Same as above; supports `reference_videos` |
| **Video Reference Fast** | `sd2_sp_video_fast_780p` | Per second | 4–15 s | Same as above; supports `reference_videos` |

## Billing

Deduct corresponding computing credits directly based on the selected `model`:

| Item | Description |
|------|-------------|
| Calculation | **Unit price (credit/s) × `duration`** |
| Unit Price | Based on the price for the corresponding model name in the console |
| Duration | `duration` field, ranging from 4 to 15 seconds |


## Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | See table above |
| `prompt` | string | Yes | Text prompt |
| `duration` | int | Yes | Length in seconds, 4–15 (default 5) |
| `resolution` | string | No | Output resolution: `480p`, `720p` (default), `1080p` |
| `ratio` | string | No | Aspect ratio, e.g. `16:9`, `9:16`, `1:1` |
| `images` | string[] | No | Reference images |
| `first_image` | string | No | First frame |
| `last_image` | string | No | Last frame |
| `reference_videos` | string[] | No | Reference videos |
| `reference_audios` | string[] | No | Reference audio; must pair with images/videos or frames |

## Assets

- Pass public `https://` URLs directly.
- Or [upload assets](/en/api-reference/seedance/sp/assets-upload) first, then use `asset://{asset_id}`.

## Constraints

- Do not combine `images` (reference mode) with `first_image` / `last_image` (frame mode).
- `reference_audios` cannot be used alone; pair with reference images/videos or frames.

## Examples


### Economy — first-frame to video

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2_sp_720p",
    "prompt": "Rainy street at night, girl turns and smiles, cinematic dolly-in",
    "duration": 5,
    "ratio": "16:9",
    "first_image": "https://example.com/start.png"
  }'
```

### Reference images

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2_sp_720p",
    "prompt": "Subject slowly turns head, gentle breeze in hair",
    "duration": 6,
    "ratio": "9:16",
    "images": [
      "https://example.com/ref-1.jpg",
      "https://example.com/ref-2.jpg"
    ]
  }'
```

### Using uploaded assets

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2_sp_fast_780p",
    "prompt": "Slow dolly in, subtle lighting change",
    "duration": 8,
    "ratio": "16:9",
    "images": ["asset://your-asset-id-here"]
  }'
```

## Response

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "vid_abc123",
    "status": "queued",
    "model": "sd2_sp_720p",
    "created_at": 1710000000
  }
}
```

## Poll for result

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

Statuses: `queued` → `processing` → `completed` or `failed`. Video URL is in `data.result.video_url` when completed.

<Note>
Result URLs are retained for about **3 days**. Download promptly.
</Note>
