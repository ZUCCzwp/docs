## 错误处理

### 常见Code码

| Code码 | 说明     | 解决方案     |
| --- | ------ | -------- |
| 20000 | 请求成功 | | 
| 20002 | 请求参数错误 | 检查请求参数格式 |
| 20001 | 鉴权失败   | 尝试更换token     |
| -1 | 服务器错误  | 稍后重试     |

## 最佳实践

1. **合理使用缓存**：生成的图像/视频链接有效期为3天
2. **错误重试**：实现指数退避重试机制
3. **监控使用量**：定期检查API使用情况
4. **安全存储**：妥善保管您的API密钥
