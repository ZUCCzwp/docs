<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status and read the video URL from `result.video_url`.
</Note>

This uses the same endpoint as [Create Seedance 2.5 Video](/en/api-reference/seedance/25/create): `POST /api/open-api/v1/seedance25/videos`. For the fixed 30-second model with face blur, see [seedance2.5-30s](/en/api-reference/seedance/25/create-30s).

<Warning>
Do **not** call `/api/open-api/v1/seedance/videos` (Seedance 2.0 / Full routes). That would land on the Full channel.
</Warning>

## Supported models

| model | Output | Notes |
|-------|--------|-------|
| `sd2.5-720p` | **720p**, length set by `duration` | Text-to-video, reference images / videos / audios. Faces are kept |

<Warning>
Faces in reference images are kept as-is. The platform does not blur faces, and it does not reject a task because a face is present.
</Warning>

## Parameter constraints

- **Prompt**: Required, 1–5000 characters.
- **Duration**: `4`–`30` seconds. Defaults to **4** when omitted. Billing uses this length.
- **Aspect ratio** (`aspect_ratio` / `ratio`): **`16:9`** and **`9:16`** only. Default `9:16` when omitted.
- **Reference images** (`reference_images` / `images`): max **30** public URLs. Faces are not blurred.
- **Reference videos** (`reference_videos` / `videos`): max **10** public URLs.
- **Reference audios** (`reference_audios` / `audios`): max **10** public URLs.
- **Not supported**: `first_image` / `last_image` (first-last frames).
- **Not supported**: `resolution`, `generate_audio`, `watermark`, `output_format`, and other GZ-only fields. Resolution is fixed at 720p by the model.
- Pass public `https://` URLs for reference videos and audios. Do not send base64 payloads.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `sd2.5-720p` |
| `prompt` | string | Yes | Text prompt |
| `duration` | integer | No | Output seconds, `4`–`30`. Defaults to `4` |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `reference_images` | string[] | No | Reference image URLs, max 30. Faces are kept |
| `images` | string[] | No | Alias for `reference_images` |
| `reference_videos` | string[] | No | Reference video URLs, max 10 |
| `videos` | string[] | No | Alias for `reference_videos` |
| `reference_audios` | string[] | No | Reference audio URLs, max 10 |
| `audios` | string[] | No | Alias for `reference_audios` |

## Billing

- Billing mode: **`per_second`**
- Billing model: `sd2.5-720p` (configured separately from `seedance2.5-30s`)
- Charge = unit price × `duration` (4 seconds when `duration` is omitted)

Configure the per-second unit price on `sd2.5-720p` in Console.

## Example request

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance25/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd2.5-720p",
    "prompt": "A cat running on grass, tracking shot",
    "duration": 8,
    "aspect_ratio": "9:16",
    "reference_images": ["https://example.com/cat.png"],
    "reference_videos": ["https://example.com/ref.mp4"],
    "reference_audios": ["https://example.com/ref.mp3"]
  }'
```
