---
title: 'SP Query Asset Detail'
openapi: 'POST /api/open-api/v1/seedance/sp/assets/detail'
---

Query processing status and metadata for a single Seedance SP economy asset.

## Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `asset_id` | string | Yes | Asset ID returned from upload |

## Example

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/sp/assets/detail' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "asset_id": "asset_abc123"
  }'
```

## Response fields

| Field | Description |
|-------|-------------|
| `asset_id` | Asset ID |
| `official_id` | Upstream official ID |
| `status` | `READY` when ready to use |
| `name` | Asset name |
| `image_url` | Image URL when applicable |
| `created_at` | Creation time |

## Status values

| Status | Meaning |
|--------|---------|
| `PROCESSING` | Still processing |
| `READY` | Ready; use `asset://{asset_id}` |
| `FAILED` | Processing failed |
| `DISABLED` | Disabled |
