---
title: 'Create Seedance 2.0 GZ 720p Video'
openapi: 'POST /api/open-api/v1/seedance/videos'
---

<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status and read the final video URL from `result.video_url`.
</Note>

This uses the same endpoint as [Create Seedance Full Video](/en/api-reference/seedance/create): `POST /api/open-api/v1/seedance/videos`. Select this route with `model: "seedance2.0-gz-720p"`.

## Supported models

| model | Notes |
|-------|-------|
| `seedance2.0-gz-720p` | Seedance 2.0 GZ 720p: fixed 720p output; text-to-video plus optional reference images / videos / audios |

Aliases such as `seedance2.0-gz720p` and `seedance20-gz-720p` normalize to `seedance2.0-gz-720p`.

## Parameter constraints

- **Prompt**: Required, 1–5000 characters.
- **Duration**: 4–15 seconds (default `5`).
- **Aspect ratio** (`aspect_ratio` / `ratio`): `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16` (default `16:9`).
- **Resolution**: Fixed `720p` (any other value is ignored / forced to 720p).
- **Reference images**: `images` or `reference_images`, max **9**, public HTTPS URLs or `asset://{assetId}`.
- **Reference videos**: `videos` or `reference_videos`, max **3**.
- **Reference audios**: `audios` or `reference_audios`, max **3**; must be paired with at least one image or video reference.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `seedance2.0-gz-720p` |
| `prompt` | string | Yes | Text prompt |
| `duration` | integer | No | Duration in seconds, default `5` |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `images` | string[] | No | Reference image URLs (0–9) |
| `reference_images` | string[] | No | Alias for `images` when `images` is empty |
| `videos` / `reference_videos` | string[] | No | Reference video URLs (0–3) |
| `audios` / `reference_audios` | string[] | No | Reference audio URLs (0–3); requires image or video refs |

## Billing

- Mode: `per_second`
- Billing model: `seedance2.0-gz-720p` (unit price from [console pricing](https://api.viraltok.ai))

```text
cost = unit_price × duration
```

## Example request

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance2.0-gz-720p",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 5,
    "aspect_ratio": "16:9",
    "images": ["https://example.com/reference.png"],
    "reference_videos": ["https://example.com/reference.mp4"]
  }'
```

## Result URL

When the task completes, read `data.result.video_url`. This route returns a **direct media link** — download promptly.
