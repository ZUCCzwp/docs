---
title: 'Create video super-resolution task'
openapi: 'en/api-reference/openapi.json POST /api/open-api/v1/super-resolution/videos'
---

Create a video super-resolution task that enhances a publicly accessible low-resolution video. After submission you receive a `task_id`. Poll via [Query Video Task](/en/api-reference/common/query) and read `result.video_url` when completed.

## Supported models

Model names combine target clarity and frame-rate tier: `lowfps` = 30 FPS, `highfps` = 120 FPS.

| model | Target | FPS tier |
|-------|--------|----------|
| `superResolution-720p-lowfps` | 720p | Standard |
| `superResolution-720p-highfps` | 720p | High |
| `superResolution-1080p-lowfps` | 1080p | Standard |
| `superResolution-1080p-highfps` | 1080p | High |
| `superResolution-2k-lowfps` | 2K | Standard |
| `superResolution-2k-highfps` | 2K | High |
| `superResolution-4k-lowfps` | 4K | Standard |
| `superResolution-4k-highfps` | 4K | High |

Resolution and frame rate are determined by `model` — no extra fields required.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | See table above |
| `video_url` | string | Yes | Public URL of the source video; must remain accessible while processing |

## Billing

- Mode: `per_second`
- Duration: probed from `video_url`, **ceiled** to whole seconds (minimum 1)
- Unit price: from console pricing for the selected `model`

```text
cost = unit_price × ceil(video_duration_seconds)
```

## Example

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/super-resolution/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "superResolution-1080p-lowfps",
    "video_url": "https://example.com/input-low-resolution.mp4"
  }'
```

## Response example

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "task_id": "video_task_1234567890",
    "status": "queued",
    "model": "superResolution-1080p-lowfps",
    "created_at": 1782529105,
    "cost": 0.4
  }
}
```

## Query task

```bash
curl -X GET 'https://api.viraltok.ai/api/open-api/v1/videos/{task_id}' \
  -H 'Authorization: Bearer sk_xxx'
```

Poll every 5–10 seconds until `completed` or `failed`. Result URLs are kept about **3 days** — download promptly.
