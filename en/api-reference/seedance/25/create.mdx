<Note>
After creation, the response returns a `task_id`. Use the [Query Video Task](/en/api-reference/common/query) endpoint to poll task status and read the final video URL from `result.video_url`.
</Note>

<Warning>
These models require `POST /api/open-api/v1/seedance25/videos`. Do **not** call `/api/open-api/v1/seedance/videos` (Seedance 2.0 / Full routes); that would land on the Full (Manxue) channel.
</Warning>

## Supported models

| model | Notes |
|-------|-------|
| `seedance-2.5` | Standard Seedance 2.5: text-to-video plus optional reference images / videos / audios |
| `seedance-2.5-sp` | Seedance 2.5 SP: flat per-second price, 720p only, supports reference images / videos / audios / first-last frames |

Aliases such as `seedance2.5`, `seedance_2.5`, and `seedance25` normalize to `seedance-2.5`.

Standard billing model names are also accepted as `model`: `seedance-2.5-480p`, `seedance-2.5-720p` (resolution is parsed from the model when `resolution` is omitted; an explicit `resolution` field takes precedence).

## Parameter constraints

### Standard `seedance-2.5`

- **Prompt**: Required, 1–5000 characters.
- **Duration**: 4–30 seconds (default `4`).
- **Aspect ratio** (`aspect_ratio` / `ratio`): `16:9`, `9:16`, `1:1` (default `9:16`).
- **Resolution**: `480p`, `720p` (default `480p`).
- **Reference images** (`reference_images`): max **30**.
- **Reference videos** (`reference_videos`): max **10**; each clip and the combined duration must be ≤ **30.2** seconds.
- **Reference audios** (`reference_audios`): max **10**; each clip must be ≤ **30** seconds.

### SP `seedance-2.5-sp`

- **Duration**: 4–30 seconds (default `4`).
- **Aspect ratio**: `16:9`, `9:16`, `1:1`.
- **Resolution**: `720p` only.
- **Reference images**: max **30**.
- **Reference videos**: max **10**; each clip and the combined duration must be ≤ **30.2** seconds.
- **Reference audios**: max **10**; each clip must be ≤ **30** seconds.
- **First / last frame**: optional `first_image` / `last_image` (one each); **cannot** be combined with `reference_images` / `images`.

## Request parameters

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `model` | string | Yes | `seedance-2.5` / `seedance-2.5-sp`, or standard billing names `seedance-2.5-480p` / `seedance-2.5-720p` |
| `prompt` | string | Yes | Text prompt |
| `duration` | integer | No | Duration in seconds |
| `aspect_ratio` | string | No | Aspect ratio; takes precedence over `ratio` |
| `ratio` | string | No | Alias for `aspect_ratio` |
| `resolution` | string | No | Standard `480p`/`720p`; SP `720p` only |
| `first_image` | string | No | First-frame image URL; SP only |
| `last_image` | string | No | Last-frame image URL; SP only |
| `reference_images` | string[] | No | Reference image URLs (0–30) |
| `images` | string[] | No | Alias for `reference_images` |
| `reference_videos` | string[] | No | Reference video URLs (0–10); each and total ≤ 30.2s |
| `videos` | string[] | No | Alias for `reference_videos` |
| `reference_audios` | string[] | No | Reference audio URLs (0–10); each ≤ 30s |
| `audios` | string[] | No | Alias for `reference_audios` |

## Billing

- Mode: `per_second`
- Standard billed by resolution:
  - `seedance-2.5-480p`
  - `seedance-2.5-720p`
- SP fixed billing model: `seedance-2.5-sp` (**0.5** per second)

```text
cost = unit_price × duration
```

## Example request

Standard:

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance25/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance-2.5",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 4,
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "reference_images": ["https://example.com/reference.png"],
    "reference_videos": ["https://example.com/reference.mp4"],
    "reference_audios": ["https://example.com/reference.mp3"]
  }'
```

SP:

```bash
curl -X POST 'https://api.viraltok.ai/api/open-api/v1/seedance25/videos' \
  -H 'Authorization: Bearer sk_xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "seedance-2.5-sp",
    "prompt": "A cinematic product shot with natural lighting and a slow push-in",
    "duration": 5,
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "first_image": "https://example.com/start.png",
    "last_image": "https://example.com/end.png"
  }'
```
